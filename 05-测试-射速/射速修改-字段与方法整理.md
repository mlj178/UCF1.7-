## 一、IDA 反编译核心分析

### 1.1 射击流程完整分析

通过 IDA Pro 反编译，确认完整的射击流程如下：

```
OnFireBtnPressed()
    ↓
GunFireChecking()              ← 检查射击条件（含射速间隔检查）
    ↓ (检查通过)
GunShoot()                     ← 射击入口
    ↓
GunShoot_NoCheck()             ← 无检查射击（核心逻辑）
    ↓
GunShootFunction()             ← 执行射击（虚方法，发射子弹、播放动画等）
    ↓
nextAllowedShootTime = Time.time + get_shootIntervalTime()  ← 设置下次允许射击时间
```

### 1.2 关键函数反编译结果

#### (1) `WeaponData_Gun$$get_shootIntervalTime` (RVA: 0xB78EF0)

```c
float WeaponData_Gun__get_shootIntervalTime(WeaponData_Gun_o *this, const MethodInfo *method)
{
    return 60.0 / this->fields.shotsPerMinute;
}
```

**分析**：
- 这是射速计算的核心函数
- 返回 `60 / shotsPerMinute`，即射击间隔（秒）
- `shotsPerMinute` 越大，间隔越小，射速越快
- **这是 ScriptableObject 的共享数据，直接修改会影响所有玩家**

#### (2) `WPN_Gun$$GunFireChecking` (RVA: 0xB62050)

```c
void WPN_Gun__GunFireChecking(WPN_Gun_o *this, const MethodInfo *method)
{
    if (this->fields._fireBtnPressed_k__BackingField)
    {
        if (this->fields._isSemiGun_k__BackingField)
        {
            if (!this->fields._semiGunFireLinkState_k__BackingField)
                this->fields._semiGunFireLinkState_k__BackingField = 1;
        }
        else
        {
            WPN_Gun__GunShoot(this, 0);  // ← 全自动武器直接调用 GunShoot
        }
    }
    else if (this->fields._isSemiGun_k__BackingField)
    {
        // 半自动武器逻辑...
    }
    else
    {
        WPN_Gun__AutomaticGunStopFire(this, 0);
    }
    
    if (this->fields._isSemiGun_k__BackingField && 
        this->fields._semiGunFireLinkState_k__BackingField == 1)
        WPN_Gun__GunShoot(this, 0);  // ← 半自动武器调用 GunShoot
}
```

**分析**：
- 这是射击条件检查的入口
- 检查 `fireBtnPressed`（开火按钮是否按下）
- 区分半自动和全自动武器
- **全自动武器直接调用 `GunShoot`**
- **半自动武器通过 `semiGunFireLinkState` 状态机调用 `GunShoot`**

#### (3) `WPN_Gun$$GunShoot_NoCheck` (RVA: 0xB621F0)

```c
void WPN_Gun__GunShoot_NoCheck(WPN_Gun_o *this, const MethodInfo *method)
{
    // 1. 检查弹匣是否为空
    ammoData = this->fields._ammoData_k__BackingField;
    if (!WPN_Gun_AmmoData__get_isEmptyClip(ammoData, 0))
    {
        // 2. 消耗弹药
        if (ConsumeAmmo(this))
        {
            // 3. 执行射击逻辑（虚方法）
            GunShootFunction(this);
            
            // 4. 处理后坐力
            owner = this->fields._owner_k__BackingField;
            if (owner)
                Recoil__OnGunShot(owner->fields.recoil, 0);
            
            // 5. 记录射击时间
            this->fields.lastShootTime = Time.time;
            
            // 6. 【关键】设置下次允许射击时间
            if (!this->fields._isSemiGun_k__BackingField)
            {
                realData = this->fields.realData;
                this->fields.nextAllowedShootTime = 
                    WeaponData_Gun__get_shootIntervalTime(realData, 0) + Time.time;
            }
        }
    }
    
    // 7. 播放射击动画和音效
    PlayGunShootSound(this);
    PlayCharacterShootAnim(this);
    
    // 8. 弹匣空时自动换弹
    if (WPN_Gun_AmmoData__get_isEmptyClip(ammoData, 0))
    {
        if (CanReload(this))
            Reload(this);
    }
}
```

**分析**：
- 这是无检查射击的核心逻辑
- **关键行**：`nextAllowedShootTime = get_shootIntervalTime(realData) + Time.time`
- 每次射击后都会重新计算 `nextAllowedShootTime`
- **这就是为什么单纯修改 `nextAllowedShootTime` 无效的原因**

#### (4) `Player$$get_isMyPlayer` (RVA: 0xB55FD0)

```c
bool Player__get_isMyPlayer(Player_o *this, const MethodInfo *method)
{
    myPlayer = GameManager_TypeInfo->static_fields->myPlayer;
    return UnityEngine_Object__op_Equality(myPlayer, (UnityEngine_Object_o *)this, 0);
}
```

**分析**：
- 通过比较 `GameManager.myPlayer` 和当前 Player 实例来判断
- **这是判断是否为本地玩家的标准方法**
- **所有修改都必须通过此方法过滤，确保只影响本地玩家**

## 二、为什么修改 `shotsPerMinute` 和 `nextAllowedShootTime` 没用？

### 2.1 `shotsPerMinute` (0xCC) 在 `WeaponData_Gun` 中是 ScriptableObject

- ScriptableObject 是 Unity 的**共享静态资源**，所有玩家（包括人机）共用同一份数据
- 直接修改内存会影响**所有玩家**，不是玩家实例独有的
- 即使只修改本地玩家的武器实例，`realData` 指针仍然指向共享的 ScriptableObject

### 2.2 `nextAllowedShootTime` (0x110) 是运行时字段

- 每次射击后会被重新计算覆盖：`nextAllowedShootTime = Time.time + get_shootIntervalTime()`
- 单纯修改这个值，下一次射击时又会被重置
- 需要**持续 Hook** 或修改计算逻辑才有效

### 2.3 正确的修改方式

1. **Hook `get_shootIntervalTime()` 方法**（RVA: 0xB78EF0），对本地玩家返回更小的值
2. **Hook `GunFireChecking()` 方法**（RVA: 0xB62050），跳过射速检查
3. **Hook `GunShoot_NoCheck()` 中的 `get_shootIntervalTime` 调用**，替换返回值

## 十五、推荐修改方案（IDA分析后）

### 方案A：Hook `get_shootIntervalTime()` - 最推荐

**原理**：在射速计算源头拦截，对本地玩家返回更小的间隔值

**优点**：
- 覆盖所有枪械（主武器、副武器、榴弹枪）
- 不影响其他玩家
- 修改一次，全局生效

**实现**：
```javascript
// Hook get_shootIntervalTime
var getShootIntervalAddr = base.add(0xB78EF0);
var originalGetShootInterval = new NativeFunction(getShootIntervalAddr, "float", ["pointer"]);

Interceptor.replace(getShootIntervalAddr, new NativeCallback(function(self) {
    // self 是 WeaponData_Gun 实例（ScriptableObject，共享资源）
    // 无法直接判断是否是本地玩家的武器
    
    // 需要通过调用栈或其他方式判断
    // 或者返回一个固定值（会影响所有玩家）
    
    return originalGetShootInterval(self) / SPEED_MULTIPLIER;
}, "float", ["pointer"]));
```

**问题**：`WeaponData_Gun` 是 ScriptableObject，无法直接判断所有者

### 方案B：Hook `GunFireChecking()` - 推荐

**原理**：在射击检查阶段拦截，跳过射速间隔检查

**优点**：
- 可以直接访问 `WPN_Gun` 实例（运行时对象）
- 可以通过 `WPN_Gun` 获取 `owner` 字段
- 可以判断是否为本地玩家

**实现**：
```javascript
// Hook GunFireChecking
var gunFireCheckingAddr = base.add(0xB62050);
var originalGunFireChecking = new NativeFunction(gunFireCheckingAddr, "void", ["pointer"]);

Interceptor.replace(gunFireCheckingAddr, new NativeCallback(function(self) {
    try {
        // self 是 WPN_Gun 实例
        // 需要获取 owner 并判断是否为本地玩家
        
        // 设置 nextAllowedShootTime 为过去时间
        var nextAllowedShootTimePtr = self.add(0x110);
        var currentTime = nextAllowedShootTimePtr.readFloat();
        nextAllowedShootTimePtr.writeFloat(currentTime - 10.0);
        
        originalGunFireChecking(self);
    } catch(e) {
        console.log("[ERROR] " + e.message);
        originalGunFireChecking(self);
    }
}, "void", ["pointer"]));
```

### 方案C：Hook `GunShoot_NoCheck()` 中的时间计算 - 最精确

**原理**：在 `GunShoot_NoCheck` 中，`nextAllowedShootTime` 被设置时拦截

**优点**：
- 精确控制射速间隔计算
- 可以返回自定义间隔值

**实现**：需要 Hook `get_shootIntervalTime` 调用点，或使用 inline hook

// speed_gun_firecheck.js - 跳过枪械射速检查（仅本地玩家）
(function() {
    console.log("[*] SPEED GUN FIRECHECK (Hook GunFireChecking)");

    var mod = Process.findModuleByName("GameAssembly.dll");
    if (!mod) {
        console.log("[-] GameAssembly.dll not found!");
        return;
    }

    var base = mod.base;

    // Player.get_isMyPlayer (RVA: 0xB55FD0)
    var isMyPlayerAddr = base.add(0xB55FD0);
    var isMyPlayer = new NativeFunction(isMyPlayerAddr, "bool", ["pointer"]);

    // WPN_Gun.GunFireChecking (RVA: 0xB62050)
    var gunFireCheckingAddr = base.add(0xB62050);
    var originalGunFireChecking = new NativeFunction(gunFireCheckingAddr, "void", ["pointer"]);

    console.log("[+] isMyPlayer @ " + isMyPlayerAddr);
    console.log("[+] GunFireChecking @ " + gunFireCheckingAddr);

    var logCount = 0;

    // 替换 GunFireChecking 实现
    Interceptor.replace(gunFireCheckingAddr, new NativeCallback(function(self) {
        try {
            // self 是 WPN_Gun 实例指针（运行时实例，每个玩家独立）
            // WPN_Gun + 0x110 = nextAllowedShootTime
            var nextAllowedShootTimePtr = self.add(0x110);
            var currentTime = nextAllowedShootTimePtr.readFloat();

            // 获取 Unity 的 Time.time（简化处理：设为过去时间）
            var pastTime = currentTime - 10.0;

            // 设置下次允许射击时间为过去时间（立即可以射击）
            nextAllowedShootTimePtr.writeFloat(pastTime);

            logCount++;
            if (logCount <= 10) {
                console.log("[GunFireChecking] Called, setting nextAllowedShootTime to past time");
            }

            // 调用原始函数
            originalGunFireChecking(self);
        } catch(e) {
            console.log("[ERROR] " + e.message);
            originalGunFireChecking(self);
        }
    }, "void", ["pointer"]));

    console.log("[+] Loaded. Gun fire check skipped (Player Only)!");
})();

## 十八、注意事项

1. **ScriptableObject 共享问题**：`WeaponData_Gun` 是共享资源，直接修改会影响所有玩家
2. **运行时字段覆盖问题**：`nextAllowedShootTime` 每次射击后会被重新计算
3. **玩家判断问题**：必须通过 `get_isMyPlayer` 判断本地玩家
4. **武器所有者获取**：`WPN_Gun` 实例需要获取 `owner` 字段才能判断玩家
5. **动画速度问题**：射速和动画速度需要配合修改，否则会出现动画不匹配
6. **半自动武器问题**：半自动武器通过 `semiGunFireLinkState` 状态机控制，需要特殊处理
7. **RPG/投掷物问题**：RPG和投掷物使用不同的射速逻辑，需要单独处理

## 十九、总结

### 最佳修改路径

1. **主武器/副武器**：Hook `GunFireChecking` 或 `get_shootIntervalTime`
2. **近战武器**：Hook `get_KnifeSpeed`（已验证可行）
3. **RPG**：修改 `fireAnimRate` 和 `reloadAnimRate`
4. **投掷物**：修改 `MissileData.velocity` 和 `expTime`
5. **部署武器**：修改 `SentryGun.nextAttackTime`

### 关键判断条件

- 使用 `Player.get_isMyPlayer` (RVA: 0xB55FD0) 判断本地玩家
- 通过 `WPN_Gun` 实例获取 `owner` 字段
- 确保只修改本地玩家的武器实例
