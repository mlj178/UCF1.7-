# 穿越火线单机版功能文档体系说明

## 作用

本文档只说明代码解读、功能问答、模板和索引之间如何配合。具体生成要求以各自规范为准；即使不读取本文档，也能使用任意一份规范独立生成对应页面。

## 文件关系

| 文件 | 作用 | 是否需要同时读取其他规范 |
|---|---|---|
| `HTML代码解读文档生成规范.md` | 生成各功能的 `代码解读.html` | 否 |
| `HTML功能问答文档生成规范.md` | 生成各功能的 `功能问答.html` 和问答 JSON | 否 |
| `代码解读HTML模板.html` | 展示代码解读页面的结构和交互 | 否，按代码解读规范使用 |
| `功能问答HTML模板.html` | 展示问答页面的结构、编辑和持久化交互 | 否，按功能问答规范使用 |
| `index.html` | 汇总所有功能并提供页面入口 | 不适用 |

两类页面复用标题、源码档案、关键行图例、完整代码导航和完整代码正文的视觉结构，并统一以 `代码解读HTML模板.html` 作为视觉和尺寸基准。它们的右侧职责不同：代码解读页显示业务流程解读，功能问答页保存用户的问题和回答。

## 功能文件夹

每个功能使用同一个编号文件夹：

```text
功能文档/
└─ XX-功能名称/
   ├─ 代码解读.html
   ├─ 功能问答.html
   └─ XX-功能名称-功能问答.json    可选，由用户导出
```

- `代码解读.html` 和 `功能问答.html` 应互相提供链接。
- 两个页面应使用同一版本的源码、相同的文件路径、代码段名称和行号范围。
- 问答 JSON 是可交换数据，不要求固定保存在功能文件夹中。
- 只生成其中一种页面时，另一种页面不是必需文件，不得创建无效链接。

## index.html 的职责

`index.html` 是功能文档总入口，负责让读者知道每个功能目前有哪些文档。

- 每个功能只保留一个目录条目，编号和名称与功能文件夹一致。
- 已存在 `代码解读.html` 时显示“代码解读”入口。
- 已存在 `功能问答.html` 时显示“功能问答”入口。
- 尚未生成的页面不显示链接，也不使用指向空文件的占位按钮。
- 新增、重命名或删除任一页面后，检查并同步对应条目。
- 索引只负责导航，不复制代码解读或问答规范的详细内容。

## 后续生成时如何选择

- 用户要求分析功能实现、Hook、字段、指针和游戏逻辑：读取 `HTML代码解读文档生成规范.md`。
- 用户要求记录问题、保存回答或交换问答数据：读取 `HTML功能问答文档生成规范.md`。
- 用户同时要求两种页面：分别按两份规范生成，并复用同一份源码分段信息。
- 完成任一页面后：检查页面互链，并同步 `index.html` 中该功能的可用入口。
