你的代码采用的是“内存修改流”（DLL/内部透视），而你提到的那段描述是“外部透视流”（Overlay/外部瞄准）。









| 维度     | 内部流 (Internal / DLL) *(你现在的脚本)* | 外部流 (External / Overlay) *(你提到的屏幕坐标)* |
| -------- | ---------------------------------------- | ------------------------------------------------ |
| 本质     | 改数据 (直接修改内存/寄存器)             | 改操作 (模拟鼠标/键盘)                           |
| 视野     | 游戏引擎内部 (上帝视角)                  | 显示器屏幕 (像素视角)                            |
| 性能     | 极高 (几乎不掉帧)                        | 一般 (需要截图、计算、绘图)                      |
| 开发难度 | 难 (需要逆向找 RVA/Offset)               | 易 (逻辑直观，不需要深究游戏内部)                |
| 隐蔽性   | 低 (容易被 VAC/BE 检测到 DLL)            | 高 (纯黑盒，只读内存不写，较难封禁)              |
