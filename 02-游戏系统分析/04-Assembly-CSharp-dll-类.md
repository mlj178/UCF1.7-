这种格式是**嵌套类**

嵌套类的**核心作用**就两条：

1. **代码组织**：把只属于某个类的辅助类（如 `Weapon.KnifeHitData`）写在它内部，避免全局命名污染，让结构更清晰。
2. **访问私有成员**：内部类可以直接访问外部类的私有字段，便于紧密协作的实现（如 AI 行为节点需要读写 Bot 私有状态）。

> 注意：它**不产生内存中的实例关联**，也不影响数据结构的可读性（Cheat Engine 里看不到嵌套关系）。



**嵌套类** ，**实例化引用**，**继承**的区别

三者区别一句话总结：

| 概念           | 本质                               | 比喻                                             |
| -------------- | ---------------------------------- | ------------------------------------------------ |
| **嵌套类**     | 代码写在别人花括号里               | 你的**户口本**登记在你爸名下，但你不一定住他家里 |
| **实例化引用** | 一个对象里存着另一个对象的**地址** | 你**手机里存着你朋友电话号码**，随时能打电话找他 |
| **继承**       | 子类自动拥有父类的所有成员         | 你**遗传了你爸的基因**，生来就有他的特征         |

---

**详细拆解：**

1. **嵌套类**：  
   `class A { class B { } }`  
   → B 的定义写在 A 里面，但 A 的实例**不会自动包含** B 的实例。  
   纯代码组织，运行时无关。

2. **实例化引用**：  
   `class A { public B b; }`  
   → A 的实例里有一个指针（字段）指向一个 B 的实例。  
   **运行时真的能通过 A 找到 B**。 has-a（有一个）

3. **继承**：  
   `class B : A { }`  
   → B 的实例自动拥有 A 的所有字段和方法（可以访问或重写）。  
   是一种“**is-a**”（是一个）关系。

---

**核心区别**：
- 嵌套类：**不产生内存关系**，只是源码里的分组。
- 引用：**产生内存关系**，一个对象指向另一个对象。
- 继承：**产生类型关系**，子类对象同时也是父类对象。
