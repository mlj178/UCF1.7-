## 根节点总结（可直接获取的静态入口）

| 根节点类           | 获取方式                                   | 中文说明                                   |
| ------------------ | ------------------------------------------ | ------------------------------------------ |
| `GameManager`      | `GameManager.instance`                     | 游戏全局管理器，持有玩家、武器数据、实体等 |
| `ModeBase` 子类    | `ModeBase.instance` 或子类专用 `instance3` | 游戏模式管理器（回合制、纳米模式等）       |
| `CameraManager`    | `CameraManager.instance`                   | 相机、后处理特效、渲染特性管理器           |
| `EffectManager`    | `EffectManager.instance`                   | 特效、粒子、脉冲对象池管理器               |
| `SoundManager`     | `SoundManager.instance`                    | 音效播放、音频通道管理器                   |
| `MapManager`       | `MapManager.instance`                      | 地图数据、复活点、雷达参数管理器           |
| `AssetManager`     | `AssetManager.instance`                    | 全局资源（图标、预制体）管理器             |
| `PlayerController` | `PlayerController.instance`                | 玩家输入、UI 焦点控制器                    |
| 各 `HUD_*` 单例    | 各自 `instance` 属性                       | 各类 UI 面板（角色、武器、雷达、击杀等）   |
| `SentryGunSystem`  | `SentryGunSystem.instance`                 | 哨戒炮系统管理器                           |

> 注：`Bot` 实体无静态根，需通过 `FindObjectsOfType<Bot>()` 获取。

## 总结：所有根节点类

| 根节点类                  | 获取方式                                 | 中文说明                                   |
