## 一、阶段一：需求分析提示词

### 1.1 明确功能目标提示词

```
我要实现 {功能描述}
例如：扩大刀具攻击范围，但只修改玩家的，不影响人机



### 1.2 需求拆解提示词

请帮我将这个大目标拆分为具体步骤：

步骤1：
步骤2：
步骤3：
步骤4：
步骤5：

每个步骤需要说明：
- 要做什么
- 预期输出是什么
```

### 1.3 确认技术要求提示词

```
如何完成上述的需求分析
在 dump.cs 中寻找执行步骤的思路，让开发者去选择可行性比较好的方案。


对比各个方案的优缺点


确认好方案后，去 dump.cs 中搜索目标类。
```



```
### 2.3 使用 IDA Pro MCP 反编译提示词

```

已经开启IDA的MCP，请你查询xxx功能的实现逻辑。从进入房间 到xxxx。是哪个类，改写了哪个字段，调用哪个方法。

帮我节省token，不要乱找内容。



有的时候需要只对玩家生效，有的时候，全局生效也无所谓。

只对玩家生效就得找继承类。全局生效找顶层类
