5. # UnityCrossFire 快刀功能 Frida 开发总结

    ## 1. 背景与目标
    - **游戏**：UnityCrossFire（Unity IL2CPP 引擎的 FPS 游戏）。
    - **目标**：通过 Frida 动态修改内存，实现“快刀”（出刀动画速度大幅提升）。
    - **最终成果**：`speed_knife_v11.js`，支持全模式、全背包，轻击第一段、轻击第二段、重击全部加速至 5 倍，无卡顿，无需重复注入。
    
    ---
    
    ## 2. 游戏结构分析
    - **反编译数据来源**：`dump.cs`（类型定义）和 `script.json`（方法 RVA 映射）。
    - **武器类继承链**：
      `WPN_Knife` → `Weapon` → `CFAnimator` → `Model` → `RecyclableObject`
    - **攻击类型枚举**：`WPN_Knife.KnifeAttackType`
      | 类型    | 值   | 说明       |
      | ------- | ---- | ---------- |
      | None    | 0    | 无攻击     |
      | Combo1  | 1    | 轻击第一段 |
      | Combo2  | 2    | 轻击第二段 |
      | Bigshot | 3    | 重击       |
    - **关键速度字段**：
      | 字段               | 所在结构                                        | 偏移        | 控制内容                       |
      | ------------------ | ----------------------------------------------- | ----------- | ------------------------------ |
      | `combo1_AnimSpeed` | `WPN_Knife` 实例                                | `0xEC`      | 轻击第一段动画速度（直接有效） |
      | `attackSpeed.x`    | `WeaponData_Knife` 对象（通过 `data` 指针访问） | `data+0xE8` | 轻击第一段备选（未单独使用）   |
      | `attackSpeed.y`    | 同上                                            | `data+0xEC` | 轻击第二段速度                 |
      | `attackSpeed.z`    | 同上                                            | `data+0xF0` | 重击速度                       |
    - **武器数据指针路径**：`WPN_Knife` 实例 → `+0x68` 读取 `data` 字段 → 指向 `WeaponData_Knife` 对象（内含 `attackSpeed` Vector3）。
    - **是否玩家武器判断**：游戏内置 `Weapon.get_isMyWeapon()`（RVA `0xB6E1D0`），可直接调用。
    
    
    
    ### V10：全背包支持
    - **改进**：使用 `Weapon.get_isMyWeapon()` 实时判断玩家武器，替代前两把缓存策略。
    - **效果**：所有背包（1-7 号）的刀均有效，无需缓存。
    
    ### V11：最终版本（当前）
    - **修复内容**：在 V10 基础上恢复对 `attackSpeed.y` 和 `attackSpeed.z` 的修改（通过 data 指针），但增加了严格的安全检查和合法值校验。
    - **结果**：轻击第一段、第二段、重击全部加速，全模式全背包通用，无卡顿，无需重新注入。

    ## 4. 关键问题与解决思路
    
    | 问题                 | 原因                                            | 解决方法                                                     |
    | -------------------- | ----------------------------------------------- | ------------------------------------------------------------ |
    | 轻击有效，重击无效   | 重击速度由 `attackSpeed.z` 控制，未修改         | 增加通过 data 指针修改 attackSpeed 各分量                    |
    | 特殊模式卡顿/无效    | data 指针指向非预期对象，定时器持续写入导致异常 | 移除定时器，仅 Hook 触发时写入；增加 data 指针和值的合法性验证 |
    | 退出房间后需重新注入 | 缓存了武器指针，旧指针失效                      | 使用 `get_isMyWeapon()` 实时判断，不缓存武器指针             |
    |                      |                                                 |                                                              |
    | 轻击第二段无效       | 未修改 `attackSpeed.y`                          | 在 `setAttackSegmentSpeeds` 中同时修改 y 分量                |
    | V9 注入失败          | 系统权限不足                                    | 管理员运行 Frida                                             |
    
    ---
    
    ## 5. 经验总结与后续开发建议
    
    1. **优先寻找通用字段**：`combo1_AnimSpeed` 这样的直接字段比通过指针间接访问更安全，且往往影响更广泛（。
    2. **定时器慎用**：高频定时器（16ms）极易造成性能问题，除非必要，尽量采用事件驱动的 Hook。
