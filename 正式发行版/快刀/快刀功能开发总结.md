# UnityCrossFire 快刀功能开发总结

## 项目概述

为 Unity IL2CPP 游戏 UnityCrossFire 实现"快刀"功能，通过 Frida 动态修改刀攻击动画速度，使轻击（Combo1）和重击（Bigshot）的出刀速度提升 3 倍。

**最终脚本**：`speed_knife_v5.js`
**游戏进程**：UnityCrossFire.exe
**核心 DLL**：GameAssembly.dll（IL2CPP 编译）

---

## 技术背景

### 游戏架构
- **引擎**：Unity IL2CPP
- **核心 DLL**：GameAssembly.dll
- **反编译工具**：Il2CppDumper
- **关键文件**：
  - `dump.cs`：C# 反编译代码，包含类定义、字段、方法签名和 RVA
  - `script.json`：方法名到绝对地址的映射

### 刀攻击类型
```csharp
enum WPN_Knife.KnifeAttackType {
    None = 0,
    Combo1 = 1,    // 轻击（第一次挥刀）
    Combo2 = 2,    // 轻击（连续挥刀）
    Bigshot = 3,   // 重击（蓄力挥刀）
    Other = 4
}
```

### 类继承链
```
WPN_Knife → Weapon → CFAnimator → MonoBehaviour → Component → ...
```

## 关键数据结构

### WPN_Knife 类字段
| 字段名 | 偏移 | 类型 | 说明 |
|--------|------|------|------|
| `combo1_AnimSpeed` | **0xEC** | float | 控制 Combo1 轻击动画速度 |

### Weapon 类字段
| 字段名 | 偏移 | 类型 | 说明 |
|--------|------|------|------|
| `data` | **0x68** | WeaponData* | 指向武器数据对象 |

### WeaponData_Knife 结构体
| 字段名 | 偏移 | 类型 | 说明 |
|--------|------|------|------|
| `knifeAttackAnimName` | 0xB8 | string | 攻击动画名 |
| `knifeHitSoundName` | 0xBC | string | 命中音效名 |
| `knifeAttacks` | 0xC0 | KnifeAttackData[] | 攻击数据数组 |
| `damageBodyRatio` | 0xC4 | DamageBodyRatio | 伤害身体比例 |
| `attackSpeed` | **0xE8** | Vector3 | 攻击速度（x=Combo1, y=Combo2, z=Bigshot） |

### attackSpeed 分量对应关系
- `attackSpeed.x`（偏移 0xE8）→ Combo1 轻击速度
- `attackSpeed.y`（偏移 0xEC）→ Combo2 轻击速度
- `attackSpeed.z`（偏移 **0xF0**）→ **Bigshot 重击速度**

---



**效果**：
- ✅ 轻击（Combo1）速度变快
- ❌ 重击（Bigshot）速度不变

### V5 - 双速度修改（最终成功版本）

**核心改进**：同时修改轻击和重击的速度控制字段

**实现细节**：

#### 1. 轻击速度修改
```javascript
function setCombo1Speed(weaponPtr) {
    var addr = weaponPtr.add(0xEC);  // combo1_AnimSpeed 偏移
    addr.writeFloat(3.0);
}
```

#### 2. 重击速度修改
```javascript
function setBigshotSpeed(weaponPtr) {
    // 步骤 1: 读取 Weapon.data 指针
    var dataPtrAddr = weaponPtr.add(0x68);
    var dataPtr = dataPtrAddr.readPointer();
    
    // 步骤 2: 修改 attackSpeed.z（WeaponData_Knife 偏移 0xF0）
    var attackSpeedZAddr = dataPtr.add(0xF0);
    attackSpeedZAddr.writeFloat(3.0);
}
```

#### 3. 内存访问路径
```
WPN_Knife 实例 (this)
    │
    ├─ 0xEC → combo1_AnimSpeed (float) ← 轻击速度
    │
    └─ 0x68 → data (WeaponData_Knife*)
                │
                └─ 0xF0 → attackSpeed.z (float) ← 重击速度
```

#### 4. 三重 Hook 保证覆盖
| Hook 函数 | RVA | 触发时机 |
|-----------|-----|----------|
| `OnSpecialBtnDown` | 0xB64240 | 玩家按下攻击键 |
| `PlayKnifeAttackAnim` | 0xB642B0 | 播放攻击动画前 |
| `AnimSpeedSetting` | 0xB63BD0 | 动画速度设置时 |
