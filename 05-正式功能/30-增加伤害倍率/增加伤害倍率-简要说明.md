## 默认行为

- 敌人倍率：`1.0x`（默认不动）。
- 自己倍率：`2.0x`（保持旧版“开启即强化自己输出”的手感）。
- 队友倍率：`1.0x`（默认不动）。
- 三个阵营可以各自单独开关；1.0x 表示原版，低于 1.0x 就是削弱。
- 倍率范围 `0.1x ~ 10.0x`，步进 0.1，**不允许 0**。

## 生效范围，说人话版

这个功能调整的不是“全场统一伤害”，而是**三个阵营各自的伤害**：

| 滑块 | 含义 |
| --- | --- |
| 敌人 | 敌人（含 Bot、怪物、生化攻击）打出来的伤害 |
| 自己 | 你打出来的伤害 |
| 队友 | 队友打出来的伤害 |

- 把敌人调到 0.2x：敌人几乎打不动你（也打不动你队友）。
- 把自己调到 3.0x：你一枪一个。
- 把队友调到 0.5x：队友输出被压住。
- 三个都保持 1.0x：等于什么都不改。

支持的伤害类型：

- 枪械伤害：支持。
- 近战 / 刀伤害：支持。
- 手雷 / 爆炸类伤害：支持。
- `Other` 类型特殊伤害：默认允许，比如部分英雄技能或特殊武器伤害，但不同武器需要实测确认。
- RPG、AT4、榴弹、炮台、机枪守卫这类“伤害源不是玩家本体”的情况：脚本会记录 owner，映射回真正的玩家后再判阵营。

不调整的情况：

- 找不到归属的伤害：不调整。
- 无效伤害、0 伤害、负数伤害：不调整。
- 不在 `Gun / Knife / Grenade / Other` 里的未知伤害类型：不调整。
- `Infect`（生化感染）：默认不参与，可配置放开。
- 自己打自己（例如自己的手雷炸自己）：默认跳过，避免调高自己倍率时把自己秒了。

## 阵营判定口径

与游戏自身的 `ExpandUtil.IsSameTeam` / `IsEnemy` 完全一致：

- `Entity.team`：`0` BlackList、`1` GlobalRisk、`2` Neutral。
- 同队 = 两边都不是 `2` 且相等；`Neutral(2)` 永远算敌对。
- 用 `Player.get_isMyPlayer` 找本地玩家；玩家列表来自 `GameManager.allPlayers / playersBL / playersGR`，缓存 2 秒。

## 核心原理

脚本 Hook `Entity.OnEntityHurt` 和 `Player.OnEntityHurt`，在 x86 cdecl 栈上定位按值传入的 `DamageEventData`，只修改 `damage` 字段：

| 字段 | 偏移 |
| --- | --- |
| `attacker` | `0x00` |
| `victim` | `0x04` |
| `damage` | `0x08` |
| `type` | `0x34` |
| `damageTag` | `0x38` |
| `wpnIndex` | `0x3C` |
| `wpnSprIndex` | `0x40` |
| `ignoreDmgRate` | `0x44` |

为避免 `Player.OnEntityHurt` 调用基类时重复修改，脚本在 Player 入口期间记录 `playerHurtDepth`，同一调用链内的 `Entity.OnEntityHurt` 只跳过不二次修改。

## 需要实测关注

- 机械英雄炮台：确认 `SentryGun.SetData` owner 映射能命中。
- RPG/AT4/榴弹枪：确认 missile owner 映射能命中。
- 生化模式：确认 `Neutral(2)` 阵营下敌人/队友的划分符合预期。
- GhostBlade、MasterHero、BoxingKing 等特殊武器：观察 `damageTag` 和 `DamageType.Other` 是否符合预期。
