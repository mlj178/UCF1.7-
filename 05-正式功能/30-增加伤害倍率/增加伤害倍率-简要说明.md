# 增加伤害倍率 - 简要说明

## 文件

| 文件 | 说明 |
| --- | --- |
| `AAAAA-damage_multiplier_min.js` | Frida 核心脚本 |
| `AAAAA-damage_multiplier_ui.py` | CustomTkinter 单功能 UI |
| `test_damage_multiplier_static.py` | 静态验证测试 |
| `伤害来源分类与倍率可行性.md` | 伤害来源分类和可行性研究 |

## 默认行为

- 默认倍率：`2.0x`。
- 默认只放大本地玩家造成的输出伤害。
- 默认跳过本地玩家作为受害者的事件，避免误伤自己。
- 默认跳过 `DamageType.Infect`，避免影响感染判定。
- 默认覆盖 `Gun`、`Knife`、`Grenade`，并允许 `Other` 类型特殊技能伤害。
- 默认启用导弹和炮台 owner 映射，用于 RPG、榴弹、手雷、机枪守卫等特殊来源。

## 核心原理

脚本 Hook `Entity.OnEntityHurt` 和 `Player.OnEntityHurt`，在 x86 cdecl 栈上定位按值传入的 `DamageEventData`，只修改 `damage` 字段：

| 字段 | 偏移 |
| --- | ---: |
| `attacker` | `0x00` |
| `victim` | `0x04` |
| `damage` | `0x08` |
| `type` | `0x34` |
| `damageTag` | `0x38` |
| `wpnIndex` | `0x3C` |
| `wpnSprIndex` | `0x40` |
| `ignoreDmgRate` | `0x44` |

为避免 `Player.OnEntityHurt` 调用基类时重复放大，脚本在 Player 入口期间记录 `playerHurtDepth`，同一调用链内的 `Entity.OnEntityHurt` 只跳过不二次修改。

## 需要实测关注

- 机械英雄炮台：确认 `SentryGun.SetData` owner 映射能命中。
- RPG/AT4/榴弹枪：确认 missile owner 映射能命中。
- GhostBlade、MasterHero、BoxingKing 等特殊武器：观察 `damageTag` 和 `DamageType.Other` 是否符合预期。
- 感染伤害暂不纳入倍率，后续如需要可做独立开关。
