# 25-人机暂停：当前实现说明

## 实现原理

通过修改 `Bot` 类的静态字段 `stopAllBot` 来控制所有人机的行动。

- `Bot.stopAllBot = true` → 所有人机暂停
- `Bot.stopAllBot = false` → 所有人机恢复

## 当前最小实现

已做成独立单功能脚本和 UI：

```text
AAAAA-bot_pause_min.js
AAAAA-bot_pause_ui.py
test_bot_pause_static.py
人机暂停-最小实现步骤.md
```

## 关键地址和偏移

| 项目 | 值 | 说明 |
| --- | --- | --- |
| Bot_TypeInfo | 0xE25F44 | `script.json` 中的 `Bot_TypeInfo` |
| Bot_c.static_fields | 0x5C | IL2CPP x86 类结构中的静态字段指针 |
| Bot.stopAllBot | 0xC | `Bot_StaticFields` 内的 bool 字段 |

实际读写路径：

```text
GameAssembly.dll base + 0xE25F44
  -> Bot_TypeInfo
  + 0x5C
  -> static_fields
  + 0xC
  -> stopAllBot
```

## 怎么运行

运行：

```powershell
python "05-正式功能\25-人机暂停\AAAAA-bot_pause_ui.py"
```

启动游戏后，UI 会自动 attach `UnityCrossFire.exe` 并加载 JS。打开开关会写入 `true`，关闭开关或退出 UI 会恢复 `false`。

## 当前边界

- 只控制所有 Bot，不区分敌方、队友或具体 Bot。
- 不整合进正式发行版，先作为独立单功能验证。
- 如果进入房间前 `static_fields` 尚未初始化，先进入有人机的模式后再切换开关。
