## 实现原理

最小版不重写背包逻辑，也不主动调用发武器函数。

它只做两件事：

1. Hook `Player.SelectWeaponBag(int index)`。
2. 在游戏原函数执行前，把 `WeaponBag.disabled` 和 `WeaponBag.tooFarFromSpawnPos` 写成 false。

这样后面仍然走游戏自己的流程：

```text
HUD_Bag.SelectBag
  -> Player.SelectWeaponBag
  -> GameManager.GiveWeaponByBag
```

## 修改字段

```text
Player.weaponBag                    offset 0xA4
WeaponBag.disabled                  offset 0x8
WeaponBag.tooFarFromSpawnPos        offset 0x14
HUD_Bag.bag                         offset 0x2C
```

`disabled` 和 `tooFarFromSpawnPos` 是 `ObscuredBool`，所以脚本用：

```text
ObscuredBool.Encrypt(false, key)
```

加密后写入 `hiddenValue`，同时设置：

```text
inited = 1
fakeValue = 0
fakeValueActive = 0
```

## Hook 点

```text
Player.SelectWeaponBag    RVA 0xB52830
HUD_Bag.Update            RVA 0xB00360
```

`HUD_Bag.Update` 是辅助保险：当 HUD 每帧刷新背包状态时，继续清掉距离限制和禁用状态。

## 运行方式

先启动游戏并进房间，然后运行：

```powershell
python "D:\trae_project\ucf1.7-modifier\05-正式功能\23-无限背包\launcher.py"
```

退出时按 `Ctrl+C`，启动器会调用 `cleanup()` 清理 Hook。

## 测试重点

进游戏后按这个顺序测：

1. 出生点附近打开背包，切 1、2、3 号背包。
2. 远离出生点后打开背包，再切背包。
3. 开枪时尝试打开背包和切背包。
4. 退出房间再进房间，确认不闪退。
5. 关闭脚本后，确认游戏还能正常操作。

## 当前边界

这版是最小实现，还没有整合进正式发行版。

如果远离出生点后还是打不开背包，说明限制可能在 UI 层，需要继续看：

```text
HUD_Bag.SetVisible
HUD_BagButton.OnPointerDown
PlayerController.get_FocusHUD
```

如果 `SelectWeaponBag return=false`，说明可能还有别的限制，需要继续看：

```text
WeaponBag.available
WeaponBag.weaponID
开枪状态相关字段
```
