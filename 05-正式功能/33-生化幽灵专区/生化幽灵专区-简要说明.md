# 33-生化幽灵专区

## 功能定位

这是方案 C 的 v1 单功能版本，作用范围是“本地玩家成为生化幽灵”后生效，不强化全场所有生化幽灵。

## v1 调节项

- 承伤倍率：本地幽灵作为受害者时修改最终伤害。
- 攻击倍率：本地幽灵作为攻击者时修改最终伤害。
- 移动倍率：Hook `PropertyModifier.Get`，仅拦截本地幽灵的移动速度倍率查询。
- 刀速倍率：Hook `PlayerWeapons.get_KnifeSpeed`，仅修改本地幽灵近战速度。
- 刀距倍率：Hook `WPN_Knife.GetKnifeAttackData`，仅修改本地幽灵近战范围。
- 技能无冷却：在本地幽灵 `Player.Update` 中周期调用 `Skill.EndCold`。
- 击退倍率：实验项。受击前后读取 `PlayerVelocity.velocity` 差值并按倍率缩放；倍率为 0 时会尝试临时启用 `Entity.isNoHitFeedback`。

## 文件

- `AAAAA-bio_ghost_boost_min.js`：Frida 最小脚本。
- `AAAAA-bio_ghost_boost_ui.py`：独立 CustomTkinter UI。
- `test_bio_ghost_boost_static.py`：静态结构测试。

## 测试建议

优先在生化房间内测试 `0.0x`、`0.5x`、`2.0x` 三档击退倍率，确认实际表现是否对应游戏里的击退而不是单纯受击硬直。

界面底部会显示 `本地玩家`、`幽灵命中`、`幽灵标记` 等诊断项：

- `本地玩家` 为 0：说明脚本还没有捕获到本地 Player。
- `本地玩家` 大于 0 但 `幽灵命中` 为 0：说明功能已启用，但生化幽灵过滤条件没有命中。
- `幽灵命中` 大于 0 后，各倍率命中计数才会开始增长。
