# 游戏模式切换-简要说明-整合版2.2

本文按 `全功能整合包2.2/game_modifier/features/27_game_mode_override/script.js` 的当前逻辑整理。

## 1. 总体规则

模式切换只在游戏房间开始流程中生效，不做对局中热切换。脚本会在 `MapAsset.ApplyGameSetting` 后覆盖 `GameManager.gameMode`、`GameManager.gameModePrefab`、`GameManager.weaponLimited`，并在开始按钮流程末尾同步胜利条件、时间、回合等规则字段。

UI 当前提供 7 个选项：团队竞技、刀战、生化4、生化6、生化4终结者、狙击战、手枪战。

## 2. 选项效果速查

| UI 选项 | 目标模式效果 | WeaponLimited | 胜利/结算规则 |
| --- | --- | ---: | --- |
| 团队竞技 | 强制切到团队竞技 `GameMode=0`，BL/GR 阵营 | 0 | 团队人头/限时规则，按房间下拉框读取 |
| 生化4（普通生化） | 强制切到普通生化 `GameMode=4` | 0 | 生化回合规则，目标回合数和时间按房间/静态配置读取 |
| 生化6（剑客模式） | 强制切到剑客模式 `GameMode=5` | 0 | 生化回合规则，目标回合数和时间按房间/静态配置读取 |
| 生化4终结者（多人生化） | 强制切到多人生化 `GameMode=6` | 0 | 生化回合规则，终结者时间优先读静态配置 |
| 刀战 | 武器限制模式，刀限制 | 1 | 个人/团队图保留原规则；生化图转团队人头规则 |
| 狙击战 | 武器限制模式，狙击限制 | 3 | 个人/团队图保留原规则；生化图转团队人头规则 |
| 手枪战 | 武器限制模式，手枪限制 | 2 | 个人/团队图保留原规则；生化图转团队人头规则 |

## 3. 源地图组合

| 源地图类型 | 选择团队竞技 | 选择生化4/生化6/多人生化 | 选择刀战/狙击战/手枪战 |
| --- | --- | --- | --- |
| 个人竞技图 | 转成团队竞技，bot 会重分 BL/GR，并借用中立出生点给 BL/GR | 转成对应生化规则；若缺中立出生点，会尝试借用 BL/GR 出生点 | 保留个人竞技规则，只改武器限制 |
| 团队竞技图 | 保持/转成团队竞技规则 | 转成对应生化规则；若缺中立出生点，会尝试借用 BL/GR 出生点 | 保留团队竞技规则，只改武器限制 |
| 生化类图 | 转成团队竞技规则 | 转成所选生化规则 | 转成团队竞技规则，再套刀/狙/手枪武器限制 |

生化类判断范围是 `GameMode=3..6`。虽然 UI 不提供生化3和个人竞技选项，但源地图仍可能是这些模式。

## 4. 胜利条件和时间

团队规则使用 `buildTeamRule`：

- 如果房间胜利类型是限时胜利，`targetScore=0`，时间从团队时间数组读取，兜底为 5/8/10/12 分钟。
- 如果房间胜利类型是击杀数胜利，`targetScore` 从团队击杀数组读取，兜底为 40/60/80/100/150；时间从团队静态击杀条件时间读取，兜底 20:00。
- 团队规则会写 `revengeEnable=1`、`targetRound=0`、`respawnTime=3.0`。

生化规则使用 `buildNanoRule`：

- `targetRound` 从生化回合数组读取，兜底为 9/11/13/15/17，默认偏向 13。
- `targetScore=0`，`revengeEnable=0`，`respawnTime=3.0`。
- 多人生化时间优先读终结者静态时间，兜底 3:30；普通生化/剑客时间优先读普通生化静态时间，兜底 2:30。

## 5. 静态配置/兜底值

脚本会优先读取游戏里的 `MapAsset` 静态配置；如果静态字段或数组读不到，就使用下面这些内置兜底值。

| 配置项 | 读取来源 | 兜底值 |
| --- | --- | --- |
| 团队限时胜利时间 | `TeamDeath.TimeDatas` | 5:00 / 8:00 / 10:00 / 12:00 |
| 团队击杀胜利人头 | `TeamDeath.KillDatas` | 40 / 60 / 80 / 100 / 150 |
| 团队击杀胜利时间 | `TeamDeath.KillConditionTime` | 20:00 |
| 生化目标回合 | `Nano.RoundDatas` | 9 / 11 / 13 / 15 / 17，默认索引用 13 |
| 普通生化/剑客单回合时间 | `Nano.GameTime_Nano4` | 2:30 |
| 多人生化/终结者单回合时间 | `Nano.GameTime_Nano4Terminator` | 3:30 |
| 团队/生化复活时间 | 写入 `ModeBase.respawnTime` | 3.0 秒 |
| 团队复仇开关 | 写入 `GameManager.revengeEnable` | 1 |
| 生化复仇开关 | 写入 `GameManager.revengeEnable` | 0 |
| 团队目标回合 | 写入 `ModeBase.targetRound` | 0 |
| 生化目标分数 | 写入 `ModeBase.targetScore` | 0 |

下拉框默认索引也有固定兜底：团队胜利类型默认按击杀胜利处理；击杀数默认取第 4 档，也就是 100 人头；限时胜利默认取第 1 档，也就是 5:00；生化回合默认取第 3 档，也就是 13 回合。

## 6. 武器和 bot 兼容

刀战、狙击战、手枪战会改 `GameManager.weaponLimited`。为了避免 bot 首次发枪仍拿到不符合限制的主武器，脚本保留 bot 发枪兜底：

| 限制模式 | bot 兜底武器索引 |
| --- | ---: |
| 刀战 | 244 |
| 狙击战 | 2568 |
| 手枪战 | 20 |

团队规则套到个人竞技图时，脚本会在 bot 生成后把 bot 交替分到 BL/GR，并在 `MapManager.Awake` / `GameManager.AddPlayers` / `GetSpawnPoint` 阶段处理出生点兜底。这个兜底只解决出生点数组缺失，不补地图专属机关、触发器或场景资源。

## 7. Hook 范围

2.2 整合版保留的是开局和出生/发枪相关 Hook：开始按钮、`MapAsset.ApplyGameSetting`、bot 生成、加玩家、`MapManager.Awake`、取出生点、发枪、Spawn/Respawn。未恢复 `ModeBase.OnStartNewGameRound`、生化回合、死亡事件等生命周期 Hook，目的是降低与 ESP 的冲突风险。
