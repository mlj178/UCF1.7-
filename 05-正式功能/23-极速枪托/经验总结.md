# 24-极速枪托：经验总结

## 这次功能做了什么

让带右键近战的枪械，右键枪托攻击更快。

这里的“枪托”指的是：

```text
WPN_Gun 的右键近战攻击
```

不是普通刀，也不是左键射击。

## 核心定位

先从 `dump.cs` 找 `WPN_Gun`，再去汇编里看右键特殊攻击。

最后确认关键链路是：

```text
WPN_Gun.OnSpecialBtnDown
  -> 播放 knife-attack 动画
  -> WPN_Gun.GetKnifeAttackData
  -> WeaponData_Gun.knifeAttacks
```

说明枪托攻击数据就在枪械自己的 `knifeAttacks` 里。

## 修改了什么

当前版主要做三件事：

```text
Animator.speed = 倍率
Hook WPN_Gun.KnifeAttackEvent
Hook WPN_Gun.OnAnimationExit
动画 tag 是 knifeAttack 时，只恢复 Animator.speed
```

作用：

```text
Animator.speed = 倍率
  让枪托动作播放更快。

KnifeAttackEvent
  这是枪托真正出伤害的事件。

OnAnimationExit
  这是原游戏的动画退出回调。

tag == knifeAttack 时恢复 Animator.speed
  只收尾我们改过的动画速度，不接管原游戏解锁。
```

默认倍率是 `4.0`。

之前的版本在右键入口就清 `knifeAttackAnim`，玩家点太快时可能出现：

```text
动作变快了
但还没走到伤害事件
下一次右键又重播动画
上一下伤害被取消
```

所以现在改成：

```text
不提前清锁
不手动清 knifeAttackAnim
KnifeAttackEvent 只记录伤害触发
OnAnimationExit 只恢复动画速度
OnKnifeAttackExit 继续由原游戏自己调用和清锁
```

## 没有修改什么

这版刻意不碰这些东西：

```text
不改伤害
不改攻击范围
不改普通左键射击
不改普通刀
不 replace 原函数
不重写游戏原逻辑
```

这样风险最小，方便先验证方向对不对。

## 运行方式

启动游戏后运行 UI：

```powershell
python "D:\trae_project\ucf1.7-modifier\05-正式功能\24-极速枪托\AAAAA-fast_gunstock_ui.py"
```

UI 会自动连接 `UnityCrossFire.exe`。

连接成功后：

```text
打开功能开关
用倍率滑块调整速度，默认 8x
```

## 游戏里怎么测

1. 找一把有右键枪托、刺刀、近战动作的枪。
2. 不开脚本，先右键几次，记住原速度。
3. 开脚本，再右键，观察动作是否明显变快。
4. 连续快速右键，看间隔是否缩短。
5. 换没有右键枪托的枪，确认不会乱触发。
6. 测普通左键射击，确认没有被影响。

## 如果效果不够

如果动作变快，但伤害频率没变快，说明伤害判定不完全跟动画速度走。

下一步查：

```text
WPN_Gun.KnifeAttackEvent
WPN_Gun.StartKnifeAttack
WPN_Gun.GetKnifeAttackData
```

如果 UI 里的“伤害”计数不增长，说明没有走到 `KnifeAttackEvent`，下一步再查动画事件绑定或 `StartKnifeAttack`。

## 复用经验

以后做类似功能，按这个顺序来：

```text
先找玩家操作入口
再找真实数据字段
再找状态锁字段
优先 Hook，不 replace
优先只改本地玩家
先写最小版验证方向
最后再考虑整合到正式发行版
```

一句话：

```text
先让功能小范围跑通，再逐步扩大，不要第一版就写成全功能大改。
```
