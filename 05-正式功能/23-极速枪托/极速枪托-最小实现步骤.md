# 24-极速枪托：最小实现步骤

## 目标

加快部分主武器、副武器的右键枪托攻击速度。

这里的“枪托”不是普通刀，也不是左键开火。

它指的是：

```text
WPN_Gun 这类枪械自带的右键近战攻击
```

例如一些枪械右键会用枪托、刺刀、近战动作攻击。

## 已确认的链路

右键枪托大概走这条链路：

```text
右键特殊攻击
  -> WPN_Gun.OnSpecialBtnDown
  -> 播放 knife-attack 动画
  -> WPN_Gun.GetKnifeAttackData
  -> 使用 WeaponData_Gun.knifeAttacks
```

关键点：

```text
WeaponData_Gun.knifeAttacks
```

说明枪械数据里本身就带一组近战攻击数据，所以这就是“枪托攻击”的来源。

## 关键 RVA

| 方法 | RVA | 作用 |
| --- | --- | --- |
| `WPN_Gun.OnSpecialBtnDown()` | `0xB629F0` | 右键枪托入口 |
| `WPN_Gun.GetKnifeAttackData(int attackIndex)` | `0xB61F90` | 获取枪托攻击数据 |
| `WPN_Gun.KnifeAttackEvent(int index)` | `0xB62730` | 枪托真正出伤害的事件 |
| `WPN_Gun.OnKnifeAttackExit()` | `0xB62990` | 枪托动画退出后清状态 |
| `WPN_Gun.OnAnimationExit(string animName, string animTag)` | `0xB62800` | 原游戏动画退出回调 |
| `Weapon.get_isMyWeapon()` | `0xB6E1D0` | 判断是不是本地玩家武器 |
| `CFAnimator.get_characterAnimator()` | `0xB35310` | 获取角色 Animator |
| `CFAnimator.get_handAnimator()` | `0xB35330` | 获取手部/武器 Animator |
| `UnityEngine.Animator.set_speed()` | `0xAA8C30` | 设置动画速度 |

## 关键字段

| 类 | 字段 | 偏移 | 说明 |
| --- | --- | --- | --- |
| `WPN_Gun` | `realData` | `0xEC` | 指向 `WeaponData_Gun` |
| `WeaponData_Gun` | `knifeAttacks` | `0x180` | 枪托攻击数据数组 |
| `WPN_Gun` | `knifeAttackCount` | `0x118` | 是否有枪托攻击 |
| `WPN_Gun` | `knifeAttackAnim` | `0x11C` | 枪托攻击动画锁 |

`WPN_Gun.OnSpecialBtnDown` 里会检查：

```text
knifeAttackCount > 0
knifeAttackAnim == 0
```

如果 `knifeAttackAnim != 0`，下一次右键枪托会被挡住。

## 最小方案

当前最小方案只做五件事：

1. Hook `WPN_Gun.OnSpecialBtnDown`。
2. 如果是本地玩家武器：
   - 设置角色 Animator 和手部 Animator 速度为高倍数。
3. Hook `WPN_Gun.KnifeAttackEvent`。
4. Hook `WPN_Gun.OnAnimationExit`。
5. 当 `animTag == knifeAttack` 时，恢复 `Animator.speed = 1.0`。

也就是说：

```text
不重写枪托攻击
不改伤害
不改普通射击
不 replace 原函数
不在右键入口提前清锁
不手动清 knifeAttackAnim
```

## 为什么这样做

枪托速度主要被两个东西卡住：

```text
动画速度
knifeAttackAnim 状态锁
```

动画慢，攻击节奏自然慢。

但是 `knifeAttackAnim` 不能太早清。

如果右键入口就清锁，玩家点太快时可能发生：

```text
第一次枪托还没走到伤害事件
第二次右键已经重新播放动画
第一次伤害被取消
```

所以现在改成：

```text
先让游戏原本的枪托攻击走到 KnifeAttackEvent
KnifeAttackEvent 只确认伤害已经触发
等原游戏 OnAnimationExit(tag=knifeAttack)
我们只恢复动画速度
OnAnimationExit -> OnKnifeAttackExit -> 清 knifeAttackAnim 由原游戏自己完成
```

## 运行方式

启动游戏后运行 UI：

```powershell
python "D:\trae_project\ucf1.7-modifier\05-正式功能\24-极速枪托\AAAAA-fast_gunstock_ui.py"
```

UI 会自动连接游戏。

连接成功后打开开关，并用滑块调整动作倍率。

默认倍率是 `4x`。

## 测试方式

进游戏后找一把带右键近战的主武器或副武器。

按这个顺序测：

1. 不开脚本，右键攻击，感受原始间隔。
2. 开脚本，右键攻击，观察动作是否明显变快。
3. 连续快速右键，观察是否能更快触发。
4. 换一把没有右键枪托的枪，确认不乱触发。
5. 切房间后再测一次。

## 如果失败

### 情况 A：右键没有任何日志

说明没有走 `WPN_Gun.OnSpecialBtnDown`。

继续查：

```text
WPN_RPG.OnSpecialBtnDown
WPN_GrenadeGun.OnSpecialBtnDown
Weapon.OnSpecialBtnDown
PlayerController.SkillButton
```

### 情况 B：日志有，但速度没变化

优先查：

```text
Animator.set_speed 是否成功
是否还需要设置 CharacterModel.PlayWpnAnim 的 duration
是否需要 Hook CFAnimator.PlayWeaponAnim
```

### 情况 C：动作变快，但伤害没变快

说明伤害判定不跟动画速度走。

先看 UI 里的“伤害”计数。

如果“伤害”计数不增长，继续看：

```text
WPN_Gun.KnifeAttackEvent
WPN_Gun.StartKnifeAttack
WPN_Gun.GetKnifeAttackData
```
