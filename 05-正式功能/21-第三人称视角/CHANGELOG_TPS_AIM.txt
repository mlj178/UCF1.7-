第三人称瞄准功能变更日志
===========================

版本: v1.2 (关键修复版)
日期: 2026-06-22
目标: 修复关键问题，确保子弹从枪口射向准星

一、修复关键问题
------------------

### 1. AimIK 对象取错，完全关闭

✅ 修复: 完全关闭所有 AimIK 相关代码
   - 位置: Line 966-973, 1223-1233, 3312-3314, 1974-2032
   - 问题: Player.recoil 是游戏的射击 Recoil (MonoBehaviour)，不是 FinalIK.Recoil
   - 影响: AimIK 路径错误，存在崩溃风险
   - 修复: 注释掉所有 AimIK 相关函数和调用

### 2. 射击 Hook 安装位置错误

✅ 修复: 将 installShootHooks() 移到 installhook() 中
   - 位置: Line 3566
   - 问题: 只在启动"瞄准诊断"后才安装，正常开启第三人称时不修改子弹
   - 影响: 子弹不会被校正
   - 修复: 在 installhook() 中安装射击 Hook

### 3. 枪口缓存比较错误

✅ 修复: 使用 equals() 比较 NativePointer
   - 位置: Line 1751-1756
   - 问题: 使用 === 比较 NativePointer，每次都返回 false
   - 影响: 每100ms重新解析 QVModel，造成卡顿
   - 修复: 使用 inUse.equals(muzzleCache.weaponPtr)

### 4. bindWpn 校验未使用

✅ 修复: 如果 bindWpn 不匹配当前武器，返回未找到
   - 位置: Line 1783-1790
   - 问题: weaponMatches 计算后未使用，换枪过程中可能使用上一把枪的枪口
   - 影响: 枪口定位不准确
   - 修复: 添加校验逻辑，不匹配时返回空缓存

### 5. 左右模型选择错误

✅ 修复: 检查哪一侧模型实际激活
   - 位置: Line 1801-1820
   - 问题: 永远优先选择右侧，可能选中隐藏模型的 GunFire
   - 影响: 枪口定位不准确
   - 修复: 添加 isTransformActive() 检查，优先选择激活的一侧

### 6. WPN_Gun.gunFire 回退缺失

✅ 修复: 添加 WPN_Gun.gunFire +0x114 回退
   - 位置: Line 1845-1868
   - 问题: QVModel 为空时直接结束，不尝试当前 Weapon 的 GunFire
   - 影响: 某些武器无法定位枪口
   - 修复: 添加回退逻辑，从 WPN_Gun.gunFire 获取枪口

### 7. Physics.Raycast 调用约定未验证

✅ 修复: 更新 RaycastHit 布局注释，修正 distance 偏移
   - 位置: Line 2335-2369
   - 问题: distance 偏移错误 (0x30 应为 0x1C)
   - 影响: 距离数据不准确
   - 修复: 更新 distance 偏移为 0x1C，添加 TODO 注释说明 Ray ABI 待验证

版本: v1.1 (修复版)
日期: 2026-06-22
目标: 修复阻断性错误

一、修复阻断性错误
------------------

### 1. Component.get_transform 地址错误

✅ 修复: RVA 从 0x3F2D80 改为 0x032CF40
   - 位置: Line 117
   - 影响: 相机 Transform、武器 Transform、枪口 Transform 全部获取失败
   - 原因: 变更日志错误记录为"已验证"，实际地址错误

### 2. callPhysicsRaycast() 参数错误

✅ 修复: 传递完整 Ray 对象，而不是 origin/direction 分开传递
   - 位置: Line 1867, 1897-1905
   - 影响: Raycast 调用失败，aimPoint 使用相机远点而不是真实命中点
   - 修复前: callPhysicsRaycast(cameraRay.origin, cameraRay.direction, maxDist)
   - 修复后: callPhysicsRaycast(cameraRay, maxDist)

### 3. QVModel.left/right 读取错误

✅ 修复: QVModel.left/right 是内联结构体，不是指针
   - 位置: Line 1750-1755
   - 影响: 枪口定位全部错位
   - 修复前: qvModel.add(OFF.QV_left).readPointer()
   - 修复后: qvModel.add(OFF.QV_left) (直接使用地址)

### 4. GunFire Transform 未真正使用

✅ 修复: 优先使用 GunFire Transform 作为枪口
   - 位置: Line 1685-1701
   - 影响: 只依赖名称搜索，GunFire 被读取但未使用
   - 修复: 添加 componentGetTransform(gunFire, ptr(0)) 并优先返回

### 5. 武器过滤缺失

✅ 修复: GetShootRay 只允许 localPlayer.recoil
   - 位置: Line 3100-3115
   - 影响: 可能修改敌人、机器人、其他玩家的射击
   - 修复: 添加 localRecoil 检查，比较 this._thisPtr.equals(localRecoil)

### 6. 相机 SphereCast 未验证

✅ 修复: 暂时关闭相机碰撞检测
   - 位置: Line 1225-1228
   - 影响: SphereCast ABI 未验证，可能引入崩溃
   - 修复: 注释掉 checkCameraCollision() 调用

### 7. 字符串读取偏移错误

✅ 修复: 使用32位 IL2CPP 字符串偏移和 UTF-16 编码
   - 位置: Line 452-459
   - 影响: muzzle/fire/barrel 等节点名称无法正确读取
   - 修复前: len=0x10, chars=0x14, readUtf8String
   - 修复后: len=0x08, chars=0x0C, readUtf16String

### 8. List 数组元素读取错误

✅ 修复: Il2CppArray 元素从 +0x10 开始
   - 位置: Line 477, 596, 616, 670, 697, 1022, 1042, 1265, 1283
   - 影响: PV/CV、GameObject 列表读取错误
   - 修复前: itemsPtr.add(i * PTR_SIZE)
   - 修复后: itemsPtr.add(0x10 + i * PTR_SIZE)
