射击调用链分析
==============

来源: IDA汇编 + dump.cs

一、调用关系图 (IDA)
-------------------

  WPN_Gun$$GunShoot
    -> WPN_Gun$$GunShoot_NoCheck
         -> WPN_Gun$$GunShootFunction
              -> Recoil$$GetShootRay (返回 Ray)
              -> WPN_Gun$$GunShoot_Logic
                   -> WPN_Gun$$Damage (接收 Ray)
                   -> WPN_Gun$$GenerateBullet
                   -> WPN_Gun$$PlayGunFire (未确认)

二、函数 RVA (IDA)
-----------------

  Recoil.GetShootRay: 0x0B195C0 (il2cpp:10B195C0)
  WPN_Gun.Damage: 0x0B613D0 (il2cpp:10B613D0)
  WPN_Gun.GunShoot: 0x0B624C0 (il2cpp:10B624C0)
  WPN_Gun.GunShoot_Logic: 0x0B62170 (il2cpp:10B62170)
  WPN_Gun.GunShootFunction: 0x0B62110 (il2cpp:10B62110)
  WPN_Gun.GenerateBullet: 0x0B61F40 (il2cpp:10B61F40)

三、GetShootRay ABI (IDA)
------------------------

  签名: UnityEngine_Ray_o __cdecl Recoil__GetShootRay(Recoil_o*, MethodInfo*)
  调用方 (GunShootFunction):
    push 0 (method)
    push eax (this=Recoil*)
    lea eax, [ebp+var_18] (retBuf)
    push eax (retBuf)
    call Recoil$$GetShootRay
    add esp, 0Ch

四、Damage Ray 栈布局 (IDA)
--------------------------

  [ebp+08] = this (WPN_Gun*)
  [ebp+0C] = ray.origin.x
  [ebp+10] = ray.origin.y
  [ebp+14] = ray.origin.z
  [ebp+18] = ray.direction.x
  [ebp+1C] = ray.direction.y
  [ebp+20] = ray.direction.z
  [ebp+24] = MethodInfo*

五、结论
--------

✅ 已验证:
  1. GetShootRay 返回值通过隐藏 retBuf 传递
  2. Damage 接收 inline Ray (栈内联，24 bytes)
  3. GunShootFunction 调用 GetShootRay 后获取 Ray

⚠️ 高概率但未运行验证:
  1. Damage 和 GenerateBullet 可能共用同一条 Ray
  2. 修改 GetShootRay retBuf 可能同时修正伤害和视觉弹道

❌ 仍然缺失:
  1. GenerateBullet 的参数未确认
  2. PlayGunFire 的 RVA 未确认
  3. 弹痕/曳光/枪口特效的调用链未确认
