GetShootRay ABI 确认
====================

函数: Recoil.GetShootRay
RVA: 0x0B195C0
IDA: il2cpp:10B195C0

IDA 签名:
  UnityEngine_Ray_o __cdecl Recoil__GetShootRay(Recoil_o *this, const MethodInfo *method)

IDA 栈帧定义:
  var_14 = byte ptr -14h
  arg_4 = dword ptr 0Ch

关键汇编:
  mov esi, [ebp+arg_4]  ; esi = this (Recoil*)
  push 0                ; method = 0
  push esi              ; this (Component.get_transform的this)
  call UnityEngine_Component$$get_transform

调用方 (WPN_Gun$$GunShootFunction, 0xB62110):
  push 0                ; method
  push eax              ; this (Recoil*)
  lea eax, [ebp+var_18] ; retBuf = local buffer (24 bytes)
  push eax              ; retBuf (最先压栈!)
  call Recoil$$GetShootRay
  add esp, 0Ch          ; 清理3个参数 (12 bytes)

结论 - 32位 __cdecl 参数顺序:
  [ebp+08] = this (Recoil*)
  [ebp+0C] = MethodInfo*

但调用方压栈顺序（从右到左）:
  push MethodInfo* (0)
  push this (Recoil*)
  push retBuf (Ray* 返回缓冲区, 最先压栈)

Frida Interceptor.attach onEnter:
  args[0] = [ebp+08] = this (Recoil*)
  args[1] = [ebp+0C] = MethodInfo*

Ray 返回缓冲区读取:
  在调用方处，retBuf是局部变量 [ebp+var_18]
  在 GetShootRay 函数内，Ray 数据被写入 [ebp+var_14] (var_14 = -0x14 = 20 bytes)
  注意: var_14只有20 bytes? 可能是IDA分析不完整，Ray应为24 bytes

Ray 布局:
  origin.x    +0x00
  origin.y    +0x04
  origin.z    +0x08
  direction.x +0x0C
  direction.y +0x10
  direction.z +0x14
  total size: 24 bytes

读取示例 (在调用方 Hook 中):
  onEnter: function(args) {
    var retBuf = this.context.esp.add(4).readPointer(); // 第一个压栈参数
    var thisPtr = args[0]; // [ebp+08]
    var methodInfo = args[1]; // [ebp+0C]
  }
