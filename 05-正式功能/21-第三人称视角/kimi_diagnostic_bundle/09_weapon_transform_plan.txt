武器Transform枚举方案
=====================

当前状态: 未运行时枚举，提供可靠方案供Codex实现

1. 从WPN_Gun/Weapon获取Transform的路径
   方案A: 使用Component.get_transform
     - Weapon继承CFAnimator，CFAnimator继承Model，Model继承RecyclableObject
     - Model继承UnityEngine.Component
     - 所以Weapon对象可以直接调用Component.get_transform
     - 函数: Component.get_transform (RVA: 0x032CF40)
     - 签名: Transform* get_transform(Component* this, MethodInfo*)

   方案B: 通过GameObject获取Transform
     - 如果方案A失败，尝试:
     - 获取Component的gameObject字段（UnityEngine.Component.gameObject）
     - 然后调用GameObject.get_transform
     - 但gameObject字段偏移未确认，不推荐直接使用

2. Transform递归枚举方案
   函数: Transform.GetChild (RVA: 0x03F3150)
   签名: Transform* GetChild(Transform* this, int index, MethodInfo*)
   函数: Transform.get_childCount (RVA: 0x03F3E80)
   签名: int get_childCount(Transform* this, MethodInfo*)

   枚举逻辑:
     function enumTransform(transform, depth) {
       if (depth > 6) return;
       var count = getChildCount(transform, 0);
       for (var i = 0; i < count; i++) {
         var child = getChild(transform, i, 0);
         var name = Object_get_name(child, 0);
         // 检查名称关键词
       }
     }

3. 节点名称关键词评分
   精确匹配(10分): muzzle, firePoint, fire_point, shotPoint, shot_point, bulletPoint, barrelEnd
   模糊匹配(5分): 包含 muzzle/fire/shot/bullet/barrel/weaponRoot
   可疑(2分): rightHand, leftHand, hand, spine

4. 区分第一人称与第三人称武器
   第一人称武器特征:
     - 通常作为Camera或PlayerCameraManager的子节点
     - 模型细节高，有手臂模型
   第三人称武器特征:
     - 作为CharacterModel的子节点（在角色手中）
     - 模型简化

5. 禁止使用的未验证偏移
   - weapon+0x10 = GameObject (未确认)
   - GameObject+0x30 = Transform (未确认)
   - 任何未经IDA或dump.cs验证的硬编码偏移

6. 推荐实现顺序
   1. 从Player获取当前Weapon
   2. 调用Component.get_transform(weapon)获取Transform
   3. 递归枚举所有子节点
   4. 根据名称评分找muzzle候选
   5. 验证候选节点的forward方向
