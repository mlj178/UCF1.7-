Codex 交接摘要（合并版）
======================

来源: codex_diagnostic_bundle + kimi_diagnostic_bundle 合并（以 codex 为准）

一、已验证关键信息
-----------------

1. QVModel 结构体: left(0x44), right(0x7C), 大小0x38
2. QVModel.Data: Model(0x0), GunFire(0x34)
3. CharacterModel.bindQvMdl(0xB4) -> QVModel
4. Recoil.aimIK(0x18) -> AimIK.solver(0x1C) -> IKSolverAim
5. IKSolverAim.IKPosition(0x8) 可设置目标点
6. GetShootRay/Damage 的 ABI 已确认
7. Camera.ScreenPointToRay_Injected 参数已确认
8. Physics.Raycast 参数已确认

二、实现路线图
-------------

### Phase 1: 修复现有错误
- Component.get_transform 调用顺序
- Injected 函数调用顺序（32位 ABI）
- 32位 List 布局
- bool 参数类型

### Phase 2: 定位第三人称枪口
- 从 CharacterModel 读取 bindQvMdl -> QVModel
- 从 QVModel 读取 left/right Data -> GunFire/Model
- 枚举 GunFire/Model 的子节点找枪口
- 缓存枪口 Transform，避免每帧查找

### Phase 3: 实现两段式射击 Ray
- 使用 Camera.ScreenPointToRay_Injected 获取准星射线
- 使用 Physics.Raycast 获取准星命中点
- 从枪口位置向准星命中点构造射击 Ray
- 修改 GetShootRay retBuf 使 Ray 对准枪口方向

### Phase 4: 角色和武器视觉瞄准
- 通过 AimIK 设置 IKPosition 指向准星目标
- 设置 IKPositionWeight = 1.0
- 在主循环中更新 AimIK 目标点

### Phase 5: 相机碰撞
- 使用 Physics.SphereCast 检测相机碰撞
- 调整相机距离避免穿墙

### Phase 6: 状态和恢复
- Hook Player.OnEntityDeath/SetWeapon/Respawn/Spawn
- 事件发生时清空枪口缓存
- 禁用时恢复所有修改

三、禁止事项
-----------

- 不要假设 weapon+0x10=GameObject
- 不要把 64位 ABI 用在 32位进程上
- 不要根据旧注释认定地址正确
- 不要猜测未验证的字段偏移
- 不要在脚本加载时就安装 Hook

四、下一步建议
-------------

1. 运行时枚举武器子节点，确认枪口位置
2. 运行时验证 AimIK 是否挂载
3. 运行时验证 32位 List<T> 布局
4. 运行时验证 Physics.Raycast 参数传递
5. 检查 CinemachineCollider 是否存在
