重点检查项（来自 IDA 验证）：
  - PlayerCameraManager.set_modelVisible: IDA 签名 = void(this, bool, MethodInfo*)
    JS 当前声明: void(pointer, bool) -> 缺少 MethodInfo*
    修复: new NativeFunction(base.add(RVA), "void", ["pointer", "bool", "pointer"])

  - PlayerData.SetObserveMode: IDA 签名 = void(this, int32_t, MethodInfo*)
    JS 当前声明: void(pointer, int) -> 可能缺少 MethodInfo*

  - Model.OnOwnerObserveModeChange: IDA 签名 = void(this, int32_t, MethodInfo*)
    JS 当前声明: void(pointer, int) -> 可能缺少 MethodInfo*

  - Model.SetModelLayer: IDA 签名 = void(this, int32_t, int32_t, MethodInfo*)
    JS 当前声明: void(pointer, int, int) -> 可能缺少 MethodInfo*

  - Weapon.SynchronizeHand: IDA 签名 = void(this, MethodInfo*)
    JS 当前声明: void(pointer) -> 可能缺少 MethodInfo*

  - Singleton_GetInstance: 签名 pointer(pointer)
    问题: 传入的是 MethodInfo* 地址，需确认是地址本身还是地址中的指针
