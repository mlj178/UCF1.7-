## 一、总览：GUN 与 RPG 是两条完全不同的路径

| 武器 | 换弹入口 | 谁决定换弹时长 | 本功能的做法 |
|---|---|---|---|
| WPN_Gun 系 | WPN_Gun.Reload(0xB62CB0) | 每次换弹算 GetAnimSpeed(reloadAnimRatio) × PlayerWeapons.ReloadSpeed，写进 Animator 的 "ReloadSpeed" 参数 | 在 CFAnimator.SetFloat 里把该参数乘倍率 |
| WPN_RPG | WPN_RPG.OnReloadBtnDown(0xB67AF0) | 只播放 "reload" 动画，**不写 "ReloadSpeed"**；该参数只在 Deploy 时由 AnimSpeedSetting(0xB66CA0) 写一次，且 RPG 的换弹动画不吃它 | 换弹前把武器/手部 Animator.speed 设为倍率，动画结束复位 1.0 |

两类武器的换弹结束都是「reload 动画播完」事件（WPN_Gun.OnAnimationEnd → ReloadOver()、
WPN_RPG.OnAnimationEnd → AmmoData.Reload()），所以只要缩短动画，补弹就会同步提前。

## 二、RPG / AT4 最初没效果的三层原因（2026-11-08 定位）

1. **入口找错**：WPN_RPG.Reload(0xB67C40) 是死代码 —— 全 DLL 没有任何 call 指向它
   （OnReloadBtnDown 把同样的逻辑内联了）。v2 早期把"刷新 RPG 参数"的钩子挂在 0xB67C40 上，
   等于没挂。（2.8 的 01_ammo 也把 RPG 弹匣维护挂在同一个死函数上，属于同一个坑。）
2. **参数无效**：RPG 的换弹动画由 OnReloadBtnDown 直接播放，过程中不写 "ReloadSpeed"；
   该参数只在 Deploy 的 AnimSpeedSetting 里写一次。实测乘这个参数对 RPG 掉血无效。
3. **日志被吞**：2.8 的日志辅助函数每个模块只放行 10 条消息。
   实测日志里 15:28:44~46 的 3 条「换弹动画速度 1.00 → 5.00」把额度用完（第 10 条带「已达上限」标记），
   之后 15:28:47 才换上的 AT4 全程没有任何快速换弹日志 —— 所以"从日志看不出问题"本身就是个坑。
   现在诊断日志改走 send({type:'log_file'}) 通道，不受上限影响。

## 三、当前实现细节

### GUN（参数路径）
- Interceptor.replace(CFAnimator.SetFloat @0xB34E40)。
- 命中条件：参数名 == "ReloadSpeed" && Weapon.get_isMyWeapon(self) && 不是 RPG。
- 动作：value ×= 倍率，再交给原实现；只对本地玩家，bot / 其他玩家不受影响。

### RPG（动画器速度路径）
- Interceptor.attach(WPN_RPG.OnReloadBtnDown @0xB67AF0) onEnter：
  本地玩家 + 是 RPG → 把 weapon.animator(CFAnimator+0x40) 与
  owner.characterModel.handAnimator(+0x5C→+0x4C) 的 Animator.speed 设为倍率。
- 复位时机：WPN_RPG.OnAnimationEnd(0xB67640) 且 tag == "reload"；WPN_RPG.Deploy(0xB67030)；
  关闭功能；另加 5s 看门狗（换弹被切枪/死亡打断时兜底）。
- 游戏自己的 CFAnimator.AnimatorInit 每次 Deploy 也会把这两个 Animator.speed 复位成 1.0，
  是天然的第二道保险。
- RPG 在参数路径里被显式跳过，避免"参数 × 动画器速度"叠成平方。

### RPG 判定
Weapon.data(+0x68) 与 WPN_RPG.realData(+0xF0) 指向同一个 WD_RPG 实例；
WPN_Gun 的 +0xF0 是 bool（isSemiGun），不会是有效指针，因此不会误判。

## 四、游戏原生「快速换弹」BUFF 的底层逻辑（多人生化 · 人类）

    Mode_Nano4_Terminator.AddPropertyModifier(Player)  @0xB42930
      wpns.Modifier_ReloadSpeed.modifier =
          Delegate.Combine(existing, new CustomEvent_PlayerRefFloat(this, RapidReload))
      （另外三条：KnifeRange→NailExtraRange、KnifeSpeed→HotKnifeSpeed、MoveSpeedRatio→MoveSpeedModifier）

    Mode_Nano4_Terminator.RapidReload(Player, ref float speed)  @0xB45270
      if (player.playerData.nanoRole.value != 0) return;   // 只有人类(0)
      if (this.attribute_Human.id != 15) return;           // 人类特性 id 15 = 快速换弹
      speed *= 2.5f;                                       // 常量 @0x10B99D74

- 它乘的仍然是 PlayerWeapons.ReloadSpeed，只影响 GUN 那条链，**原生 BUFF 对 RPG 同样无效**。
- 特性 ID 读取方式与 2.8 的 15_nano4t 一致：mode+0xE4(attribute_Human) → +0x0C(id)。
- 不直接搬它的原因：要伪造 Il2CppDelegate 才能进委托链，版本敏感；且解决不了 RPG。

## 五、关键地址（GameAssembly.dll，RVA）

| RVA | 符号 | 用途 |
|---|---|---|
| 0xB34E40 | CFAnimator.SetFloat(this, name, value, character, method) | GUN 落点 |
| 0xB6E1D0 | Weapon.get_isMyWeapon(this) | 只处理本地玩家 |
| 0xB67AF0 | WPN_RPG.OnReloadBtnDown(this) | **RPG 换弹真实入口** |
| 0xB67640 | WPN_RPG.OnAnimationEnd(this, animName, animTag) | 换弹结束复位 |
| 0xB67030 | WPN_RPG.Deploy(this) | 重部署复位 |
| 0xAA8C30 | UnityEngine.Animator.set_speed(animator, value, method) | 改动画器速度 |
| 0xB62CB0 | WPN_Gun.Reload | GUN 换弹入口（内部写 ReloadSpeed） |
| 0xB66CA0 | WPN_RPG.AnimSpeedSetting | RPG 参数写入点（只在 Deploy 调用） |
| 0xB67C40 | WPN_RPG.Reload | **死代码，无调用点，勿再挂钩子** |
| 0xB45270 | Mode_Nano4_Terminator.RapidReload | 原生 BUFF（×2.5，仅 GUN 链） |

字段：Weapon.owner +0x30、Weapon.data +0x68、CFAnimator.animator +0x40、
WPN_RPG.realData +0xF0、Player.characterModel +0x5C → handAnimator +0x4C、
WeaponData_Gun.reloadAnimRatio +0xD4、WD_RPG.reloadAnimRate +0xEC。

## 六、覆盖范围与限制

- 模式：无限制（函数级 Hook，与模式无关）。
- 武器：WPN_Gun 系（步枪/冲锋枪/狙击/手枪/霰弹/榴弹枪）+ WPN_RPG（火箭筒 / AT4 / Nano AT4）。
  投掷（WPN_Throw）、一次性武器（WPN_Disposable）、哨戒炮（WPN_SentryGun）、近战（WPN_Knife）
  没有换弹动画，天然不涉及。
- 仅本地玩家：bot / 其他玩家不变速。
- 叠加：多人生化人类 BUFF「快速换弹」(id 15) 是 ReloadSpeed ×2.5，只作用在 GUN；
  RPG 不受该 BUFF 影响，最终倍率就是滑块值。

## 七、验证步骤

1. 连接游戏 → 开关打开 → 日志（log_file 通道）出现
   「已启用 — 4.0x（GUN=动画参数 / RPG=动画器速度）」。
2. 步枪换弹 → 「GUN 换弹动画速度 1.00 → 4.00（4.0x）」。
3. 拿 AT4/RPG 换弹 → 「RPG 换弹加速 ×4.0（动画器速度，共 2 个 animator）」，
   同时换弹动作与补弹都应明显变快；换弹结束后武器后续动作恢复正常速度（不会一直加速）。
4. 拖滑块改倍率 → 下一次换弹立即按新倍率；1.0 = 原速。
5. 切枪打断 RPG 换弹 → 5 秒内速度自动复位；再部署也会复位（AnimatorInit）。
6. 关闭功能 → 换弹恢复原速（Interceptor.revert + 动画器 speed 复位 1.0）。
