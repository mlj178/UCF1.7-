# 快速换弹经验总结

## 快速换弹实现方案

### 实现原理
通过 Hook `PlayerWeapons.get_ReloadSpeed()` 函数，为本地玩家返回加速后的换弹速度值。

### 关键信息
- **Hook 地址**: `PlayerWeapons.get_ReloadSpeed` (RVA 0xB170E0)
- **玩家判断**: 使用 `Player.get_isMyPlayer()` (RVA 0xB55FD0) 判断是否为本地玩家
- **字段偏移**: `PlayerWeapons.Modifier_ReloadSpeed` (偏移 0x3C)
- **默认倍数**: 2.0x（可根据需要调整）

### 实现步骤
1. 获取 `GameAssembly.dll` 基址
2. 定位 `get_ReloadSpeed` 函数地址
3. 使用 `Interceptor.replace` 替换函数实现
4. 在替换函数中判断是否为本地玩家
5. 为本地玩家返回加速后的换弹速度

### 代码示例
```javascript
Interceptor.replace(getReloadSpeedAddr, new NativeCallback(function(self) {
    try {
        var owner = self.add(0x8).readPointer();
        if (!owner || owner.isNull()) {
            return RELOAD_SPEED_MULTIPLIER;
        }
        
        if (isMyPlayer(owner)) {
            return RELOAD_SPEED_MULTIPLIER;  // 快速换弹
        }
        
        return 1.0;  // 默认速度
    } catch(e) {
        return RELOAD_SPEED_MULTIPLIER;
    }
}, "float", ["pointer"]));
```

### 注意事项
- 该方案全模式通用，不依赖特定游戏模式
- 只对本地玩家生效，不影响其他玩家
- 换弹速度倍数可根据实际需求调整
- 建议倍数范围：1.5x ~ 4.0x

### 删除原因
**无限弹匣功能调用的 `get_isInfinityAmmo()` 方法仅控制 UI 显示效果，实际无效。**

#### 技术分析
1. **UI 效果而非实际功能**
   - `get_isInfinityAmmo()` 仅被 UI 系统（HUD）调用，用于显示无限符号
   - 武器射击逻辑（`WPN_Gun`）**不调用**该函数，直接操作 `AmmoData.clip` 字段
   - Hook 该函数只会改变 UI 显示，不会影响实际弹药消耗

2. **实测验证失败**
   - 经过实际测试，Hook `get_isInfinityAmmo()` 返回 `true` 后：
     - UI 显示无限符号 ✓
     - 实际弹匣仍会打空 ✗
     - 打空后无法继续射击 ✗

3. **真正的无限弹匣需要其他方案**
   - 方案一：定时锁定 `AmmoData.clip` 字段（需要找到准确的偏移）
   - 方案二：调用原生 `InfinityAmmoBuff` 系统（逆向量大）
   - 当前脚本未实现这些方案，因此删除无效的 UI Hook
