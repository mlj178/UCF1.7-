### 两种换弹加快实现方式对比

------

#### 一、`speed_gun_universal 换弹加快.js` 实现方式

**核心机制**：修改**武器数据类**的装填动画速度比例

| 属性         | 值                                 |
| ------------ | ---------------------------------- |
| **目标类**   | `WeaponData_Gun`                   |
| **目标字段** | `reloadAnimRatio`（偏移 `0xD4`）   |
| **修改方式** | Hook `GunShoot_NoCheck` 时写入内存 |
| **加速倍数** | 5.0 倍                             |

**关键代码**（第116-122行）：

```javascript
// 获取 realData (WeaponData_Gun*)
var realData = self.add(0xEC).readPointer();
if (!realData.isNull()) {
    // 修改 reloadAnimRatio (0xD4) - 装填动画速度比例
    var reloadAnimRatioPtr = realData.add(0xD4);
    var currentReloadRatio = reloadAnimRatioPtr.readFloat();
    if (currentReloadRatio > 0 && currentReloadRatio < 100) {
        reloadAnimRatioPtr.writeFloat(5.0);  // 设为5倍速
    }
}
```

**实现原理**：

- 每次射击时（`GunShoot_NoCheck` 被调用）检查武器实例
- 找到 `WPN_Gun.realData`（指向 `WeaponData_Gun`）
- 直接修改内存中的 `reloadAnimRatio` 字段
- **影响范围**：仅当前持有的武器

------

#### 二、`AAAAA-infinite_ammo_rapid_reload_test.js` 实现方式

**核心机制**：Hook **玩家武器管理器**的属性 getter 方法

| 属性         | 值                                  |
| ------------ | ----------------------------------- |
| **目标类**   | `PlayerWeapons`                     |
| **目标函数** | `get_ReloadSpeed()`（RVA 0xB170E0） |
| **修改方式** | 替换整个函数返回值                  |
| **加速倍数** | 2.0 倍（可配置）                    |

**关键代码**（第58-80行）：

```javascript
Interceptor.replace(getReloadSpeedAddr, new NativeCallback(function(self) {
    try {
        // PlayerWeapons + 0x8 = owner (Player)
        var owner = self.add(0x8).readPointer();
        if (!owner || owner.isNull()) {
            return RELOAD_SPEED_MULTIPLIER;
        }
        // 判断是否是本地玩家
        if (isMyPlayer(owner)) {
            return RELOAD_SPEED_MULTIPLIER;  // 快速换弹
        }
        return 1.0;  // 非本地玩家返回默认值
    } catch(e) {
        return RELOAD_SPEED_MULTIPLIER;
    }
}, "float", ["pointer"]));
```

**实现原理**：

- 替换 `PlayerWeapons.get_ReloadSpeed` 属性方法
- 游戏代码调用此方法获取换弹速度加成
- 直接返回自定义倍数（如 2.0）
- **影响范围**：玩家的所有武器（全局）

------

#### 三、核心区别对比

| 维度           | `换弹加快.js`                | `无限子弹+快速换弹.js`            |
| -------------- | ---------------------------- | --------------------------------- |
| **修改对象**   | `WeaponData_Gun`（武器数据） | `PlayerWeapons`（玩家武器管理器） |
| **修改层次**   | 武器级（单把武器）           | 玩家级（全局）                    |
| **作用时机**   | 射击时一次性修改             | 每次查询换弹速度时生效            |
| **影响范围**   | 当前武器，换武器需重新触发   | 所有武器，切换自动生效            |
| **技术方式**   | 直接内存写入字段             | 替换属性 getter 函数              |
| **代码复杂度** | 较低（简单内存操作）         | 较高（需要判断玩家）              |
| **灵活性**     | 每把武器独立设置             | 统一控制所有武器                  |

------

#### 四、总结

**`换弹加快.js`** 是**武器级**修改，通过直接修改武器数据的 `reloadAnimRatio` 字段实现，优点是简单直接，但需要每次获取新武器时重新设置。

**`无限子弹+快速换弹.js`** 是**玩家级**修改，通过 Hook `PlayerWeapons.get_ReloadSpeed()` 属性方法实现，优点是全局生效，切换武器自动继承，是更优雅的实现方式。

**本质区别**：前者修改**数据**，后者修改**属性访问器**。后者更符合游戏原有的设计模式（通过属性方法获取加成）。
