# 29-子弹穿墙：仿原版穿透版

## 功能目标

子弹可以命中墙后的目标，但不重写伤害结算。

本功能保留 `WPN_Gun.Damage` 原流程，让游戏继续按 `WeaponData_Gun.wallShotDamageRatio` 做穿墙伤害衰减，并保留 `wallThrough` 命中/击杀标记。

## 实现方式

成熟方案通常不是直接补一次伤害，而是让射线能拿到墙后目标，再交回原版伤害函数处理。Unity 的 `RaycastAll` 会返回射线上的多个命中点，但返回顺序不保证稳定，因此原版代码一般会排序后再逐个处理命中结果；本功能利用这一点，只在本地武器进入 `WPN_Gun.Damage` 的短窗口内临时调整射线层。

具体流程：

1. Hook `WPN_Gun.Damage`，不使用 `Interceptor.replace`。
2. 调用 `Weapon.get_isMyWeapon`，确认只处理本地玩家武器。
3. 进入本地 `Damage` 时读取 `WeaponData_Gun.wallShotDamageRatio` 用于状态显示。
4. 临时把 `LayerConstant.LM_GunShoot` 改成 `HitBox-only` 掩码，让原版射线可以看到墙后的 hitbox。
5. 保持 `WeaponLogic.CheckWall` 原函数不变，墙体检测、伤害衰减、`wallThrough` 标记继续由游戏原版逻辑执行。
6. `WPN_Gun.Damage` 返回后立即恢复原 `LM_GunShoot`。

## 游戏内验收点

1. 开启功能后，本地开枪时 UI 的 `本地 Damage` 增加。
2. 首次本地开枪时 `层 Patch/恢复` 应接近 `1/1`，持续开枪时两边数量应同步增长。
3. 打墙后目标时，`CheckWall` 计数应增加。
4. `wallShotDamageRatio` 应显示当前武器数据里的原版穿墙伤害倍率。
5. 击杀/命中表现应走原版 `wallThrough` 标记，不应出现额外的二次伤害。

> 本目录（05-正式功能）保留的是**子弹穿墙**这一段的历史开发记录，脚本与测试仍是单功能版。
> 2.7 整合包里的实现在 `04-正式发行版/全功能整合包2.7/game_modifier/features/29_bullet_wall_penetration/`，
> 在原脚本基础上**追加了「弹体穿墙」**，卡片名同步改为「子弹穿墙/弹体穿墙」。
> 完整设计文档见 `02-开发规范/各个功能/29-子弹穿墙.md`（B 段）。

### 弹体穿墙解决的问题

弹体追踪（40-开火直伤/弹体追踪）里的火箭筒 / 榴弹 / 手雷 / 技能弹是真实飞行的实体，
撞到墙会被物理挡住并提前爆炸（"撞墙即爆"），目标躲在墙后时追不到。

### 关键反汇编结论（0x10B5D0F0 = WPN_GRENADE.OnCollisionEnter 尾部）

```
mov edi,[esi+44h] / test edi,edi / jz ret
call Rigidbody.get_velocity ... call Rigidbody.set_velocity
cmp byte [esi+74h],0        ; expWhenTouchSth
jz  ret
push [eax+118h] / push esi / call eax   ; vtable slot11 = TryExplosion
```

- 撞墙走的是 `expWhenTouchSth` → 虚表调用，**弹体根本不读 `LayerConstant.LM_GunShoot`**，
  所以"子弹穿墙那套放开门掩码"对弹体无效。
- 这段是**虚表间接调用**，`get_callees` 里看不到 —— 只靠 callees 会误判成"弹体撞墙只播个音效"。

### 版本迭代：第一版只做碰撞回调，实测无效

第一版只在 `WPN_Missile/WPN_GRENADE.OnCollisionEnter` 里兜底（抑制 `expWhenTouchSth`
+ `IgnoreCollision` + 写回速度），并挨个核对过 8 个 RVA 都正确安装。
**实测火箭筒完全没反应**：`game_modifier.log` 里 8 个钩子都装上了，但整场
**没有任何一条弹体日志** —— 说明卡在某条静默 return 上（最可能是
`Collision.get_contacts()` 或层判定），而且当时没写诊断，只能靠猜。

教训：**新机制第一次上机必须先把可观测性做进去**（计数器 + 周期 beat + 每次事件一行）。

补上诊断后第二次实测，日志直接给出真凶：

```
[beat] 弹体穿墙 ... 探路射线=0(...) ... FixedUpdate=300(本地0/非我300) ... lastReject=notMine
弹体碰撞：missile=0x84fda80 层=-1 normalY=n/a 判定=不穿墙/notMine
参数自检：... raycast=OK findObject=OK detectCollisions=OK ignoreCollision=OK
```

钩子全装上了、参数自检全 OK，但**所有判定都失败** —— 根因是
`native.isMyPlayer(...) === true` / `native.raycast(...) !== true`：
**Frida 的 `'bool'` 返回值不保证是 JS 的 `true`**（这里是数字 `1`），严格相等恒 false。
修法：统一走 `toFlag()`（40_direct_damage 里早有同名函数，本项目踩过同一个坑），
并把原始返回值 `typeof:值` 打进 beat 日志（`isMy原始=`）。

### v2 主路径：主动穿墙（不依赖碰撞回调）

每一物理步（`WPN_Missile.FixedUpdate` 钩子，仅本地玩家弹体）：

1. 沿飞行方向 `Physics.Raycast` 探路 `projectileProbeLookahead`(3.5m)，起点前移 0.35m；
2. `RaycastHit.m_Collider`(instanceID) → `Object.FindObjectFromInstanceID` → `GameObject.layer` 反查层：
   不是可穿透层（默认只有 Environment=layer 0）不处理；`|normal.y| >= 0.6` 算地板/斜面，不处理；
3. 判为墙面 → **接触之前**摘掉这次碰撞：
   **主选** `Physics.IgnoreCollision(弹体自身 collider, 这一面墙 collider, true)`（只影响这一颗弹 ×
   这一面墙，地板不受影响；墙 collider 由 `RaycastHit` 的 instanceID 反查得到）；
   **备选**（拿不到 collider 时）`Rigidbody.set_detectCollisions(rb, false)` 关掉整颗弹的物理碰撞。
4. 结束条件（任一）：走过"入态墙距 + `projectileGhostExtra`(0.8m)"且中心已不在关卡几何里 /
   `projectileIgnoreMaxMs`(1200ms) 硬上限 / 弹体回池 / 功能关闭 → 立刻 `set_detectCollisions(rb, true)`。

> **必须还原**：`detectCollisions` 留在 false 会被对象池的下一颗弹继承 → 直接飞穿全场。
> SetWeaponData / Recycle / sweep / disable / cleanup 五条路径都调 `restoreGhost()`。

### v2 兜底路径：碰撞回调（保留）

探路没赶上时（一个物理步就跨过探路距离），回调里再做一次：
本地弹体 + 可穿透层 + 法线偏水平 → onEnter 把 `WPN_GRENADE.expWhenTouchSth(+0x74)` 临时写 0
（onLeave 按原字节写回）→ `Physics.IgnoreCollision(弹体自身 collider, 墙 collider, true)`
→ 写回缓存的碰撞前速度。
（自身 collider 的来源见下面 v3。）

### v3：修掉"穿墙时卡墙减速 / 悬在空中迟迟不引爆"（2.7 第二次实测后）

第二版在功能上是"正常的"（能穿墙），但实测反馈：**穿墙时会明显变慢、卡住，
快要打到人时好像悬在空中、不立即引爆**。第二次实测日志（17:56 那局）把根因指清楚了：

```
反查弹体自身 collider 失败 ×19 条（该 WARNING 限频 2s/条）
弹体穿墙：missile=0x8d1dc80 wall=0x43929d60 layer=2 忽略=0对   ← 2.3 秒内同一面墙连撞 14 次
弹体碰撞：… 对象=ALPHA_Blocker.bmp 判定=墙面→穿墙            ← 判定是对的，但没忽略掉
[beat] 探路射线=995(墙520/地187/其他层288 命中层=2)
```

链条是这样的：

1. 找"弹体自己的 collider"靠 `Physics.OverlapSphere + Collider.attachedRigidbody` 反查，
   **会间歇性返回空**（采样 84 条 `弹体穿墙：` 里 38 条 `忽略=0对` ≈ **45%**）。
2. 反查失败 → 这面墙没被忽略；而**反应式路径没有兜底**（只有主动探路那条路有
   `detectCollisions` 备选，这局 `主动穿墙=0`，一次都没走到）→ 弹体继续撞。
3. 撞一次的代价是游戏硬编码的：`WPN_Missile/WPN_GRENADE.OnCollisionEnter` 尾部
   `velocity *= 0.6`（常量在 `0x10BAC054`）→ 连撞几次就卡在墙里，看起来就是
   "变慢 / 卡住 / 悬在空中"。
4. "不立即引爆"是连锁反应，不是另一个 bug：撞墙不炸是我们**故意**抑制的
   （`expWhenTouchSth` 写 0），弹体被卡住到不了敌人，只能等生命计时器
   （`RecyclableObject.lifeTime` 默认 **2.0s**）→ `OnLifeTimerEnd → TryExplosion` → 原地自爆。
   日志里那串"同一面墙 2.3 秒内 14 次碰撞"正好等于一发弹的整个寿命。

**三处修改：**

1. **自己的 collider 改从碰撞接触点里直接拿**（不再依赖物理查询）：
   `ContactPoint.m_ThisColliderInstanceID(+0x18)`（对方 `+0x1C`）
   → `Object.FindObjectFromInstanceID` → 用 `attachedRigidbody == rb` 验一下就直接用。
   三级来源：**接触点 hint > 本发弹的 collider 缓存 > OverlapSphere 反查**。
2. **忽略失败不再"算了"**：把这一面墙排队，下一个物理步（`WPN_Missile.FixedUpdate`，
   一定早于本次 `Physics.Simulate`）补一次忽略；超过 `projectilePendingRetryMs`(400ms)
   仍失败才放弃。日志里看 `补忽略=N(队列M/超时K)`。
3. **探路射线不再被"非墙层"吃掉**：敌人(7)/命中盒(3)/尸体(8)/幽灵(10) 经常正好挡在墙前面
   （实测 `其他层=288/995` ≈ 29%），一发射线就被吃掉、墙永远探不到。现在命中不可穿透层
   就跳过它继续往后探（最多 `projectileProbeMaxSkips`(3) 段）。

### 可调参数

`projectileWallPenetration`（总开关，默认开）、`projectileProbeLookahead`（探路 3.5m）、
`projectileGhostExtra`（多走 0.8m 才算穿过）、`projectileWallMaxNormalY`（法线阈值 0.6）、
`projectileIgnoreMinMs` / `projectileIgnoreMaxMs`（80 / 1200ms）、
`projectilePenetrableLayers`（**可穿透层掩码**，默认 `0xFFFFFA77` = 除角色/命中盒层外全部；
要收窄就改小，例如只留 layer 0 和 2 = `5`）、
`projectileProbeMaxSkips`（探路一次最多跳过几个不可穿透层的物体，默认 3）、
`projectilePendingRetryMs`（忽略失败的墙最多等多久补忽略，默认 400ms）。

> 注意：`Physics.CheckSphere` 不能用来判断"还在墙里" —— 它只看 layerMask，会把弹体自己的
> collider 也算进去（弹体多半就在 layer 0），结果永远为 true、永远不还原。要用
> `OverlapSphere + attachedRigidbody` 过滤自己。

### 诊断读法（`[beat] 弹体穿墙` 每 5 秒一行）

| 现象 | 含义 |
|---|---|
| `FixedUpdate=(…本地0…)` 且 `isMy原始=number:1` | **原生 bool 类型坑**：`isMyPlayer` 返回数字 1，`=== true` 恒 false → 用 `toFlag()` |
| `FixedUpdate=(…本地0…)` 且 `isMy原始=owner=null` | 弹体 owner 没读到 |
| `探路射线>0 墙=0 地>0` | 前方都被判成地板/斜面 → 调 `projectileWallMaxNormalY` |
| `其他层>0` + `命中层=N` | 前方的墙不在可穿透掩码里，N 就是它所在的层 → 改 `projectilePenetrableLayers` |
| `探路层分布=2(AirWall):37 0(Default):20 …` | **最有用的一行**：探路打在哪些层上（带层名） |
| 启用时的 `本工程层名表：0=Default 2=AirWall …` | 直接回答"layer N 是什么" |
| `主动穿墙=0` | 没进入穿墙态（看上面几项） |
| `主动穿墙>0` 但穿不过去 | `detectCollisions` 写入没被物理引擎接受 |
| `还原失败>0` | `set_detectCollisions` 调用报错 |
| `反查失败`（v3 新增） | 三条路都没拿到弹体自己的 collider 的次数，**正常应接近 0** |
| `接触点collider`（v3 新增） | 成功从碰撞接触点拿到自己 collider 的次数，正常应接近"本地碰撞数" |
| `缓存兜底`（v3 新增） | 反查失败、靠缓存顶住的次数（少量正常） |
| `补忽略=N(排队M/超时K/未决L)`（v3 新增） | 排队是累计 M 次、下一物理步补成功 N 次、超时放弃 K 次、当前还压着 L 条；**K 应远小于 M** |
| `反查失败现场：…`（v3 新增） | 只在三条路全失败时打一行（约 2%），含 `contacts=` / `thisID=` / `thisRB=` / `overlap=`，用于一轮定位残余失败 |

### 游戏内验收点（2.7）

1. 只开「子弹穿墙/弹体穿墙」，打 RPG / 扔手雷撞墙应**不再爆炸**，能穿到墙后，
   而且**穿墙前后速度不应肉眼可见地掉**（v3 的目标）。
2. 日志里 `[beat] 弹体穿墙` 每 5 秒一行：`主动穿墙=N/结束=N` 且 `穿墙中` 能回到 0。
3. `还原失败=0`；`追踪弹` 回池后 `穿墙中` 必须归零（否则有弹体没还原碰撞）。
   另外 v3 起要看：`反查失败` 应停在很小的数、`接触点collider` 应接近本地碰撞数、
   `补忽略` 的 `超时` 应远小于 `队列`。
4. 判定失败时看 `lastReject` / `命中层`：`floorLike`=地板斜面（设计上不穿）、
   `notMine`=别人/人机的弹体、`其他层>0` 则是"墙不在可穿透掩码里"，按 `探路层分布`/`本工程层名表` 调 `projectilePenetrableLayers`。
5. 人机的弹体撞墙应当仍然照常爆炸（不影响原版）。
