# 打包规范

## 0. 核心原则

打出来的 EXE 是给用户用的，不是给开发者调试用的。

## 1. 必须遵守

### EXE 配置
- **单文件模式**：所有东西打成一个 `.exe`，不要产出文件夹
- **`console=False`**：不弹控制台窗口，用户不需要看黑框
- **`uac_admin=True`**：需要管理员权限（frida 注入要用）
- **`upx=False`**：不压缩，避免杀软误报和运行异常
- **`debug=False`**：不打包调试信息

### 资源打包（只读文件 → 打进 EXE 内部）
- JS 脚本：通过 `datas` 打包
- DLL / inject.exe：通过 `datas` 打包
- 图片、音效：通过 `datas` 打包
- **不要打包运行时产生的文件**（日志 inject_log.txt 等）

### 运行时路径（代码里要处理）
打包后 `__file__` 指向临时解压目录，不再是 EXE 所在目录。代码里必须区分两种路径：

```python
def _get_app_dir():
    """可写目录 = EXE 旁边（配置、日志）"""
    if getattr(sys, "frozen", False):
        return Path(sys.executable).resolve().parent
    return Path(__file__).resolve().parent

def _get_internal_dir():
    """只读目录 = 打包内部（JS、DLL 等资源）"""
    if getattr(sys, "frozen", False):
        return Path(sys._MEIPASS)
    return Path(__file__).resolve().parent
```

| 文件类型 | 用哪个目录 | 原因 |
|---------|-----------|------|
| JS 脚本 | `_get_internal_dir()` | 只读，打包进去的 |
| DLL / inject.exe | `_get_internal_dir()` | 只读，打包进去的 |
| 配置 JSON | `_get_app_dir()` | 可写，EXE 旁边 |

### hiddenimports
必须显式声明所有动态导入的库，PyInstaller 扫描不到的都要写：
- `customtkinter`, `frida`, `frida_tools`, `psutil`
- 根据实际功能再加：`pynput`, `keyboard`, `pygame`, `PIL` 等

## 2. 不要做的事

- **不要打包日志文件**：`inject_log.txt`、`logs/` 目录等运行时产物
- **不要打包开发文件**：`.pyc`、`__pycache__`、`tests/`、`.md`（除非用户要求）
- **不要开 UPX 压缩**：压缩后容易被杀软拦截
- **不要开 console**：用户看到黑框会困惑

## 3. Spec 文件模板

```python
# -*- mode: python ; coding: utf-8 -*-
import os

block_cipher = None
current_dir = os.path.dirname(os.path.abspath(SPEC))

datas = []

# JS 脚本
js_file = os.path.join(current_dir, "你的脚本.js")
if os.path.exists(js_file):
    datas.append((js_file, "."))

# 其他只读资源按需添加 datas.append((源路径, 打包目标子目录))

a = Analysis(
    ['你的入口.py'],
    pathex=[current_dir],
    binaries=[],
    datas=datas,
    hiddenimports=[
        'customtkinter',
        'frida',
        'frida_tools',
        'psutil',
        # 按需补充
    ],
    hookspath=[],
    hooksconfig={},
    runtime_hooks=[],
    excludes=[],
    win_no_prefer_redirects=False,
    win_private_assemblies=False,
    cipher=block_cipher,
    noarchive=False,
)

pyz = PYZ(a.pure, a.zipped_data, cipher=block_cipher)

exe = EXE(
    pyz,
    a.scripts,
    a.binaries,
    a.zipfiles,
    a.datas,
    [],
    name='输出文件名',
    debug=False,
    bootloader_ignore_signals=False,
    strip=False,
    upx=False,
    upx_exclude=[],
    runtime_tmpdir=None,
    console=False,
    disable_windowed_traceback=False,
    argv_emulation=False,
    target_arch=None,
    codesign_identity=None,
    entitlements_file=None,
    icon=None,  # 有 ico 就填路径
    uac_admin=True,
)
```

## 4. 打包命令

```powershell
cd "你的项目目录"
pyinstaller --clean 你的文件.spec
```

产出在 `dist/` 目录下。`build/` 是中间产物，可以删。
