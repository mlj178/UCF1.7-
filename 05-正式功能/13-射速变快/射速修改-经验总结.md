## 一、IDA 反编译核心分析

### 1.1 射击流程完整分析

通过 IDA Pro 反编译，确认完整的射击流程如下：

```
OnFireBtnPressed()
    ↓
GunFireChecking()              ← 检查射击条件（含射速间隔检查）
    ↓ (检查通过)
GunShoot()                     ← 射击入口
    ↓
GunShoot_NoCheck()             ← 无检查射击（核心逻辑）
    ↓
GunShootFunction()             ← 执行射击（虚方法，发射子弹、播放动画等）
    ↓
nextAllowedShootTime = Time.time + get_shootIntervalTime()  ← 设置下次允许射击时间
```

## 十五、推荐修改方案（IDA分析后）

### 方案A：Hook `get_shootIntervalTime()` - 最推荐

**原理**：在射速计算源头拦截，对本地玩家返回更小的间隔值

**优点**：
- 覆盖所有枪械（主武器、副武器、榴弹枪、RPG、投掷物、部署武器）(假的，只作用于全自动武器)
- 不影响其他玩家
- 修改一次，全局生效



---

## 十八、注意事项

1. **ScriptableObject 共享问题**：`WeaponData_Gun` 是共享资源，直接修改会影响所有玩家
2. **运行时字段覆盖问题**：`nextAllowedShootTime` 每次射击后会被重新计算
3. **玩家判断问题**：必须通过 `get_isMyPlayer` 判断本地玩家
4. **武器所有者获取**：`WPN_Gun` 实例需要获取 `owner` 字段才能判断玩家
5. **动画速度问题**：射速和动画速度需要配合修改，否则会出现动画不匹配
6. **半自动武器问题**：半自动武器通过 `semiGunFireLinkState` 状态机控制，需要特殊处理
7. **RPG/投掷物问题**：RPG和投掷物使用不同的射速逻辑，需要单独处理

---

## 十九、总结

### 最佳修改路径

1. **主武器/副武器**：Hook `GunFireChecking` 或 `get_shootIntervalTime`
2. **近战武器**：Hook `get_KnifeSpeed`（已验证可行）
3. **RPG**：修改 `fireAnimRate` 和 `reloadAnimRate`
4. **投掷物**：修改 `MissileData.velocity` 和 `expTime`
5. **部署武器**：修改 `SentryGun.nextAttackTime`

### 关键判断条件

- 使用 `Player.get_isMyPlayer` (RVA: 0xB55FD0) 判断本地玩家
- 通过 `WPN_Gun` 实例获取 `owner` 字段
- 确保只修改本地玩家的武器实例
