# 直接变身剑客

## 目标

生化6（剑客模式）下，一键让本地玩家或存活 Bot 变成剑客（GhostBlade）。

## 关键 RVA

| 名称 | RVA |
| --- | --- |
| ModeBase.Update | 0x00AF6A00 |
| Mode_Nano6.get_instance3 | 0x00B4A310 |
| Mode_Nano6.BecomeGhostBlade | 0x00B47740（静态） |
| Player.get_isMyPlayer | 0x00B55FD0 |
| Player.get_nanoRole | 0x00B56200 |
| HealthData.get_isDead | 0x00AE4830 |

## 原理

调用静态方法 `Mode_Nano6.BecomeGhostBlade(player)`：当前 `nanoRole==0` 且存活时变为剑客（21）。本地玩家额外更新技能提示 HUD。

## 限制

- 仅生化6 / 剑客模式（gameMode == 5）
- 目标必须是佣兵且存活
- 动作在 ModeBase.Update 主线程执行

## 踩坑（2026-09-11）

- 与救世主同源：`SubscribeableProperty.value` 偏移应为 `+0x08`；已改为优先 `Player.get_nanoRole`。

## RPC

enable / disable / status / cleanup / trigger(`local_ghostblade`|`bot_ghostblade`) / setConfig

## 持久化日志与自动检查

- 调试 UI 每次启动会写 `logs/become_ghostblade_ui_YYYYMMDD_HHMMSS.log`
- 日志包含：UI 操作、Frida 日志、`RPC_STATUS` 完整状态 JSON
- 测完后自动检查：

```powershell
$env:MIMO_PYTHON  # 或 python
& $env:MIMO_PYTHON check_logs.py
& $env:MIMO_PYTHON check_logs.py --all
```

- 结论：`PASS` / `WARN` / `INCOMPLETE` / `FAIL`
- 退出码：0 正常或不完整；1 发现问题；2 无日志
