# 英雄能力扩展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `05-正式功能/35-英雄能力扩展` 中完成一个可独立测试的功能卡片，使所有模式的普通 Human 能用原生英雄技能键获得并首次部署机枪守卫，并使团队模式 Human 可用交互键打开英雄选择界面、变身且复活后保持所选英雄。

**Architecture:** 单功能目录采用接近整合包 2.5 的插件形状，但本计划不向 2.5 复制任何文件。`script.js` 是唯一 Frida 运行脚本，内部由 `SharedRuntime`、`HumanSentryModule`、`TeamHeroModule` 三个闭包组成；两个业务模块只依赖共享运行接口，不互相调用。先用只读/日志型探针验证输入键和团队模式英雄选择桥接，再实现持久化卡片与两个可独立启停的模块。

**Tech Stack:** Python 3.12、CustomTkinter、标准库 `unittest`、Frida 17 JavaScript API、32 位 IL2CPP、IDA Pro MCP、GameAssembly.dll SHA-256 `45162101da4f963e8e99ecd63873092e3f5808f00ffcfd6f2649eea68d94ee1f`。
