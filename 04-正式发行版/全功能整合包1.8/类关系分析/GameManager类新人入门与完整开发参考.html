二、五分钟理解 GameManager

GameManager 的声明：public class GameManager : Singleton<GameManager> // TypeDefIndex: 5365

继承来源：Singleton<GameManager>。新人先记住“它在游戏里负责什么”，再看完整字段表。

#问题新人应先记住的答案依据
1GameManager 最重要的作用是什么？它是“本局战斗的总入口”，尤其负责玩家集合、创建玩家、伤害事件、回合事件。dump.cs + 游戏流程推断
2allPlayers、playersBL、playersGR 是什么关系？allPlayers 是总数组；playersBL/playersGR 是按阵营拆开的列表；Alive 列表只放当前存活对象。dump.cs + 游戏流程推断
3怎么确认哪个 Player 是自己？优先用 GameManager.myPlayer，它是在 AddPlayers 时根据 ClientData.mine 绑定出来的。dump.cs + 游戏流程推断
4为什么直接调用无参方法可能没反应？很多方法依赖 Unity 生命周期、场景对象、资源字典、事件订阅或当前回合状态，单独调用不满足上下文。dump.cs + 游戏流程推断
5修改伤害应该看哪里？先看 TakeDamage 和 DamageEvent_* 事件链，再看 Weapon / Entity / Mode_* 是否继续改写结果。dump.cs + 游戏流程推断

本局战斗总入口

GameManager 是一局战斗的总协调者：创建玩家、保存玩家集合、加载武器和角色资源、转发伤害/死亡/出生/回合事件。

GameManager 自己连接的系统

Player/Entity：GameManager 创建、登记、统计和通知。
PlayerWeapons/Weapon：发枪、拿枪、回收和武器字典。
CharacterModel/CharacterAsset：给 Player 设置角色模型。
HUD/规则类：通过事件接收伤害、死亡、回合通知。
