ModeBase

玩法规则基类。它集中维护比分、回合、时间、复活、双方人数和计分板 UI，是具体模式规则的共同底座。

它直接保存的主要类型

GameObject 字段依据：rectContainer / playerRectPrefab

Unity 场景对象或预制体。这里多用于 UI 容器、玩家条目模板或模式对象生成。

HUD_PlayerRect 字段依据：playerRect_BL / playerRect_GR

计分板玩家条目 UI。用于显示玩家名称、阵营、存活、击杀死亡等对局状态。

Material 字段依据：timeFlashMat

Unity 材质资源。这里常用于倒计时闪烁、警告色或 UI 特效表现。

Player 字段依据：myPlayer

玩家战斗主体。保存生命、阵营、武器、输入、模型和 HUD 状态，是本机玩家、队友、敌人和 Bot 在战斗层的核心对象。

RawImage 字段依据：scoreBoardImage

Unity UI 原始图片组件。用于显示计分板背景或模式相关图片。

SimpleObjectPool 字段依据：playerRectPool

简单对象池。用于复用计分板条目、临时 UI 或场景对象，减少频繁创建销毁。

Text 字段依据：scoreText_L / scoreText_R / roundText_T / roundText_C / timeText_M / timeText_S

Unity UI 文本组件。用于显示比分、回合、倒计时、模式提示等。

Texture 字段依据：scoreBoardTex

Unity 贴图资源。用于计分板、模式提示或 UI 皮肤切换。

Vector2Int 字段依据：score / gameTime / restGameTime

二维整数值。用于比分、时间、回合等两个数字组合，例如 BL/GR 分数或分钟/秒。
