GameManager

一局对战的全局总控。它保存玩家、阵营、模式、武器数据、角色/武器资源池，并通过事件把伤害、死亡、出生、回合开始等流程通知给其他系统。

它直接保存的主要类型

CharacterAsset 字段依据：characterAsset

角色资源配置表：管理可用角色/模型资源

Entity 字段依据：entityBL_Alive / entityGR_Alive

战斗实体基类：玩家/Bot 等可受击对象

GameMode 字段依据：gameMode

玩法模式枚举。它不是运行时对象，而是对局类型编号，用来决定当前局是团队竞技、个人竞技、特殊模式还是纳米/终结者模式。

GameObject 字段依据：playerPrefab / botPrefab / gameModePrefab

Unity 场景对象或预制体。这里多用于 UI 容器、玩家条目模板或模式对象生成。

NameKeyPool 字段依据：characterPool / weaponPool

按名称索引的对象池：复用角色/武器对象

Player 字段依据：myPlayer / allPlayers / playersBL / playersBL_Alive / playersGR / playersGR_Alive / <ace>k__BackingField

玩家战斗主体。保存生命、阵营、武器、输入、模型和 HUD 状态，是本机玩家、队友、敌人和 Bot 在战斗层的核心对象。

RecyclableObject 字段依据：recyclableObjects

可回收场景物：掉落物或临时对象清理

Weapon 字段依据：WpnDictionary

武器实例：实际可装备、发射、掉落的武器对象

WeaponAsset 字段依据：weaponAsset

武器资源配置表：提供可加载/可发放武器资源

WeaponData 字段依据：WpnDataDictionary

武器数值配置：伤害、弹药、图标等资料

WeaponLimited 字段依据：weaponLimited

武器限制枚举。用于描述当前玩法或房间限制的武器类型，例如刀战、手枪战、狙击战。
