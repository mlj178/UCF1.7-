## 二、核心类分层

```mermaid
flowchart TB
    subgraph ROOM["房间与配置层"]
        UI["UI_GameRoom<br/>房间玩家列表与模式配置"]
        CD["ClientData<br/>昵称、阵营、Bot、背包和角色"]
    end

    subgraph RULE["对局与规则层"]
        GM["GameManager<br/>玩家、武器、伤害和回合总入口"]
        MB["ModeBase / Mode_*<br/>比分、时间、胜负和模式规则"]
        MM["MapManager<br/>地图和出生点"]
    end

    subgraph PLAYER["战场角色层"]
        EN["Entity<br/>队伍、生命、Buff、出生和死亡"]
        PL["Player<br/>移动、视角、复活和战绩"]
        BOT["Bot<br/>电脑玩家决策"]
    end

    subgraph VIEW["装备与表现层"]
        PW["PlayerWeapons<br/>武器槽与当前武器"]
        WP["Weapon / WPN_*<br/>具体武器行为"]
        CM["CharacterModel<br/>模型、动画和受击部位"]
        CAM["CameraManager<br/>本机观察和第一人称视角"]
    end

    UI --> CD
    UI --> GM
    GM --> MB
    GM --> MM
    GM --> PL
    PL --> EN
    BOT --> PL
    PL --> PW
    PW --> WP
    PL --> CM
    GM --> CAM
```
