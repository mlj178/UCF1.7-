# 技能无冷却闪退修复记录

## 修改内容

- 删除 `get_nickName` 玩家识别：该函数提供的是 `ClientData`，不是 `Player`。
- 删除通过 `isBot` 猜测本地玩家：其他真人玩家也会通过该判断。
- `get_isMyPlayer` 改为只观察游戏原函数结果，不再替换原函数。
- x86 下只读取 `get_isMyPlayer` 返回寄存器的最低 8 位 `AL`，避免把 `false` 误判为 `true`。
- 删除 Frida `setInterval` 定时调用。
- 改为在已确认的本地玩家 `Player.Update` 中，每 200ms 调用一次 `EndCold`。
- 增加 `Player.OnDestroy` 和 `GameManager.OnDestroy` 清理，退出房间或玩家销毁后立即废弃旧指针。
- 任一必要 Hook 安装失败时，回滚全部 Hook，功能保持关闭。

## 保留功能路径

```text
get_isMyPlayer 返回 true
→ 保存本地 Player
→ 本地 Player.Update（游戏线程）
→ 每 200ms 读取当前 PlayerSkills / Skill[]
→ 校验技能对象
→ 调用 Skill_Common.EndCold
```

## 预期状态

- 技能无冷却效果保持不变。
- 不再把 `ClientData`、其他真人玩家或已销毁玩家当成本地玩家。
- 不再因 `EAX` 高 24 位残留数据而连续记录多个“本地玩家”。
- 退出房间、切换场景后不继续访问旧技能对象。
- 游戏重开并重新连接后，等待游戏再次确认本地玩家，再自动恢复效果。
