# game_modifier v1.2 → v1.3 更新对比

## 一、新增功能模块

| 模块        | v1.2 |                      v1.3                      |
| ----------- | :--: | :--------------------------------------------: |
| 轻重力/高跳 |  ❌   |  ✅ 动态调整重力(0~1)与跳跃(1~5)，可选生效范围  |
| 回合跳过    |  ❌   | ✅ 写入 0:00 触发回合结束，与无限时间协作不冲突 |

---

## 二、功能增强

| 功能              | 变化说明                                                     |
| ----------------- | ------------------------------------------------------------ |
| **剑气化丝**      | 攻击距离由固定 50x → 滑块调节 **1~50x**（JS 新增 `setRange` RPC） |
| **无限时间**      | 新增 `pauseFor()` 暂停机制，回合跳过时自动停写 1 秒，避免冲突 |
| **聚怪模块**      | 重构缓存逻辑：`trackedPlayers`/`trackedBots` → `recentBotPlayers`，传送后清空，**根除第三次闪退** |
| **自动重连**      | 新增连接监控线程，断开后自动重连，**恢复所有已开启功能**     |
| **快刀 / 滑板鞋** | 下拉框 → 滑块，快刀 1~10、滑板鞋 1~6，精度 0.1               |

---

## 三、UI 界面变化

| 项目      | v1.2                     | v1.3                                       |
| --------- | ------------------------ | ------------------------------------------ |
| 窗口尺寸  | 800×920（固定）          | 650×750（**可自由缩放**）                  |
| 窗口置顶  | ❌                        | ✅ `topmost`                                |
| 半透明    | ❌                        | ✅ `alpha=0.92`                             |
| 折叠/展开 | ❌                        | ✅ 折叠后仅显示状态栏                       |
| 功能分类  | 垂直长列表               | **选项卡分类**：武器 / 人物属性 / 其他     |
| 卡片布局  | 单列纵向                 | **两列网格**，空间利用率提升               |
| 连接状态  | 只有文字                 | **绿🟢/红🔴/灰⚫ 三色区分**，断线提示同步变色 |
| 底部提示  | ❌                        | ✅ 拖动边框提示 + 红色标语                  |
| 说明文字  | 冗长（含修辞、分词删除） | **全部精简**，仅保留功能描述               |

## 五、总结

v1.3 在 **功能** 上新增轻重力/高跳、回合跳过两大模块，剑气化丝支持动态调节，聚怪根除闪退，增加自动重连；在 **UI** 上全面重构为可缩放、半透明、可折叠、分类选项卡 + 两列网格的精简布局，交互效率和视觉体验显著提升。
