每次启动 全功能整合包2.7.exe 会弹出 UAC 授权窗口，请点击“是”。
这是修改器连接游戏（Frida attach + DLL 注入）所必需的权限，属于正常现象。

个人设置、快捷键和功能状态保存在：
%LOCALAPPDATA%\UCFModifier\2.7\data

卸载程序不会删除该目录。2.7 与 2.6 使用独立的数据目录，因此不会相互覆盖设置。

仅支持 Windows 10 / 11 64 位。Windows 7 跑不起来（程序基于 Python 3.12，官方已不支持 Win7），
所以随包附带了空白文件“win7用不了，只有win10和11能用.txt”作为提示。

若杀毒软件报毒，系修改器含注入器与 Frida 组件所致，请加入信任后使用。
