# F1/F2 Windows 原生全局快捷键设计

## 目标

让定点瞬移点位2的 F1/F2 在游戏获得前台焦点时仍可触发。

## 方案

新增独立 Win32 组件，在专用消息线程调用 `RegisterHotKey` 注册 F1/F2，并处理 `WM_HOTKEY`。收到消息后只负责把既有定点瞬移动作投递回 Tk 主线程，不触碰 Frida/RPC 实现。

注册使用 `MOD_NOREPEAT` 防止长按连发。若某个原生热键注册失败，该键回退到现有 `keyboard.add_hotkey`；失败原因必须写入日志。关闭或重新应用快捷键时调用 `UnregisterHotKey` 并结束消息线程。

F1/F2 从 Tk 局部绑定移除，避免修改器前台时原生和 Tk 两条路径重复触发。Alt+1/Alt+2 保持现状。

## 验证

通过注入假的 Win32 API 测试注册结果、消息分派和清理；通过管理器测试确认只有原生注册失败的键才使用 `keyboard` 回退；最后进行 Windows 实机注册探测和游戏内人工测试。
