# 快捷键说明-整合包通用参考

这份不是某个单独版本的说明，而是后续整合包继续迭代时的快捷键参考。只有当新功能可能需要快捷键时，再看这里判断。

原则很简单：战斗中经常临时开关的，适合；创建房间前才该设置、容易误触、或者本身是复杂配置页的，不适合。

## 文档职责

这份文档只管“要不要进快捷键选项”，不管功能怎么接入，也不管开关和参数怎么保存。

新增功能时先看主接入规范。只有当这个功能可能需要快捷键时，再读这份文档。

## 普通快捷键选项

这些功能适合出现在设置页的“功能快捷键绑定”下拉选项里：

- 聚怪：常用，适合一键开关/触发。
- 回合跳过：按钮型功能，适合快捷触发。
- 时间加速：适合开关，具体倍率不靠快捷键调。
- 第三人称：视角类开关，适合战斗中切换。
- 子弹穿墙：需要临时开关，适合快捷键。
- 人机暂停：测试、刷图、观察时都比较常用。

## 固定专用快捷键

这些也是快捷键，但不是设置页下拉框里随便绑定的功能。它们是功能自己固定占用的快捷键：

- 定点瞬移 Alt+1：保存当前位置。
- 定点瞬移 Alt+2：瞬移到保存点。

固定专用快捷键不要和普通快捷键混在一起统计，也不要在普通下拉绑定里重复占用。

## 后续可考虑

如果以后还想补一个，优先考虑空位，比如 F3：

- 自由视角：如果经常观察地图、箱子、bot 路径，可以给 F3。
- 金刚不坏：如果更看重保命，也可以给 F3。

我更建议 F3 先空着，等实际玩的时候发现哪个功能真的常按，再放进去。

## 新功能接入时怎么判断

新增功能进整合包时，按这个顺序想：

1. 这个功能是不是战斗中会反复开关？
2. 它是不是简单开关或按钮，不需要先选一堆配置？
3. 误触一下会不会把房间规则、ESP、模式状态弄乱？
4. 如果它只是开局前配置一次，就不要放快捷键。
5. 如果它更适合先在 UI 里调参数，再手动开关，也可以不放快捷键。

满足前两条，并且误触风险低，才建议在 manifest 里加：

```json
"hotkey": {
  "enabled": true
}
```

只加进快捷键选项，不代表必须默认绑定。默认绑定要看是否真的常用、有没有空位、会不会和专用快捷键冲突。
