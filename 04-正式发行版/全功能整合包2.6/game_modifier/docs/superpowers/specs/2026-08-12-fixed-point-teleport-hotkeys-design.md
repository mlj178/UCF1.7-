# 定点瞬移点位2快捷键调整设计

## 目标

- F1 固定执行“保存点位2”。
- F2 固定执行“瞬移到点位2”。
- F3、Alt+3、Alt+4 从普通快捷键槽位、全局监听和窗口监听中删除。
- Alt+1、Alt+2 继续分别执行“保存点位1”和“瞬移到点位1”。

## 实现边界

快捷键到动作的映射只在 Python 层调整。定点瞬移的 `savepoint2`、`teleporttopoint2` RPC 和 Frida 脚本保持不变。设置页继续根据核心快捷键配置动态生成；F1、F2 显示为不可改绑的固定动作。

现有 F1 普通功能绑定会被固定动作覆盖；旧配置中的 F1、F3、Alt+3、Alt+4 数据不会再被运行时读取或注册。

## 验证

通过静态回归测试验证核心映射、Tk 监听和所有用户可见文案，并运行 Python 编译检查及相关测试。
