# 2.5 版本标识与贡献者信息更新设计

## 目标

将 `全功能整合包2.5` 的用户可见程序版本从 `v2.4` 更新为 `v2.5`，并在设置窗口的“关于”页中紧接作者信息显示贡献者信息。

## 范围

- `ui/window_contract.py`：将应用版本常量更新为 `v2.5`。窗口标题和“关于”页标题均通过该常量显示，因此会同步更新。
- `ui/settings_window.py`：在“作者: 挂呱呱呱”标签之后增加一行 `Contributor(贡献者)：少年与狗子`，沿用现有字体和垂直间距。
- `packaging/installer.iss`：将安装器的默认版本值更新为 `2.5`；发布脚本传入版本时仍可覆盖该默认值。

## 明确不改动的内容

- 历史设计/计划文档中的 `2.4` 记录。
- 功能脚本中指向旧功能版本的注释。
- 用户数据目录和兼容逻辑，避免升级后丢失既有配置。

## 验证

使用静态检查确认：应用版本常量为 `v2.5`、安装器默认版本为 `2.5`、贡献者标签紧随作者标签；随后执行 Python 语法编译，确保受影响的 Python 模块可导入解析。
