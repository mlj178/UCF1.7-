# 全功能整合包 v2.0 更新说明

> 对比上一版（v1.9）。本版主要是**新增了一个重磅功能（手雷模式）**，并把上一版的所有功能整理了一下（给功能文件夹加编号、清理代码），玩法基本延续。

## 一、新增功能

| 功能 | 效果 | 在哪用 |
|---|---|---|
| 💣 手雷模式 | 把"扔手雷"变成一套强化玩法：手雷数量锁定 999、手雷不被系统回收；还能给手雷强化伤害、爆炸范围和飞行速度；开"连投模式"可以快速连续抛手雷；更可以让**人机全都变成扔手雷**，把战局搅得全是手雷 | 独立页面（特殊类） |

手雷模式里可以单独调这些选项：
- 无限手雷范围：对"玩家"或"玩家+人机"生效
- 手雷三强化：伤害 / 爆炸范围 / 飞行速度（各自可调倍率）
- 手雷连投模式：抛完就自动恢复"可再扔"状态
- 人机投掷驱动：让人机优先改用投手雷

## 二、功能优化 / 玩法调整

v1.9 的 23 个功能全部保留，玩法上只做了几处小调整：

| 功能 | 优化前 | 优化后 |
|---|---|---|
| 轻重力 | 默认重力 1.0 | 默认重力 0.9、跳跃 5.0（开箱即用更"轻"、跳得更高） |
| 聚怪 | 只靠位移传送 | 聚怪过程加了诊断日志，改用了更稳定的坐标写入方式，聚怪更可靠 |

## 三、内部整理（对用户影响小）

- 功能文件夹统一加上 `01_`、`02_` 这样的编号，方便管理。
- 手雷模式这类"独立页面"功能，快捷键/开关的处理做了适配。
- 清理了部分功能的无用代码和导入写法，让程序更干净。
