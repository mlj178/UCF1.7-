# UCF 2.5 Installer Design

## Goal

Deliver a Windows x64, administrator-required installer for `全功能整合包2.5` using PyInstaller onedir and Inno Setup, without sharing writable user settings with version 2.4.

## Decisions

- Build a formal release installer named `UCF2.5修改器安装器.exe`.
- Install the application as a complete PyInstaller onedir distribution with desktop and Start Menu shortcuts and an uninstall entry.
- Keep 2.5 user settings under `%LOCALAPPDATA%\UCFModifier\2.5\data`; do not read or overwrite 2.4 settings.
- Include release instructions and an SHA-256 checksum beside the installer.
- Preserve every existing user change outside the packaging outputs.

## Validation

- Run the focused data-directory test and the available project test suite.
- Confirm the build environment and locked dependencies are healthy.
- Inspect the onedir output, PyInstaller warnings, installer output, and SHA-256 file.
- Do not launch the game-modifier executable during this build, because it requires an interactive UAC confirmation and a game process for functional attach testing.
