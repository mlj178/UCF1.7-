# UCF 2.5 Installer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a verified installable EXE for `全功能整合包2.5` that preserves version isolation for per-user settings.

**Architecture:** The application remains a PyInstaller onedir distribution. `core/config.py` selects a 2.5-local `%LOCALAPPDATA%` storage path while frozen; `packaging/build_release.ps1` builds that distribution, compiles `installer.iss`, and writes the release documentation and checksum.

**Tech Stack:** Python 3.12.5, PyInstaller 6.20.0, Inno Setup 6, PowerShell.
