## 状态持久化功能说明

### 功能描述
软件关闭时自动保存所有功能卡片的开关状态和参数值，下次启动时自动恢复到上次的设置。

### 存储文件
- 开发模式：`game_modifier/data/feature_state.json`
- 打包后：`data/feature_state.json`（与 exe 同级）

### 记录内容

| feature_id | 字段 | 说明 |
|---|---|---|
| 所有功能 | `enabled` | 开关状态（true/false） |
| `knife` | `slider_value` | 快刀速度（1.0~10.0） |
| `movespeed` | `slider_value` | 移动速度倍率（1.0~6.0） |
| `range` | `slider_value` | 剑气化丝距离（1.0~50.0） |
| `gravity` | `gravity_value` | 重力值（0.0~1.0） |
| `gravity` | `jump_value` | 跳跃值（1.0~5.0） |
| `gravity` | `gravity_mode` | 生效范围（"player_only" / "all"） |
| `weapon_giver` | `respawn_weapon` | 复活自动装备（true/false） |

### 写入时机
1. 用户切换开关或调整滑块 → 3秒防抖自动保存（`_schedule_save_state`）
2. 软件关闭时 → 立即保存（`_save_feature_state`）

### 读取时机
1. 软件启动、UI构建完成后 → 从文件还原到UI控件（`_load_feature_state`）
2. 连接游戏成功后 → 对 enabled=true 的功能发送Frida指令使其生效（`_restore_features`）

### 实现方法（app.py）
- `_load_feature_state()`：启动时读取JSON，还原开关、滑块、下拉框到UI
- `_save_feature_state()`：将当前状态写入JSON
- `_schedule_save_state()`：3秒防抖，避免频繁写盘

### 修复的Bug
- 原v1.6的 `_on_close` 中 `_cleanup()` 先于 `registry.save_state()` 执行，导致保存的全是False
- 原 `registry.save_state()` 读的是Feature实例的 `_enabled`（从未被UI层更新，始终为False），现已改由 `app.py` 直接读取 `self._features` 字典
- 原 `registry.load_state()` 从未被调用，现已由 `_load_feature_state()` 替代
