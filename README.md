# 全功能整合包（UCF 1.7 修改器）

> **文档更新日期：2026年10月22日**
> 当前版本：**全功能整合包 v2.7**（程序内显示名以 `ui/window_contract.py` 的 `APP_VERSION` 为准）

## 这是什么

这是 **UnityCrossFire 1.7**（穿越火线单机版）的游戏修改器，正式发布形态叫 **全功能整合包**。

修改器通过 **Frida** 注入 `GameAssembly.dll`，用 JavaScript 脚本 Hook IL2CPP 方法、读写内存字段，实现 **40 项游戏功能**。界面层用 **Python + CustomTkinter** 构建，通过 RPC 与 Frida 脚本通信。

程序名、安装包名、数据目录都跟着版本号走：装好之后是 `全功能整合包2.7.exe`，设置保存在 `%LOCALAPPDATA%\UCFModifier\2.7\data`。

## 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 注入与 Hook | Frida | Windows x86 IL2CPP，调用约定 `mscdecl` |
| 脚本逻辑 | JavaScript | Hook 方法、读写内存、定时器调度 |
| 界面 | Python + CustomTkinter | 功能面板、设置页、红色主题 Tab |
| 通信 | RPC（Frida export） | Python ↔ JS 双向调用 |
| 逆向资料 | Il2CppDumper + IDA | dump.cs 查类/字段，IDA 查汇编逻辑 |
| 打包 | PyInstaller（onedir）+ Inno Setup | 目录版产物 + 可安装 exe |

## 运行环境

- Windows **10 / 11 64 位**（Windows 7 不支持：程序基于 Python 3.12，官方已不支持 Win7）
- 运行修改器需要**管理员权限**（Frida attach + DLL 注入）
- 源码运行：Python **3.12.5** 64 位

## 快速开始（源码运行）

1. 安装依赖（仅打包/开发需要，运行成品 exe 不需要）：
   `pip install -r 04-正式发行版/全功能整合包2.7/game_modifier/requirements-build.txt`
2. 进入程序目录运行：`python main.py`（连接游戏/注入 DLL 时建议以管理员身份启动，成品 exe 默认就会弹 UAC）
3. 启动游戏 `UnityCrossFire.exe`，进入房间
4. 在修改器界面勾选功能即可生效
