### Renderer.isVisible 的含义
根据 Unity 官方文档：
 Renderer.isVisible - Is this renderer visible in any camera?

This property returns true if the renderer is visible from any camera. It will return false if the renderer is not visible from any camera.
关键点：

- 只检测渲染器是否在 任何相机的视锥体 内
- 不检测遮挡 - 即使被墙挡住，只要在视野角度范围内就返回 true
- 这是 Unity 引擎层面的"可见性"，不是游戏逻辑层面的"遮挡检测"
