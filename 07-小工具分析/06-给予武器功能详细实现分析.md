## 一、功能概述

### 1.1 功能定义

**给予武器** (GiveWeapon) 是游戏修改器的核心功能之一，允许玩家：
- 直接获得指定ID的武器
- 绕过游戏正常获取武器的流程
- 实现无限弹药
- 修改武器属性

### 1.2 功能价值

| 功能 | 说明 | 应用场景 |
|------|------|---------|
| **直接获取武器** | 无需拾取/购买直接获得武器 | 快速装备测试 |
| **武器切换** | 快速切换到指定武器 | 战斗优势 |
| **无限弹药** | 弹药不减少 | 持续作战能力 |
| **武器修改** | 修改武器属性 | 自定义游戏体验 |

## 三、Unity API详细分析

### 3.1 GiveWeapon API

**完整签名**:
```cpp
Weapon GiveWeapon(Player player, Int32 weaponIndex, Boolean autoGiveUp, Boolean autoSelect);
```

**字符串地址**: 0x10054918

**参数说明**:

| 参数 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `player` | Player | 目标玩家对象 | 本地玩家实例 |
| `weaponIndex` | Int32 | 武器ID/索引 | 0=AK47, 1=M4A1... |
| `autoGiveUp` | Boolean | 是否自动放弃当前武器 | true=放弃, false=保留 |
| `autoSelect` | Boolean | 是否自动选中 | true=立即装备, false=放入背包 |
| **返回值** | Weapon | 创建的武器对象 | 新武器实例 |

**功能说明**:
- 在玩家背包中创建指定ID的武器
- 可选择是否替换当前武器
- 可选择是否立即装备
- 返回新创建的武器对象

### 3.2 GiveWeaponByBag API

**完整签名**:
```cpp
Weapon GiveWeaponByBag(Player player, Int32 weaponIndex);
```

**字符串地址**: 0x10054974

**参数说明**:

| 参数 | 类型 | 说明 |
|------|------|------|
| `player` | Player | 目标玩家对象 |
| `weaponIndex` | Int32 | 武器ID |
| **返回值** | Weapon | 创建的武器对象 |

**功能说明**:
- 从背包系统给予武器
- 不涉及当前武器替换
- 适用于背包管理系统

### 3.3 GetWeapon API

**完整签名**:
```cpp
Weapon GetWeapon(Int32 weaponIndex);
```

**字符串地址**: 0x100549b0

**参数说明**:

| 参数 | 类型 | 说明 |
|------|------|------|
| `weaponIndex` | Int32 | 武器索引 |
| **返回值** | Weapon | 武器对象 |

**功能说明**:
- 获取指定索引的武器对象
- 用于查询武器属性
- 不创建新武器

### 3.4 SetCurrentWeapon API

**完整签名**:
```cpp
Void SetCurrentWeapon(Int32 slot, Weapon wpn);
```

**字符串地址**: 0x100549d8

**参数说明**:

| 参数 | 类型 | 说明 |
|------|------|------|
| `slot` | Int32 | 武器槽位 (0=主武器, 1=副武器...) |
| `wpn` | Weapon | 武器对象 |
| **返回值** | Void | 无返回值 |

**功能说明**:
- 设置当前激活的武器
- 更新武器槽位
- 触发武器切换动画

### 3.5 WPN_RecoverAmmo API

**字符串地址**: 0x10054a40

**功能说明**:
- 恢复武器弹药
- 用于无限弹药功能

```cpp
class WeaponManager {
private:
    Player* localPlayer;
    MethodInfo* giveWeaponMethod;
    MethodInfo* setCurrentMethod;
    MethodInfo* getWeaponMethod;
    
public:
    // 初始化
    bool Initialize() {
        // 获取本地玩家
        localPlayer = GetLocalPlayer();
        if (!localPlayer) {
            printf("[Error] Local player not found\n");
            return false;
        }
        
        // 获取方法
        Il2CppClass* playerWeaponsClass = il2cpp_class_from_name(
            "Assembly-CSharp",
            "PlayerWeapons"
        );
        
        giveWeaponMethod = il2cpp_class_get_method_from_name(
            playerWeaponsClass, "GiveWeapon", 4
        );
        
        setCurrentMethod = il2cpp_class_get_method_from_name(
            playerWeaponsClass, "SetCurrentWeapon", 2
        );
        
        getWeaponMethod = il2cpp_class_get_method_from_name(
            playerWeaponsClass, "GetWeapon", 1
        );
        
        if (!giveWeaponMethod || !setCurrentMethod || !getWeaponMethod) {
            printf("[Error] Failed to get weapon methods\n");
            return false;
        }
        
        printf("[Success] WeaponManager initialized\n");
        return true;
    }
    
    // 给予武器
    Weapon* GiveWeapon(int weaponID, bool autoGiveUp = true, bool autoSelect = true) {
        if (!localPlayer || !giveWeaponMethod) {
            printf("[Error] Not initialized\n");
            return nullptr;
        }
        
        // 调用GiveWeapon
        typedef Weapon* (*Func)(Player*, int, bool, bool, MethodInfo*);
        Func giveWeapon = (Func)giveWeaponMethod->methodPointer;
        
        Weapon* weapon = giveWeapon(
            localPlayer,
            weaponID,
            autoGiveUp,
            autoSelect,
            giveWeaponMethod
        );
        
        if (weapon) {
            printf("[Success] Weapon %d created\n", weaponID);
        } else {
            printf("[Error] Failed to create weapon %d\n", weaponID);
        }
        
        return weapon;
    }
    
    // 设置当前武器
    void SetCurrentWeapon(int slot, Weapon* weapon) {
        if (!localPlayer || !setCurrentMethod) {
            printf("[Error] Not initialized\n");
            return;
        }
        
        PlayerWeapons* weapons = GetPlayerWeaponsComponent(localPlayer);
        if (!weapons) return;
        
        typedef void (*Func)(PlayerWeapons*, int, Weapon*, MethodInfo*);
        Func setCurrent = (Func)setCurrentMethod->methodPointer;
        
        setCurrent(weapons, slot, weapon, setCurrentMethod);
        printf("[Info] Weapon set to slot %d\n", slot);
    }
    
    // 获取武器
    Weapon* GetWeapon(int weaponIndex) {
        if (!getWeaponMethod) return nullptr;
        
        PlayerWeapons* weapons = GetPlayerWeaponsComponent(localPlayer);
        if (!weapons) return nullptr;
        
        typedef Weapon* (*Func)(PlayerWeapons*, int, MethodInfo*);
        Func getWeapon = (Func)getWeaponMethod->methodPointer;
        
        return getWeapon(weapons, weaponIndex, getWeaponMethod);
    }
    
    // 无限弹药
    void SetInfiniteAmmo(bool enable) {
        Weapon* currentWeapon = GetCurrentWeapon(localPlayer);
        if (!currentWeapon) return;
        
        const int AMMO_CLIP_OFFSET = 0x04;
        const int AMMO_RESERVE_OFFSET = 0x08;
        
        if (enable) {
            *(int*)(currentWeapon + AMMO_CLIP_OFFSET) = 9999;
            *(int*)(currentWeapon + AMMO_RESERVE_OFFSET) = 9999;
        }
    }
    
    // 一键获取并装备武器
    Weapon* QuickGiveWeapon(int weaponID, int slot = 0) {
        // 1. 给予武器
        Weapon* weapon = GiveWeapon(weaponID, true, true);
        if (!weapon) return nullptr;
        
        // 2. 设置到指定槽位
        SetCurrentWeapon(slot, weapon);
        
        // 3. 启用无限弹药 (可选)
        if (IsInfiniteAmmoEnabled()) {
            SetInfiniteAmmo(true);
        }
        
        return weapon;
    }
};
```

```cpp
WeaponConfig g_weaponConfig;

void LoadWeaponConfig() {
    std::ifstream file("esp_config.ini");
    std::string line;
    
    while (std::getline(file, line)) {
        if (line.find("WeaponID=") == 0) {
            g_weaponConfig.weaponID = std::stoi(line.substr(9));
        }
        else if (line.find("InfiniteAmmo=") == 0) {
            g_weaponConfig.infiniteAmmo = (line.substr(13) == "1");
        }
        else if (line.find("AutoGiveUp=") == 0) {
            g_weaponConfig.autoGiveUp = (line.substr(11) == "1");
        }
        else if (line.find("AutoSelect=") == 0) {
            g_weaponConfig.autoSelect = (line.substr(11) == "1");
        }
        else if (line.find("WeaponSlot=") == 0) {
            g_weaponConfig.weaponSlot = std::stoi(line.substr(11));
        }
    }
    
    file.close();
}

void SaveWeaponConfig() {
    std::ofstream file("esp_config.ini");
    
    file << "[Weapon]\n";
    file << "WeaponID=" << g_weaponConfig.weaponID << "\n";
    file << "InfiniteAmmo=" << (g_weaponConfig.infiniteAmmo ? "1" : "0") << "\n";
    file << "AutoGiveUp=" << (g_weaponConfig.autoGiveUp ? "1" : "0") << "\n";
    file << "AutoSelect=" << (g_weaponConfig.autoSelect ? "1" : "0") << "\n";
    file << "WeaponSlot=" << g_weaponConfig.weaponSlot << "\n";
```
