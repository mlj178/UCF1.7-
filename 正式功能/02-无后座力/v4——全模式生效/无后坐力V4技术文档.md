## 🔄 二、版本迭代记录

### 2.1 V1 版本 - 基础版

**实现思路**：
- Hook `Recoil$$OnGunShot` 函数
- 使用 `Player$$get_isMyPlayer` 判断玩家
- 跳过原函数实现无后坐力

**代码实现**：
```javascript
// V1 核心代码
Interceptor.attach(ADDR_RECOIL_ONGUNSHOT, {
    onEnter: function (args) {
        var recoilPtr = args[0];
        // 尝试调用 Player$$get_isMyPlayer
        if (Player_get_isMyPlayer(recoilPtr, ptr(0))) {
            // 跳过原函数
        }
    }
});
```

**遇到的问题**：
1. ❌ **指针类型错误**：`Recoil$$OnGunShot` 的 `this` 是 `Recoil*`，不是 `Player*`
2. ❌ **游戏崩溃**：调用 `Player$$get_isMyPlayer(recoilPtr)` 导致内存访问违规
3. ❌ **掉帧严重**：使用 `Interceptor.attach` 而非 `replace`，性能差

**失败表现**：
- 游戏秒退
- 后坐力仍然存在
- 帧率下降 30%+

---

### 2.2 V2 版本 - 时间重置版

**实现思路**：
- 使用 `playerWeaponSet` 缓存武器指针
- 添加时间重置机制（5 分钟超时）
- 添加定期清理（10 分钟）

**代码实现**：
```javascript
// V2 核心代码
var playerWeaponSet = {};
var lastResetTime = Date.now();

function isPlayerWeapon(weaponPtr) {
    var key = weaponPtr.toString();
    if (playerWeaponSet[key]) return true;
    
    var count = Object.keys(playerWeaponSet).length;
    if (count < 2) {
        playerWeaponSet[key] = { time: Date.now(), count: count + 1 };
        return true;
    }
    
    // 5 分钟超时重置
    if (Date.now() - lastResetTime > 5 * 60 * 1000) {
        resetWeaponSet();
        return true;
    }
    
    return false;
}
```

**遇到的问题**：
1. ❌ **奇偶次失效**：换房间后 `playerWeaponSet` 未正确重置
2. ❌ **模式限制**：只有团队模式有效，其他模式无效
3. ❌ **缓存污染**：Bot 武器指针被误识别为玩家武器

**失败表现**：
```
第 1 局：新武器 → 识别成功 ✅
第 2 局：新武器 → 识别失败 ❌（playerWeaponSet 已满）
第 3 局：新武器 → 识别成功 ✅（10 分钟超时重置）
第 4 局：新武器 → 识别失败 ❌（又满了）
```

### 2.3 V3 版本 - 终极版（失败）

**实现思路**：
- 使用 `Weapon$$get_isMyWeapon` 实时判断
- 不依赖缓存，每次调用游戏 API
- 支持所有游戏模式

**代码实现**：
```javascript
// V3 核心代码（错误）
var Weapon_get_isMyWeapon = new NativeFunction(
    ADDR_WEAPON_IS_MY,  // 0xB6E1D0
    "bool",
    ["pointer", "pointer"]
);

Interceptor.replace(ADDR_RECOIL_ONGUNSHOT, new NativeCallback(function (recoilThis, methodInfo) {
    // ❌ 错误：recoilThis 是 Recoil*，不是 Weapon*
    if (Weapon_get_isMyWeapon(recoilThis, ptr(0))) {
        // 无后坐力
    }
}, "void", ["pointer", "pointer"]));
```

**遇到的问题**：
1. ❌ **指针类型不匹配**：`Recoil$$OnGunShot` 的 `this` 是 `Recoil*`，但 `Weapon$$get_isMyWeapon` 期望 `Weapon*`
2. ❌ **判断失败**：所有武器都被认为是 Bot 武器
3. ❌ **完全无效**：无后坐力效果不生效

**失败表现**：
```
[*] Weapon get_isMyWeapon @ 0x6a16e1d0
[+] Weapon_get_isMyWeapon created successfully
[Fire] GunShoot - Weapon: 0x12345678 - Player: false  ← 全部识别为 false
[Fire] GunShoot - Weapon: 0x23456789 - Player: false  ← 全部识别为 false
```

**根本原因分析**：
```
Recoil 类继承链：
Recoil : MonoBehaviour  ← this 指针类型

Weapon 类继承链：
WPN_Gun : Weapon : MonoBehaviour  ← get_isMyWeapon 期望的类型

调用 Weapon$$get_isMyWeapon(recoilThis) 时：
- recoilThis 是 Recoil* 对象
- 但函数期望 Weapon* 对象
- 导致内存布局不匹配，判断失败
```

### 2.4 V4 版本 - 修复版（✅ 成功）

**实现思路**：
- 放弃调用游戏 API（指针类型问题）
- 使用缓存策略识别玩家 Recoil
- 直接清零后坐力字段（简单有效）

**代码实现**：
```javascript
// V4 核心代码（正确）
var playerRecoilSet = {};

function isPlayerRecoil(recoilPtr) {
    var key = recoilPtr.toString();
    if (playerRecoilSet[key]) return true;
    
    var count = Object.keys(playerRecoilSet).length;
    if (count < 2) {
        playerRecoilSet[key] = true;
        console.log("[+] Player recoil detected: " + recoilPtr);
        return true;
    }
    
    return false;
}

Interceptor.replace(ADDR_RECOIL_ONGUNSHOT, new NativeCallback(function (recoilThis, methodInfo) {
    if (isPlayerRecoil(recoilThis)) {
        // ✅ 直接清零后坐力字段
        recoilThis.add(0x68).writeFloat(0.0);  // addYaw
        recoilThis.add(0x6C).writeFloat(0.0);  // addPitch
        recoilThis.add(0x70).writeFloat(0.0);  // addYaw_Target
        recoilThis.add(0x74).writeFloat(0.0);  // addPitch_Target
    }
    
    // 不执行原函数
}, "void", ["pointer", "pointer"]));
```

**成功关键**：
1. ✅ **指针类型正确**：直接操作 `Recoil*` 对象，不调用其他类的方法
2. ✅ **字段清零**：直接写入 0.0 到后坐力字段
3. ✅ **缓存策略**：前 2 个 Recoil 认为是玩家的（简单有效）

**成功表现**：
```
[+] Player recoil detected: 0x12345678 (#1)
[Suppress 1] Player recoil zeroed @ 0x12345678
[Suppress 2] Player recoil zeroed @ 0x12345678
[Suppress 3] Player recoil zeroed @ 0x12345678
...
[Bot 1] Bot recoil allowed @ 0x87654321  ← Bot 正常
```

## 🎮 四、游戏逻辑分析

### 4.1 Recoil 系统工作流程

```
玩家开枪
  ↓
WPN_Gun$$GunShoot()  // 0xB624C0
  ↓
Recoil$$OnGunShot()  // 0xB19980  ← Hook 点
  ↓
计算后坐力：
  - addYaw (0x68)   ← Yaw 方向后坐力
  - addPitch (0x6C) ← Pitch 方向后坐力
  - addYaw_Target (0x70)   ← 目标 Yaw
  - addPitch_Target (0x74) ← 目标 Pitch
  ↓
应用到相机
  ↓
相机抖动（后坐力效果）
```

### 4.2 玩家 vs Bot 识别逻辑

```
游戏启动
  ↓
创建玩家武器（2 把）
  ↓
创建 Bot 武器（N 把）
  ↓
每把武器都有 Recoil 组件
  ↓
Recoil$$OnGunShot 被调用时：
  - 玩家 Recoil：前 2 次调用
  - Bot Recoil：后续调用
```

### 4.3 换房间逻辑

```
房间 1：
  - 玩家 Recoil: 0x12345678, 0x23456789
  - Bot Recoil: 0x34567890, 0x45678901, ...

换房间（游戏进程不退出）：
  - 旧 Recoil 对象销毁
  - 新 Recoil 对象创建：0x56789012, 0x67890123
  - Bot Recoil: 0x78901234, 0x89012345, ...

V4 处理：
  - playerRecoilSet 缓存新指针
  - 前 2 个新 Recoil 识别为玩家
  - 无后坐力继续生效
```

### 4.4 不同模式的差异

| 模式 | 武器数量 | Recoil 数量 | 识别难度 |
|------|---------|------------|---------|
| **团队模式** | 2 把（玩家）+ 10 把（Bot） | 12 个 | 低 |
| **爆破模式** | 2 把（玩家）+ 8 把（Bot） | 10 个 | 中 |
| **个人模式** | 1 把（玩家）+ 15 把（Bot） | 16 个 | 高 |

**V4 适配**：
- 缓存前 2 个 Recoil（覆盖所有模式）
- 不依赖固定数量判断
- 自动适应不同模式

## 📝 七、踩坑总结

### 7.1 主要坑点

| 坑点 | 版本 | 原因 | 解决方案 |
|------|------|------|---------|
| **游戏崩溃** | V1 | 指针类型错误 | 改用 `replace` + 正确指针 |
| **掉帧严重** | V1 | 使用 `attach` | 改用 `replace` |
| **奇偶次失效** | V2 | 缓存未重置 | 改为 Recoil 缓存 |
| **模式限制** | V2 | 武器识别逻辑 | 改为 Recoil 缓存 |
| **完全无效** | V3 | 指针类型不匹配 | 放弃 API 调用 |
| **字段偏移错误** | V1-V3 | 未查看 dump.cs | 查看 dump.cs 确认偏移 |

### 7.2 关键教训

1. **指针类型必须匹配**：`Recoil*` ≠ `Weapon*` ≠ `Player*`
2. **优先使用 `replace` 而非 `attach`**：性能差异巨大
3. **简单策略往往最有效**：缓存前 2 个 Recoil 比复杂 API 调用更可靠
4. **查看游戏源码**：`dump.cs` 是理解游戏逻辑的关键
5. **测试所有模式**：不同模式可能有不同的对象创建顺序
