# 全模式房间人数：两行右侧布局设计

## 目标

优化整合包 2.5“其他”页中“全模式房间人数”卡片的可读性与位置，不改变已经实现的显式开关、手动应用和关闭恢复行为。

## 网格位置

- 卡片使用两列网格右侧的两行高度（`rowspan: 2`）。
- 它位于“游戏模式切换”正下方；第一行与“第三人称视角”的下半部分相邻，第二行位于“人体穿墙”的右侧。
- 目标排列为：第三人称视角 / 游戏模式切换、第三人称视角 / 全模式房间人数、人体穿墙 / 全模式房间人数。

## 卡片内容

- 第一行：功能名称与开关。
- 第二行：人数数值与滑块。滑块不与名称并列。
- 第三行显示说明：`功能说明：开启后，设置总人数并点击“应用人数”。人数在下一局开始时生效；关闭功能会立即恢复默认人数。`
- 最后一行保留当前的状态提示与“应用人数”按钮。

## 验证

- 新增静态测试，检查 `rowspan`、滑块的独立容器和用户说明文案。
- 先在旧布局上运行测试并确认失败，再修改清单与面板。
- 完成后运行房间人数静态测试及 Python 语法检查。
