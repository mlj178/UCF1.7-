# Bot Pause Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the standalone `25-人机暂停` feature that pauses and resumes all bots by writing `Bot.stopAllBot`.

**Architecture:** Keep the feature as a single-function delivery under `05-正式功能/25-人机暂停`. The Frida script reads `Bot_TypeInfo`, follows `static_fields`, and writes the `stopAllBot` byte through RPC calls; the CustomTkinter UI handles attach/load/toggle/status/cleanup.

**Tech Stack:** Frida JavaScript, Python `customtkinter`, `frida`, `psutil`, and `unittest` static checks.
