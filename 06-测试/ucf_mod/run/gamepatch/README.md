# run\gamepatch —— 游戏本体补丁包

> **一句话**：游戏目录里本该由我们负责的"本体改动"，全都在这里，一个目录一张图。
> 这些东西以前只存在于游戏目录（`UnityCrossFire_Data\*`），删了就永久没了；现在进 git、进分发包。

## 一、目录规则

```
run\gamepatch\
├─ _index.json              总表：有哪些包、对应哪个开关、多少字节
├─ <序号>_<场景名><中文名>\   一个包 = 一张图
│  ├─ patch.json            唯一权威：目标文件、原版哈希、补丁后哈希
│  ├─ README.md             人读的说明（为什么这么改）
│  └─ UnityCrossFire_Data\  文件按"游戏内相对路径"摆，部署器直接 src→game/<rel>
└─ README.md
```

## 二、部署语义（三态）

对 `patch.json` 里每个 `files[]`：

| 目标文件当前状态 | 部署器做什么 |
| --- | --- |
| 不存在，且 `orig` 为 null | 新增（新地图文件） |
| `sha256 == orig.sha256` | 备份 → 覆盖 → 校验 `sha256` |
| `sha256 == files[].sha256`（已经是我们的） | 跳过（幂等，重复点=修复） |
| 其他（原版对不上，也不是我们的） | **拒绝并说明**，绝不盲打 |

卸载：只还原有 `orig` 的、且哈希还是我们那份的文件；新增文件直接删。

## 三、开关映射

`patch.json` 的 `switch` 字段 = 控制台「插件开关 → 地图」里那一行：

| switch | 页面文案 | 注入 | 本体补丁 |
| --- | --- | --- | --- |
| `hidden_map` | 加载暴风地图（飓风危城） | Nano30_Storm，多人终结者（mode 6），追加 | `level9` 192,144 B |
| `map_longcheng` | 加载龙城 | TestMap12，团队模式（mode 0），**第 4 项** | `level12` + `sharedassets12*` + `globalgamemanagers` |

## 四、为什么 storm 走"改文件"（方案 A）

- 效果 = 文件状态，**可以静态校验**（算哈希就知道在不在），不依赖运行时时机；
- 项目里已有备份 / manifest / 写后校验 / 卸载还原全套设施，加一个文件就行；
- storm 这张图本来就是插件注入才存在的，不存在"没装插件也要有这个效果"的场景。

运行时 `SetActive` 方案（B）留作应急预案，不在默认路径里。
