## 为什么不改 `sharedassets0.assets`

老做法：在那个 70 MB 文件的注册表里把第 3 项 `Cebu_City / 椰岛之巅` 换成 `TestMap12 / 测试地图`
（19 字节等长替换）。副作用是**顶掉椰岛之巅**，而且要把 70 MB 的文件纳入补丁管理。

现在改成**插件注入第 4 项**：`src\plugin.c` 在 `UI_GameRoom` 的地图数组末尾追加一条
`{scene: "TestMap12", label: "龙城"}`，按 `game_mode` 过滤。团队模式 = `GameMode.TeamDeath = 0`
（`dump.cs` 第 235472 行）。**`sharedassets0.assets` 一个字节都不用动。**

## 验收

1. 部署包 4 件哈希全对；
2. 进游戏 → 创建房间 → 团队模式 → 下拉第 4 项「龙城」→ 能进、能站、能开枪、不出彩虹噪点；
3. 第 1~3 项（运输船 / 小型工厂 / 椰岛之巅）仍在。
