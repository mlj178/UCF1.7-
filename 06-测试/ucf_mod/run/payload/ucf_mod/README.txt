UCF 插件 · 怎么用
============================================================

一句话：想带 mod 玩，从「启动控制台」里点开始游戏；
        直接双击 UnityCrossFire.exe 就是原版，插件不介入。

这个文件夹（游戏目录里的 ucf_mod）
------------------------------------------------------------
  游戏运行时要读的东西全在这里，游戏自己会读。
  平时你不用打开这个文件夹。

  ucf_mod.dll     插件本体
  ucf_mod.json    配置（场景 / 标签 / 模式）
  log\            日志都在这里（见下面「日志」一节）
  markers\        人机蹲守点（纯文本，可以手改）
  backup\         只有 level9.orig（卸载时还原场景用）
  uninstall.ps1   卸载

  日志（2026-11-23 起）：从「启动控制台」进游戏时，日志写在**工程端**
  D:\trae_project\ucf1.7-modifier\06-测试\ucf_mod\log\ —— 这个文件夹里不会生成日志。
  直接双击 exe 或别人机器上没有工程端时，才写到这个文件夹的 log\ 里
  （ucf_mod.log / autotest.txt / player_marks.txt；日志超过 16 MB 自动轮转成
  ucf_mod.prev.log，只留 1 代）。出问题就把 log 文件夹整个发我。

  2026-11-21 起导航数据不在这里：9 张图的 map.json / navmesh.bin 都在工程端
  navdata\（native 备份 / dev 开发），控制台启动游戏时用环境变量指过去；
  这个文件夹只剩 dll / 配置 / markers，旧的 nav\ maps\ vis\ 已清空。

我想干什么 → 去哪
------------------------------------------------------------
  想玩（带 mod）    双击 console\启动控制台.bat → 点「开始游戏（加载 mod）」
  想玩原版          直接双击 UnityCrossFire.exe（插件完全不介入）
  想试一条新路线    控制台「数据」页 → 编辑中选「图 + 包」→ 开始游戏
                     （只对那一张图生效；不行就换回「成品」）
  想改路点          游戏里按 F2 用菜单加点/连线（保存后重进图生效）；
                    或在控制台「人机路点」页建测试包；浏览器端只读，不能改
  我画的要生效    控制台「数据」页 → 选 编辑中/成品 → 开始游戏
  想撤销改动      控制台 →「数据」页 → 还原原生 ①→②（开发版退回原版）
  改功能 / 修 bug   跟我说，别自己动手
  出问题了          把 log\ucf_mod.log 发我（整个 log 文件夹更全）

另一个文件夹是干什么的
------------------------------------------------------------
  D:\trae_project\ucf1.7-modifier\06-测试\ucf_mod
  那是源码 + 备份（代码、历史、工具都在这）。
  不放在游戏目录，是因为：重装游戏会把它一起删掉、会被游戏扫描拖慢、也没法回滚。
  所以 —— 你不用进去，我看着就行。

现在有哪些功能（截至 2026-11-20）
------------------------------------------------------------
  1. 隐藏地图      往房间地图列表里塞一张「暴风」，下拉框能选
  2. 人机路点      图里一个路点都没有时，进图自动铺满并自动连线
  3. 人机蹲点      图里没有蹲守点时自动补；也可以手工放
  4. 幽灵守卫区    给幽灵人机凭空造巡逻区（暴风图专用）
  5. 可视化        按 Ctrl+V 把路点 / 连线 / 出生点画进游戏
  6. 游戏内编辑    放蹲守点、删标记、改路点、存档、重载
  7. 手动导出      游戏里 Ctrl+E，把当前图导成 JSON 到工程端开发版 ②（navdata\dev\vis）
  8. 网页工作台    浏览器里看 2D / 3D / 可走面（只读；2026-11-18 起不能改）
  9. 编辑中/成品   进图前选「编辑中（包）/ 成品（版本）」，编辑中可勾「只对哪张图生效」，
                    控制台「人机路点」页建测试包（落工程端 navdata\dev\packs）；
                    满意后 navdata.py pack promote 进成品（final），控制台切「成品」再开始游戏
 10. 跳跃点        游戏里 F2 开路点菜单 → 1 添加路点 → 2 跳跃点：
                     （准星上有虚线框预览，虚线框=将要放的位置，灰框=这里放不了）
                     第 1 下：对准「起跳处」，小键盘 5（必须站在路点上，3 米内吸附）
                     第 2 下：对准「落点」，小键盘 5 → 落点没路点会自动补一个，
                             并自动补一条 起点->落点 的连线（跳链靠这条线才生效）
                     两端至少要隔 1.5 米；建好就写进当前这个包，重进图自动重建。
                     为什么要有连线：人机只有在路径里「起点下一步就是落点」时才起跳，
                     没有连线 = 永远不触发（这一点以前没说清，2026-11-20 修）。
                     另外两端都要走得通：起点要连进主图（不然 Bot 到不了起跳点），
                     落点要接上别的路（不然跳过去是死胡同，除非落点就是目标）。

  开关在哪改，以及怎么带 mod 玩
  ------------------------------------------------------------
    双击：D:\trae_project\ucf1.7-modifier\06-测试\ucf_mod\console\启动控制台.bat
    弹出窗口里勾选，存进 ucf_mod.json，下次进游戏生效。

    也可以直接用记事本改 ucf_mod.json 里的 features 段，
    改完在 log\ucf_mod.log 开头能看到 [cfg] 那一块，确认真的读到了。

    原版 / mod 的分别（2026-11-16 19:00 起）
      控制台启动  → 给游戏递一张通行证（环境变量 UCF_MOD=1）→ 插件工作
      直接开 exe  → 没有通行证 → 插件第一时间返回，等于没装

  还没做 / 不可用：
      补给箱 SP_RedBox / SP_BlueBox、部分出生点注册
      暴风图偶尔有 bot 卡在出生洞穴

游戏内快捷键
------------------------------------------------------------
  F2      人机路点菜单（1 添加路点 / 2 建立路径 …；小键盘 8/2/5/0 操作）
            选好类型后会停在类型页：5 可以一直放同一种点，1-6 换类型，Esc 只退一级（连续编辑，2026-11-20）
  方向显示    连路点时：起点 A = 绿色方块+竖条，落点框红色；单向连线有橙色箭头（只画单向、只在菜单打开时显示）
  Ctrl+1  编辑模式开关          Ctrl+2  在准星地面放蹲守点
  Del     删除准星最近标记      Ctrl+0  显示/隐藏标记球
  Ctrl+V  导航可视化总开关      Ctrl+H  快捷键面板
  Ctrl+Shift+X   只读采集（只导出路点，不改游戏）
  Ctrl+Shift+L   文字标签：关 / 近距 / 全部
  Ctrl+Shift+7   方向罗盘开关（屏幕下方：每 10° 一刻度，北东南西四个字永远正着）
