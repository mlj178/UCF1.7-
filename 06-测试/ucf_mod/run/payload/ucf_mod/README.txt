UCF 插件 · 怎么用
============================================================

一句话：想带 mod 玩，从「启动控制台」里点开始游戏；
        直接双击 UnityCrossFire.exe 就是原版，插件不介入。

工程端（源码 / 配置 / 日志 / 路点 / 地图数据）
------------------------------------------------------------
  D:\trae_project\ucf1.7-modifier\06-测试\ucf_mod

  插件本体、ucf_mod.json、ucf_navcmd.txt、日志、路点、地图数据全在这里。
  游戏目录不再生成 ucf_mod\，也不放这些文件。

游戏目录（只放"必须有的文件"）
------------------------------------------------------------
  winhttp.dll        代理加载器（唯一必须留在游戏目录的入口）
  winhttp_orig.dll   系统 winhttp 的副本（转发目标）
  UnityCrossFire_Data\level9 等   游戏本体补丁（按开关部署）

  没有 ucf_mod\、没有 ucf_mod.dll、没有 README / uninstall / manifest。

我想干什么 → 去哪
------------------------------------------------------------
  想玩（带 mod）    双击 启动控制台.bat → 「部署」页选游戏 → 一键部署 → 开始游戏
  想玩原版          直接双击 UnityCrossFire.exe（插件完全不介入）
  第一次用          控制台「部署」页 → 选择 UnityCrossFire.exe → 一键部署
  想试一条新路线    控制台「人机路点」→ 选图 → 开始编辑这张图 → 开始游戏
                      （一张图一个草稿；不行就切回「成品」）
  想改路点          游戏里按 F2 用菜单加点/连线（保存后重进图生效）；
                     或在控制台「人机路点」页开始编辑这张图；浏览器端只读，不能改
  我画的要生效      控制台「人机路点」→ 发布这张图到成品 → 切「成品」→ 开始游戏
  想撤销改动        控制台 →「数据」页 → 还原原生 ①→②（开发版退回原版）
  出问题了          把工程端 log\ucf_mod.log 发我（整个 log 文件夹更全）
  想卸载            控制台「部署」页 → 卸载；或
                     python app\tabs\deploy\deploy_mod.py --game-exe "D:\...\UnityCrossFire.exe" --uninstall

一键部署会做什么
------------------------------------------------------------
  1) 读系统 winhttp，生成游戏目录的 winhttp_orig.dll；
  2) 把工程端 run\payload\winhttp.dll 铺到游戏目录（覆盖前备份到工程端）；
  3) 按 run\gamepatch\<包>\patch.json 铺游戏本体补丁：
     目标原版哈希对不上就拒绝，绝不盲打；
  4) 部署清单 / 备份 / 还原都在工程端，不写游戏目录。

  已装过的再点一次 = 修复：哈希一致的跳过，不会重复拷。

日志（2026-11-23 起）
------------------------------------------------------------
  主位置是工程端 log\ucf_mod.log（超过 16 MB 自动轮转成 ucf_mod.prev.log，只保 1 代）。
  控制台启动游戏时用 UCF_LOG_DIR 指过去，所以游戏目录不生成日志。
  没走控制台启动时，插件落 %LOCALAPPDATA%\UCFMod\log 或 %TEMP%\ucf_mod\log，
  同样不写游戏目录。

现在有哪些功能（截至 2026-11-25）
------------------------------------------------------------
  1. 隐藏地图      往房间地图列表里塞一张「暴风」，下拉框能选
  2. 人机路点      图里一个路点都没有时，进图自动铺满并自动连线
  3. 人机蹲点      图里没有蹲守点时自动补；也可以手工放
  4. 幽灵守卫区    给幽灵人机凭空造巡逻区（暴风图专用）
  5. 可视化        按 Ctrl+V 把路点 / 连线 / 出生点画进游戏
  6. 游戏内编辑    放蹲守点、删点位/区域、改路点、改出生点、Ctrl+S 存档、重载
                   （存档必须手动按 Ctrl+S；不按就退出房间 = 这次改动全部丢弃）
  7. 手动导出      游戏里 Ctrl+E，把当前图导成 JSON 到工程端 ②（navdata\dev\vis）
  8. 网页工作台    浏览器里看 2D / 3D / 可走面（只读）
  9. 编辑中/成品   一张图一个草稿、一份成品；发布 = 覆盖同图那份
 10. 跳跃点        F2 菜单 → 1 添加点位 → 2 跳跃点（两端要连线才触发）
 11. 出生点编辑     F2 → 1 添加点位 → 4/5 出生点 BL/GR（准星落点 + 当前朝向）
                   F2 → 5 删除点位 → 5/6 删出生点（准星对准；至少保留 1 个）
                   改的是运行时 SP_BL/SP_GR 数组，不写原图；Ctrl+S 后才写进 markers.txt，
                   下次进图自动重套。

游戏内快捷键
------------------------------------------------------------
  F2      人机路点菜单（小键盘 8/2/5/0 操作）
  F2 → 5  删除点位（按类型：1 蹲守点 2 守卫点 3 跳链 4 标签 5 出生点BL 6 出生点GR 7 任意）
          └ 1-7 选类型，小键盘5 / Enter / Delete 删当前类型，可连续删
  F2 → 6  删除区域（守卫区；连同它下面的守卫点一起删）
  F2 → 8  撤销 / 保存（3 = 保存，等同 Ctrl+S）
  Ctrl+S  保存全部（唯一保存方式；不按 Ctrl+S 就退房间 = 改动丢弃）
  Ctrl+1  编辑模式开关          Ctrl+2  在准星地面放蹲守点
  Del     删除准星最近的标记    Ctrl+0  显示/隐藏标记球
  Ctrl+V  导航可视化总开关      Ctrl+H  快捷键面板
  Ctrl+Shift+X   只读采集        Ctrl+Shift+L   文字标签
  Ctrl+Shift+7   方向罗盘开关
