## 口径

> 实际程序比 `demo.html` 多一个「编辑中」筛选：刚建、0 点改动的草稿不再算「待发布」，避免待发布列表里全是空草稿。

- **备份①** = `native` 原生底图 + `archive/final_prev` 发布快照数（最多 5 份）。
- **编辑中** = `packs/<地图文件夹>` 里唯一草稿；0 点改动 = 编辑中，有改动且未发布 = 待发布。
- **成品** = `final/<指纹>.txt`；没有就未发布。
- **部署 / 游戏加载** = 按当前启动档算：成品档看 final；编辑中档只加载当前选中图的草稿，其余图原生。**部署是全局插件，不是把地图拷进游戏目录。**
- 状态：
  - 已同步：草稿 sha256 = 成品 sha256
  - 待发布：有草稿改动，没成品或两者 sha256 不同
  - 编辑中：有草稿但还没有 0 点改动
  - 只有成品：有成品、无草稿
  - 未开始：两者都没有（原生底图还在）
  - 无点图：没有 map.json / PointGraph（只有 navmesh）
