这里不是画出来的样稿，是**真实控制台窗口的截图**（`App(role="dev")`，用户当前数据）。
用途：定「编辑中这张图怎么删」的入口位置、颜色、两态和确认文案。

| 文件 | 内容 |
|---|---|
| `01_整窗_编辑中.png` | 整窗：路点数据 → 人机路点 → 编辑中 → 本图草稿，看入口在页面里的位置 |
| `02_本图草稿_删除入口.png` | 有草稿：右边依次是「本图标记：守卫区 9」+ 琥珀色「清空本图标记」+ 红色「删除本图草稿」 |

## 设计要点

- 放在 `本图草稿` 卡片右侧危险区，不和橙色「重置本图草稿」挨着：
  重置 = 只清内容（草稿还在），删除 = 整份挪走（这张图回到「还没有草稿」）。
- 危险色沿用控制台的 `#8a1c1c`（成品页「撤销这张图的发布」同色）；
  悬停 `#a32424`；禁用 `#3a3f47`。
- 有草稿时蓝色主按钮就是「打开草稿目录」，灰色那个同名按钮收起来（原来两个一模一样的按钮）。
- **草稿 ≠ 标记**：守卫区 / 守卫点 / 蹲守点 / 标签 / 出生点 存在 `dev\markers\<图>\markers.txt`，
  **删除本图草稿时默认连它们一起清**（弹窗里的勾选框，默认勾上；取消勾选就只删草稿）；
  同一行也显示「本图标记：N」，并能单独「清空本图标记」。都挪到 `dev\archive\markers_trash\`。
- 删除不真删：整份挪到 `dev\archive\pack_trash\<图>__<时间>\`；
  成品 `final\<指纹>.txt` 不动。
- 确认框是自绘的（`ui/kit.py` 的 `confirm_danger`）：只有点红色「删除草稿」才算同意，
  标题栏 × / Esc / 「取消」都返回否。不用 `messagebox.askyesno` —— 实测它关窗返回「是」。

## 怎么重拍

```
python app/tools/_oneoff/shot_delete_draft_entry.py
```

脚本会起一次控制台、跳到编辑中页、截入口，再真弹一次确认框截完自动按「取消」，
最后换一张没草稿的图截置灰态。**全程不删任何文件**（弹窗走取消分支）。
