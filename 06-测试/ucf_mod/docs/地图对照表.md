## 这张表是怎么来的（证据，别删）

两条独立证据交叉验证，不是音译也不是猜的：

**证据 A —— 游戏自己的选图表**（`UnityCrossFire_Data\sharedassets0.assets` 里一段连续的字符串表，
每条是「模式名 / 场景名 / 中文名」）：

```
TeamDeath            TransportShip        运输船
Factory              Factory              小型工厂
Cebu_City            Cebu_City            椰岛之巅
DeathMatch           NY_TM                胜利广场
Special              Arena                竞技场
GrimReaperKM         GrimReaperKM         刀锋寨
Nano6/…              DesertFort           沙漠要塞
Nano4                NanoResort           生化酒店
Nano4_Terminator     Nano_DawnVillage     新寂静村
DeathRing            DeathRing            死亡擂台
```

**证据 B —— 每个场景文件里写着哪个场景名**（直接在 `UnityCrossFire_Data\levelN` 里搜到）：

```
level1  -> TransportShip      level7  -> DesertFort
level2  -> Factory            level8  -> NanoResort
level3  -> Cebu_City          level9  -> Nano4 / Nano30_Storm（隐藏图）
level4  -> NY_TM              level10 -> Nano_DawnVillage
level5  -> Arena              level11 -> DeathRing
level6  -> GrimReaperKM
```

两边一对就是上表。`level9` 的官方名在选图表里没有单独一项（它是插件注进列表的隐藏图，
游戏里显示为 `隐藏地图 暴风`，配置在 `ucf_mod\ucf_mod.json` 的 `label`），所以这里写 **暴风**。

## 怎么改 / 怎么加

1. 直接改上面表格的「中文名」或「场景名」（保持 5 列，序号和关卡别乱动）；
2. 跑一次整理，让文件名和索引跟上：

   ```
   cd ucf_mod\tools
   python organize_maps.py --archive
   ```

3. 打开编辑器（`启动导航编辑器.bat`）就能看到新名字。

说明：

- `maps\` 里的文件名 = `序号_中文名.json`，改了名字脚本会写新文件，旧文件留在 `backup\` 里不会丢。
- `maps\INDEX.md` 和 `maps\_index.json` 是**自动生成**的（含节点数、是否有数据），别手改。
- 每个关卡在 `geo\web\` 里要有一份地形网格，编辑器 3D 才能显示；缺了就 `python geo2web.py <关卡>`。
