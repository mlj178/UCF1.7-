# 路点菜单「连续编辑」_2026-11-20

## 需求（用户原话）

> 控制台中进入游戏，菜单编辑节点和路线，编辑一次就退出了需要重新选择，没法接着继续，非常不方便。
> ……我想连续编辑。保持某一种类型的编辑，保持，除非想换了路点种类，再按 esc 回退一下。

确认过「退出」指的是 **F2 菜单弹回主菜单 / 菜单消失**，不是游戏对局退出。

## 根因

1. `menu_activate()` 里子菜单执行完就 `g_wpMenuSub = 0`：选完类型、选完方向、删一次，都弹回主菜单，
   实际用起来就是「编辑一次就退出，要重新选」。
2. 建立路径连完一条边 `g_wpLinkStep = 0`，画折线时每条边都要重新「2 建立路径 → 选方向 → 选 A」。
3. `menu_refresh()` 开头 `if (!g_menu) return;`：换图 / `overlay_reset()` 后 `g_menu` 被清 0，
   而 `g_wpMenuOpen` 还是 1，菜单**不再绘制**。此时按 F2 第一下只是把 open 清 0（看着像关了），
   第二下才重新出现 —— 用户看到的「菜单自己退出」，这条也占一部分。

## 改动（src/editor.c）

| 位置 | 改动 |
| --- | --- |
| `menu_sub_title()` | 标题跟随模式：`添加路点：连续放置中` / `建立路径：连续连线中` / `删除：选类型（可连续删）` |
| `menu_refresh()` | 菜单对象丢失时**就地重建**（`overlay_init()`，1 s 节流），不再静默消失；补「换类型 1-6 / 结束 0 · Esc，菜单不会关」提示 |
| `menu_activate()` | 子菜单 1（类型）/ 2（方向）执行后**不再回 `g_wpMenuSub = 0`**，停在原页；删除页（6）也不弹回 |
| `menu_back()` | Esc/0 分级：先结束放置（停在类型页）→ 再结束连线（停在方向页）→ 回主菜单 → 关菜单 |
| `menu_move()` | 连续模式里 `8/2` 直接换类型 / 换方向（高亮即生效，避免「高亮变了、按 5 还是旧类型」） |
| `nav_link_one()` | 连完一条边后 **A 自动前进到刚落下的 B**，可以接着连下一个点；自环只跳过、不退出连线模式 |

## 现在的操作流程

```
F2 → 1 添加路点 → 1 普通路点
  → 小键盘5 放第一个点（菜单停在类型页）
  → 挪准星，5 接着放（同一个类型）
  → 1-6 直接换类型
  → Esc：结束放置（仍在类型页）→ Esc：回主菜单 → Esc：关菜单

F2 → 2 建立路径 → 1 双向
  → 5 选 A → 走到 B → 5 连边（A 自动前进到 B）
  → 走到 C → 5 连 B->C ……（画折线不用重选 A）
  → Esc：结束连线（仍在方向页）→ 1-3 换方向 → Esc：回主菜单
```

## 验证

- 编译：`tools/build.ps1`，mingw gcc 15.2.0，`-Werror=unused-function/-variable` 全过。
- 静态检查：`g_wpMenuSub = 0` 只剩主菜单入口 / `menu_close` / `menu_back` 回主菜单三处。
- 现场测试（需要进图）：放 5 个点不重开菜单；连 A-B-C 三点两段；Esc 分级返回；换类型后按 5 用新类型。

## 现场实测（2026-11-20 21:22，车测进图 level7，插件无焦点投递 WM_APP+0x53 键）

```
21:22:10 wpmenu: open
21:22:11 wpmenu: brush=normal          ← 主键盘 1：选「普通路点」
21:22:12 wpmenu: brush=jump            ← 主键盘 2：直接换类型，菜单没关、没回主菜单
21:22:13 wpmenu: brush=normal          ← 主键盘 1：再换回来
21:22:14 naved: add refused: no free slot (graph full, 12 nodes)   ← 小键盘5 放第 1 个（这张图槽位满，失败）
21:22:14 naved: add refused: no free slot (graph full, 12 nodes)   ← 小键盘5 放第 2 个（仍在放置模式，连续）
21:22:15 wpmenu: 结束连续放置（类型 普通路点 记着，Esc 再按一次回主菜单）   ← Esc 第 1 下
21:22:16 wpmenu: close                 ← Esc 第 3 下（第 2 下回主菜单）
```

结论：两次「编辑」（加点失败也算一次确认）之间菜单**没有关闭、没有弹回主菜单**；Esc 分级符合预期。
加点本身失败是 level7 原生 12 点全可走、没有空槽位（README「加点前提」那条），与本次改动无关。
车测收尾 `RESULT PASS targets=1`。
