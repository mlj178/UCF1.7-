# 路点菜单：新建守卫区 / 加守卫点 加落点虚线预览_2026-11-26

## 用户需求（原话）

> 路点菜单中，新建守区，守卫点，没有预设，就是显示一下虚线，告诉用户，
> 如果你选择的话，将会落在这个位置。

## 之前是什么行为

虚影预览（`ghost`）本来就有：`ghost_tick` 在准星落点画一个虚线框，
「添加点位」开笔刷、以及「建立路径 / 跳跃点」连线时都会画。
但它的开关是 `g_wpArm || g_wpLinkStep` —— **只有「先选类型 → 再按 5 放置」的流程才有预览**。

「守卫区工具」（主菜单第 3 项）走的是另一条路：`menu_activate` 里选中哪项，
按 5 就**当场在准星处创建**（`make_area` / `make_nanopos`），
不设 `g_wpArm`，于是 `ghost_tick` 在那一页永远走 `ghost_hide()`：
**玩家只能看到一行菜单文字，没有任何落点提示，按下去才知道建在哪。**

## 改动

| 位置 | 改动 |
| --- | --- |
| `editor.c` `g_ghostPrev` / `wp_guard_preview()` | 新增「只预览」状态：菜单停在「守卫区工具」且高亮第 1/2 项时为真 |
| `ghost_tick()` 开关 | 条件加上 `wp_guard_preview()`：没开笔刷也能画框（菜单关掉 / 采集模式 / 挪到第 3、4 项仍然收起） |
| `ghost_tick()` 笔刷映射 | 第 1 项 → 笔刷 4（守卫区，3.0 m 蓝框）；第 2 项 → 笔刷 3（守卫点，0.66 m 绿框）。尺寸 / 颜色直接复用 `ghost_size` / `ghost_slot`，和实体标记同一套 |
| `ghost_tick()` 落点 | 预览也 `+0.05`（和 `menu_activate` 创建前的抬高一致），坐标行显示的数和真正建出来的差 2 cm 以内 |
| `ghost_tick()` 守卫区框的竖直位置 | `make_area_aid` 只改 `scale`、不动 BoxCollider 的 offset，即 3 m 立方体**以 transform 为中心**（上下各 1.5 m）。预览框按同样中心摆，否则「框底贴地」看着对、建出来却整体高 1.5 m |
| `menu_sub_title()` | 标题改成「守卫区工具（虚线框 = 预置落点）」，进页就知道有预览 |
| `menu_refresh()` | 这一页新增 2~3 行说明：守卫区尺寸 / 颜色 / 中心在准星；守卫点会挂到哪个区（`g_curArea` + `aid`）或「没有区 → 按 5 会先建一个区」；入口 / 逃跑点写明还没接。准星打不到地面时直说「虚线框不显示」 |
| `menu_refresh()` 坐标行 | 预览时也显示 `预置 (x y z)  仅预览 · 按 5 创建`；用现算的 `wp_guard_preview()` 判，8/2 挪走后不会留一行过期坐标 |
| `menu_activate()` | 进这一页写一行日志 `wpmenu: 守卫区工具 —— 选中项在准星处画虚线预置框（只预览），按 5 才创建`；创建路径**一行没改**（仍是立刻建 + `mke_note_add` 进撤销栈） |

**预览只画框**：`ghost_tick` 里没有任何 `make_area` / `make_nanopos` / `mke_note_add` /
`editor_dirty_mk` 调用，不创建对象、不进撤销栈、不弄脏「未保存」状态。

## 行为对照

| 场景 | 之前 | 现在 |
| --- | --- | --- |
| 进「守卫区工具」，高亮「新建守卫区」 | 只有文字，准星处什么都没有 | 准星落点出现 3.0 m **蓝色虚线立方体**（中心在该点），坐标行标注「仅预览」 |
| 高亮「加守卫点」 | 同上 | 0.66 m **绿色虚线框** + 说明会挂到哪个守卫区（没有区会先建区） |
| 按 5 / 左键 / 数字 | 立刻创建 | **一样立刻创建**（行为未变，只是先能看见落点） |
| 8/2 挪到「入口 / 逃跑点」 | 无反应（只写日志） | 虚线框收起 + 菜单写明「还没接」 |
| 准星朝天 / 打不到地面 | 无提示 | 无框 + 菜单写明原因 |
| 关闭菜单 / 换图 | —— | 框收起（`ghost_hide` / `ghost_reset` 清状态） |

## 边界与已知限制

- **入口 / 逃跑点（第 3、4 项）没有预览**：这两项本来就还没接（`entrance/escape not wired yet`），
  画个框反而误导，所以只做文字说明。
- 预览位置按**准星射线**取，按 5 时再打一次射线；两次之间玩家若大幅移动，落点会差一帧的距离。
  没有改成「按键时直接用上一帧的 `g_ghostPv`」——那会在准星已移开时把东西建到旧位置，更糟。
- 守卫区仍然「建完先不激活，等第一个守卫点挂上再激活」（2026-11-25 的修法没动）。
- 预览不进撤销栈；撤销只反做**真正创建过**的守卫区 / 守卫点（这一点由 `mke_*` 负责，见
  `撤销一步修复_2026-11-26.md`）。

## 进游戏核验清单

1. F2 → 3「守卫区工具」→ 高亮第 1 项：准星处应出现蓝色 3 m 虚线立方体，菜单显示「预置 (x y z) 仅预览 · 按 5 创建」；
2. 把准星慢慢扫过地面：框跟着走，且**框底/框体不歪**（走、跑、跳时都跟手）；
3. 按 5：守卫区建在框所在位置（拿标记球对照，误差应在几厘米内），虚线框继续留着可直接放下一个；
4. 8/2 挪到第 2 项：变成绿色 0.66 m 框，菜单写明挂到哪个 aid；按 5 建守卫点；
5. 8/2 挪到第 3/4 项：框收起，菜单写「还没接」；
6. 抬头朝天：不画框，菜单写「准星没打到地面」；关菜单：框立刻消失。
