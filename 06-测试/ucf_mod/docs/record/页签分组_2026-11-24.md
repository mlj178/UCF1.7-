# 页签分组（2026-11-24）

> 用户要求：控制台页签按功能分组。10 个平铺页签 → **4 组**，其中
> 「路点数据」「部署与测试」是一个数据链的上下游，「插件开关」四个都是写 ucf_mod.json 的开关。

## 1. 分组

| 组 | 组内页签 | 为什么放一起 |
| --- | --- | --- |
| **插件开关** | 地图 · 可视化 · 导出 · 快捷键 | 都是“进游戏后插件怎么表现”的开关（写同一份 `ucf_mod.json`，重启生效）；快捷键是这组的说明书 |
| **路点数据** | 人机路点 · 录制 · 数据 | 一条数据链：选包编辑 → 录制往包里追加 → 发布成品 / 还原 / 校验；三页共用 `opt_pack` 状态 |
| **部署与测试** | 部署 · 车测 | 装进游戏 → 让它自己逐图跑一遍验收 |
| **开发调试** | 开发者选项 | 坐标记录 / 原始轨迹，给离线分析用；2026-11-21 用户要求它单独成页，这里保持独立（单页组） |

## 2. 形态

```text
[ 插件开关 ][ 路点数据 ][ 部署与测试 ][ 开发调试 ]     ← 一级：CTkTabview
   [地图][可视化][导出][快捷键]                        ← 二级：按钮条（2 页以上才显示）
   ┌ 页面内容（各页 build_* 一行没改） ┐
```

- 二级按钮条复用 `app/ui/kit.py` 的 `build_sub_tabs()`（从「人机路点」页提到共用层的，
  它当初就是为“高度不跟内容长”的对比表写的，没换成嵌套 Tabview）。
- 单页组不显示第二行，省一次点击。
- 每个组记住上次停留的子页（`ui.sub_<组名>`）；启动条「去人机路点改」一步直达组 + 页。

## 3. 代码改动

| 文件 | 改什么 |
| --- | --- |
| `app/ui/consts.py` | 新增 `TAB_GROUPS`（唯一分组表）和 `TAB_OLD_MAP`（旧配置名 → 新组） |
| `app/ui/kit.py` | `build_sub_tabs(parent, names, on_change=None)`：从 waypoint 提上来，加回调 |
| `app/tabs/waypoint.py` | 删掉本地副本，改调共用件（行为不变） |
| `app/控制台.pyw` | 装配改成“4 组 × 组内页”；新增 `build_page / on_group / show_sub / refresh_page / _restore_tab`；`jump_to_pick`、`on_close` 改存组 + 子页 |
| `app/tests/test_console_switches.py` | 页签断言改成读 `TAB_GROUPS`：组名单、10 页不重不漏、组内顺序、组顺序 |

## 4. 状态与迁移

- 存盘：`ui.tab` = 组名，`ui.sub` = 当前子页，`ui.sub_<组>` = 每组的记忆。
- 旧配置（`ui.tab` 是平铺页签名，如 “数据”）→ 按 `TAB_OLD_MAP` 搬进对应组，子页就是原页名；升级后不跳回第一页。
- `_restore_tab()` 的 7 种用例（数据 / 车测 / 快捷键 / 路点数据+录制 / 开发调试 / 已删除页 / 空值）都跑过。
