## 3. 怎么用

**UCF 控制台是唯一入口**（`启动控制台.bat` → 「数据」页）：

| 控制台里的位置 | 等价命令 | 作用 |
| --- | --- | --- |
| 「数据」页四张卡（①②③④） | `navdata.py status` | 路径 / 文件数 / 体积 / 最近写入时间 / 条数 |
| 卡片下面「一致性…」 | `navdata.py diff` | ①=②、②=③，以及 ④ 有几份导出待导入 |
| 按钮 **导入到开发版 ④→②** | `navdata.py import` | ④ 的可走面拷进 ②、原始导出整理进 ②\maps，处理后归档到 ④\archive |
| 按钮 **部署到游戏 ②→③** | `navdata.py publish` | ② 开发版 → ③ 部署版 |
| 按钮 **还原原生 ①→②** | `navdata.py restore` | ① 备份版 → ② 开发版（先弹确认） |
| 按钮 **校验备份版** | `navdata.py verify` | ① 的 SHA256 + 只读属性 |
| 「导出」页 | — | 总开关 + 六项内容；「最近一次导出」/「打开文件夹」/「整理」都指向 ④ |
| 「测试数据」页 | `navdata.py pack …` | 正式版 / 测试包（④\packs）+ 只对哪张图生效 |
| `tools\启动导航编辑器.bat` | `navserver.py` | 编 ② 开发版；可走面读 ④ |

命令行（先 `cd ucf_mod\tools`）：

    python navdata.py status            四版状态
    python navdata.py verify            校验 ①
    python navdata.py restore           ② <- ①
    python navdata.py import            ② <- ④（可走面 + 原始导出，--dry 预览）
    python navdata.py publish           ③ <- ②（推给游戏）
    python navdata.py diff              ② vs ①、② vs ③
    python navdata.py freeze --force    用当前数据重建 ①

## 4. 插件侧怎么知道 ④ 在哪（2026-11-18 新增）

控制台「开始游戏 / 车测」启动进程时注入：

| 环境变量 | 值 | 作用 |
| --- | --- | --- |
| `UCF_EXPORT_DIR` | ④ `vis\` | Ctrl+E 导出 JSON、`navmesh_*.bin`、`_seen_*` 都写这里 |
| `UCF_PACK_DIR` | ④ `packs\` | `UCF_PACK` 选中的测试包从这里读/写 |
| `UCF_NAV_READONLY` | `1`（没选测试包时） | 正式版下游戏内保存只记日志，不写 ③\nav |

插件里的解析顺序：**环境变量 > `ucf_mod.json` 的 `export_dir` / `pack_dir` > 插件目录**（旧行为）。
直接双击 `UnityCrossFire.exe`（没有 `UCF_MOD=1`）插件根本不加载，所以不存在"绕过控制台写 ③"的问题；
从控制台启动时三个变量一定在。启动日志有一行：

    four versions: export=…\navdata\test\vis packs=…\navdata\test\packs officialNavSave=blocked(read-only)

## 5. 只读是怎么保证的

1. `freeze` 写完后把 ① 里每个文件 `chmod 0444`，并放 `SHA256SUMS.txt` / `.frozen.json`；`verify` 逐个比对；
2. `navdata.py` 只有 `freeze` 会写 ①，而且必须先 `--force`；
3. 编辑器用 `UCF_PROFILE=native` 启动时是只读：`/api/save`、`/api/name` 直接 403；
4. ③ 的 `maps\` `nav\` 只有 `publish` 写；插件在正式版下 `UCF_NAV_READONLY=1`，游戏内保存被挡；
5. ④ 是唯一"脏"的地方，清理只需删 ④ 里的文件，不影响任何一版。

## 6. 路径真相：`core\ucf_paths.py`

| 变量 | 含义 |
| --- | --- |
| `UCF_PROFILE` | `dev`（默认）/ `native` / `deploy` |
| `NATIVE` / `DEV` / `DEPLOY` | ① / ② / ③ 三个根 |
| `TEST` | ④ 根（`navdata\test`） |

| `PACKS_DIR` | 测试包根：`UCF_PACK_DIR` > ④\packs |

| `DATA` / `MAPS` / `NAV` | 当前生效的根（由 `UCF_PROFILE` 决定） |
| `DATAVIS` | 当前版本自带的可走面 |
| `READONLY` | 是否是只读的备份版 |
