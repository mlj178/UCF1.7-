# 逆向速查：版本 / 偏移 / 地址

> **类型：查（工程事实）**——给写代码的人，或者给 AI 读；**只想改路线的人不用看这篇**。
> **给谁看**：写插件、hook 函数、算地址；或者要确认"这份资料是不是这一版游戏"。
> **数据来源**：`GameAssembly.dll`（IDA IDB）、`Il2CppDumper` 的 `dump.cs` / `script.json` / `stringliteral.json`、游戏安装目录的 `UnityCrossFire_Data`。全部是原厂数据，没有转述。
> **不回答什么**：这个游戏有哪几个模式、BL/GR 是谁（见 [01-游戏基础信息.md](../guide/01-游戏基础信息.md)）；人机怎么想、路线怎么改（见 [09-人机与路线设计.md](../guide/09-人机与路线设计.md)）。
> **维护约定**：换游戏版本必须整篇重测——偏移、RVA、枚举值都可能变。对不上就先核对 §1 的 md5。

---

## 1. 版本与引擎

| 项 | 值 |
| --- | --- |
| 引擎 | Unity **2020.3.30f1**（读 `UnityCrossFire_Data/globalgamemanagers` 的版本串） |
| 脚本后端 | IL2CPP，**x86 32 位**（`GameAssembly.dll` + `global-metadata.dat`） |
| 主模块基址 | `0x10000000`（IDA 里 **VA = RVA + 0x10000000**） |
| `GameAssembly.dll` md5 | `fab04426db6a014c0129ef2001530908` —— 对不上说明不是这版，下面所有偏移作废 |
| 导航插件 | A\* Pathfinding Project（`Pathfinding` 命名空间：`AstarPath` / `Seeker` / `PointGraph` / `NavMeshGraph`） |
| 场景数据 | `UnityCrossFire_Data/level0` ~ `level11`，场景表在同目录 `globalgamemanagers` |

## 2. 逆向资料在哪（别乱读，按需取）

| 资料 | 路径 | 怎么用 |
| --- | --- | --- |
| 类 / 字段 / 方法签名 | `00-游戏逆向分析-相关信息/Il2CppDumper/dump.cs`（9.1 MB） | 按类名 grep，再读命中附近 ≤200 行；**别整文件读** |
| 方法地址（RVA） | 同目录 `script.json`（25.6 MB） | 只查名字时用脚本 / jq 过滤，**别整读** |
| 字符串字面量 | 同目录 `stringliteral.json` | 同上，只在核对中文名 / UI 文案时用 |
| 函数汇编 / 交叉引用 | IDA MCP（当前库 `GameAssembly.dll`） | `decompile_function` / `disassemble_function` / `get_xrefs_to` |
| 切分好的汇编 | `IDA-汇编代码/切分输出/**/*.lst`（384 MB） | **默认不读**；只有 IDA MCP 不可用且明确需要时才 grep 单个 chunk |

> 地址换算：表里的 RVA + `0x10000000` 才是 VA；IDA 里看到的地址直接就是 VA。

## 3. 模式相关的函数地址

| 符号 | VA | 说明 |
| --- | --- | --- |
| `GameModeExpand::ToChinese` | `0x10AFE4D0` | jump table 按枚举直接返回字符串字面量（模式中文名的唯一出处） |
| `IsNanoMode` | `0x10AFE490` | `3 <= g <= 6`；交叉引用：`SO_Item_Character.GetCharacterName`、`BotEnemyInfo.ShouldWaitKnifeAttack` … |
| `IsTerminatorMode` | `0x10AFE4B0` | `g == 4 或 g == 6`；交叉引用：`Bot.Awake` |
| `IsMultiPlayerMode` | `0x10AFE480` | **只有 `g == 6`**；交叉引用：`ModeBase_Nano.InfectEvent`、`UI_GameRoom.GenerateBotClient` |
