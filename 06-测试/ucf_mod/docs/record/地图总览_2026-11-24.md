# 地图总览（2026-11-24）

## 需求

一张图一行，显示所有地图在「备份① / 编辑中 / 成品 / 部署（游戏里实际加载）」之间的状态；
A 矩阵、B 卡片、C 看板三种视图都保留，随时切换，共用筛选和搜索。
放在「路点数据」组第一位，只读，不改变现有编辑 / 发布流程。

## 实现

- `app/ui/overview.py`
  - `collect_overview(start_mode, current_level)`：11 张图一行，读 native map.json、packs 草稿、final 成品、archive/final_prev 快照。
  - `parse_nav()`：按 grow/keep 正确算点边（grow 以 0 为底，keep 以原生为底；node add/del、edge add/del）。
  - `deployment_status()`：用 `deploy_mod.build_plan()` 的 5 个 payload 文件做 sha256 对比，全局插件状态。
  - 不写盘、不建目录。
- `app/tabs/overview.py`
  - 标题 + 全局三卡（插件部署 / 当前启动档 / 数据计数）+ 视图切换 + 状态筛选 + 搜索。
  - A 矩阵：行展开详情（草稿/成品/快照路径、按钮）。
  - B 卡片：四节点生命周期；「查看」切回矩阵并展开该图。
  - C 看板：编辑中/待发布、已同步、只有成品、未开始/无点图四列；点击卡片回矩阵。
  - 视图选择写 `ucf_mod.json` 的 `ui.overview_view`。
- `app/ui/consts.py`：`TAB_GROUPS` 路点数据 = 地图总览 / 人机路点 / 录制 / 数据；`TAB_OLD_MAP` 加地图总览。
- `app/控制台.pyw`：导入 OverviewTab，`build_page` 分派，`refresh_page` 进入时刷新。
- 自检：`tests/test_overview.py`；同时把 `test_roles/test_console_switches/test_layout` 的页数从 10 改 11。

## 状态口径

| 状态 | 条件 |
|---|---|
| 编辑中 | 有草稿、0 点改动、还没有成品 |
| 待发布 | 有草稿改动，没成品或草稿/成品 sha256 不同 |
| 已同步 | 草稿/成品 sha256 相同 |
| 只有成品 | 有成品、无草稿 |
| 未开始 | 无草稿、无成品，但有原生底图 |
| 无点图 | 没有 map.json / PointGraph（只有 navmesh） |

「部署 / 游戏加载」列按当前启动档算：
- 成品档：有 final 的图加载成品，其余原生；草稿更新时显示「成品（旧）」。
- 编辑中档：只加载当前选中图的草稿，其余原生。

## 验证

- 12 个静态自检全过。
- `compileall app` 通过。
- GUI 冒烟：`App(role="dev")` 11 页，切到地图总览，矩阵/卡片/看板/行展开都能渲染。
- 真实窗口 830×900 冒烟：矩阵 / 卡片 / 看板 / 行展开都可渲染；截图不留档（数据会变）。

## 边界

- 部署是全局插件，不是每张图一份；总览只显示「游戏里会加载哪份地图数据」。
- 快照目前只显示份数和最近几份日期；逐份对比/恢复未做。
- 作品数据按用户当时磁盘状态显示；空数据时仍保留 11 行原生底图，只在顶部提示。
- 控制台需重启后出现新页签。
