# 目录重构（2026-11-24）

> 目标：根目录一眼数清，一个页签的代码在一处。改完后根目录 12 个文件夹 → 7 个。
> 本文只讲**旧路径 → 新路径**，细节看 `README.md` 的「目录」一节。

## 1. 根目录

| 旧 | 新 | 说明 |
| --- | --- | --- |
| `console/` | `app/`（顶层文件）+ `app/workbench/` | 控制台、部署三件、录制/轨迹两件 |
| `core/` | `app/core/` | ucf_paths / map_table / navdata |
| `tools/` | `app/tools/` | 构建、车测、geo / data / _oneoff |
| `tests/` | `app/tests/` | 8 个自检 |
| `geo/` | `data/geo/` | npz 源 + 派生 web/tex |
| `navdata/` | `data/navdata/` | native / dev 三区数据 |
| `payload/` | `run/payload/` | 部署弹药库（唯一副本，必须进 git） |
| `build/` | `run/build/` | 编译产物（gitignore） |
| `log/` | `log/`（不动） | 运行日志 |
| `src/` `docs/` `archive/` | 不动 | C 源码 / 文档 / 历史证据 |

根目录另有 `启动控制台.bat`（一行转发到 `app\启动控制台.bat`），保留双击启动的习惯。

## 2. 控制台：一个 5100 行文件 → 窗口壳 + 共用件 + 10 个页签

| 旧（`控制台.pyw` 内） | 新 | 约行数 |
| --- | --- | --- |
| 顶部 import / 路径常量 | `app/ui/env.py` | 100 |
| `GROUPS / DEV_ITEMS / VIS_COLORS / HUD_KEYS / AT_*` | `app/ui/consts.py` | 250 |
| 文件 / 时间 / 大小 / 配置 / 进程 / 日志函数 | `app/ui/util.py` | 290 |
| 地图对照表与图文件夹函数 | `app/ui/maps.py` | 200 |
| 导出收件箱 / 可走面 / 哈希统计 | `app/ui/stats.py` | 135 |
| 包 + 成品台账（函数 + `PackMixin`） | `app/ui/packs.py` | 1040 |
| 开关卡片 / 区块标题 / 图例 / 对话框（`Kit`） | `app/ui/kit.py` | 175 |
| 地图页 | `app/tabs/map.py` | 25 |
| 可视化页 | `app/tabs/vis.py` | 80 |
| 导出页 | `app/tabs/export.py` | 125 |
| 快捷键页 | `app/tabs/hotkey.py` | 25 |
| 人机路点页 | `app/tabs/waypoint.py` | 550 |
| 录制页 + 识别算法 | `app/tabs/record/{tab,ucf_rec}.py` | 775 + 550 |
| 数据页 | `app/tabs/data.py` | 230 |
| 部署页 + 引擎 + 首次设置 | `app/tabs/deploy/{deploy_tab,deploy_mod,first_run}.py` | 420 + 440 + 200 |

拆分方式：**mixin 类 + AST 按行范围搬运**，方法体一字未改；`控制台.pyw` 的 `App` 继承全部页签 mixin。
共用状态仍在 `self` 上，跨页调用（如 `self.write_nav_cmd`）不变。

## 3. 连带改的地方

- `app/core/ucf_paths.py`：新增 `DATA_ROOT`；`GEO / NATIVE / DEV / TOOLS / CONSOLE / WEB / CORE` 指到新位置。
- `app/core/navdata.py`：`_logs` 路径。
- `app/workbench/navserver.py`：静态根 = `P.WEB`（`app/workbench/web`）。
- `app/tabs/deploy/deploy_mod.py`：`PAYLOAD = PROJ / "run" / "payload"`。
- `app/tools/{build,autotest}.ps1`、`src/proxy/build_proxy.ps1`：项目根统一靠 `.ucfroot` 上溯；产物进 `run/build`。
- `app/tools/geo/*.py`、`docs/guide/地图3D资源导出/代码/scene_export2web.py`：`data/geo` + `.ucfroot`。
- `.gitignore`：全部改到新路径。
- 7 个自检改成读新文件；新增 `app/tests/test_layout.py` 锁住这棵树。
