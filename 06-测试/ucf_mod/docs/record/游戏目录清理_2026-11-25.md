# 游戏目录清理与直读改造（2026-11-25）

## 1. 目标

把游戏目录从"mod 存储位置"降级为"只读宿主"：

- 工程端 `06-测试\ucf_mod` 是代码、配置、日志、路点、地图数据、本体补丁的唯一事实源；
- 游戏目录只保留**必须有的文件**：加载器 `winhttp.dll` / `winhttp_orig.dll` + 游戏本体补丁；
- 不再生成 `ucf_mod\`（插件 dll、`ucf_mod.json`、README、uninstall、manifest、backup、markers 全部清掉）；
- 一键部署负责把"必须有的文件"从工程端铺到游戏目录，覆盖前备份、卸载可还原。

## 4. 代码变化

### 4.1 运行时路径

- `app/core/ucf_paths.py`：新增 `RUNTIME = run\runtime`、`CFG_PATH`、`NAVCMD`；
  `DEPLOY` 仍表示 `<游戏>\ucf_mod`（只用于反推游戏目录，目录可以不建）。
- `app/ui/env.py`：`CFG_PATH` / `NAVCMD` 改用 `run\runtime`；新增 `PAYLOAD_DLL` 兜底。
- `app/控制台.pyw`：`UCF_MOD_DIR=RUNTIME`；`UCF_MOD_DLL` 优先 `run\build\ucf_mod.dll`，
  没有就退 `run\payload\ucf_mod\ucf_mod.dll`；两个都没有拒绝启动；首次直读时从旧部署端搬一次 `ucf_mod.json`。
- `app/workbench/navserver.py`：`collect_config` 改读 `P.CFG_PATH`。
- `app/tools/autotest.ps1`：游戏位置从用户配置取；注入 `UCF_MOD_DLL` / `UCF_MOD_DIR` / `UCF_MARKERS_DIR`；
  `_autotest.cmd` 写 `run\runtime`，不写游戏目录。

### 4.2 加载器

- `src/proxy/proxy.c`：不再回退 `<游戏>\ucf_mod\ucf_mod.dll`；只认 `UCF_MOD_DLL`；
  没注入 = 原版启动；载入失败只写 `%TEMP%\ucf_mod_proxy.log`，不往游戏目录落文件。
- 重新编译产物 `run\build\proxy\winhttp.dll`（50,984 B，SHA256 `42c5fed4…`），
  同步 `run\payload\winhttp.dll`；旧哈希进 `run\payload\loader_history.json`。

### 4.3 一键部署

- 新增 `app/core/gamepatch.py`：`run\gamepatch` 的唯一解析/分类器（`ledger.py` 也复用它）。
- 重写 `app/tabs/deploy/deploy_mod.py`：
  - 计划 = 加载器 + 启用的本体补丁；
  - 状态 = 一致 / 原版 / 新增 / 缺失 / 冲突 / 已禁用；
  - 冲突或缺失时**零写入**；
  - 覆盖前备份进 `run\deploy_backup`；清单进 `run\runtime\deploy`；
  - 卸载优先现场备份，其次 `patch.json` 的 `orig_file` 包内原件；新增文件删除；
  - 不再创建 `ucf_mod\`，不再写游戏内 manifest。
- `app/tabs/deploy/deploy_tab.py` / `first_run.py`：状态/文案适配；`open_folder` 打开游戏根。
- `app/ui/overview.py`：部署卡片改用 `plan_summary`，只统计必须文件。
- `app/tools/build.ps1`：`-Deploy` 改为只更新 `run\payload`（等同 `-Payload`），不再写游戏目录。
- `run/gamepatch/.../patch.json`：新增 `default_enabled`（暴风 true / 龙城 false）和 `orig_file`；
  `orig\` 下补了 level9 / globalgamemanagers 原版。
