# storm 面图资产化（AssetBundle 方案）

> 目的：把 storm 的导航面做成 Unity 认的 Mesh 资产，让游戏像原厂 8 张图一样用它。
> 原则：**游戏目录一个字节不改**；资源、代码、文档全部留在工作区，可备份到 GitHub。

## 1. 为什么要做这一步

现在的人机导航是"运行时往游戏里塞点图"，每次重建都要重绑引用、还要射线过滤。
原厂 8 张图不是这么跑的：它们的面图是 **Mesh 资产**，A* 的 NavMeshGraph 引用它，
进图时 `Scan()` 自己把三角形变成节点。

所以目标是把我们的面也做成同样的资产，让引擎自己扫。

## 2. 数据从哪来（工作区，全部可复现）

| 文件 | 作用 |
| --- | --- |
| `out/Nano30_Storm_NavMesh.obj` | 烘好的面（1,366 顶点 / 1,258 三角），Unity 直接导入 |
| `代码/bake_navmesh.py` | 从地图几何烘面（支持合并大三角） |
| `代码/sweep2navmesh.py` | 从游戏内扫描的高度表烘面 |
| `代码/mesh2points.py` | 面 → 点图（备用方案） |
| `代码/export_obj.py` | 面 → OBJ |

## 3. 两条落地方式

### A. AssetBundle 运行时加载（推荐，不动游戏目录）

1. Unity 2020.3 建空工程；
2. 导入 `Nano30_Storm_NavMesh.obj`，改名 **Nano30_Storm_NavMesh**，位置 (0,0,0)、缩放 1；
3. 给这个 Mesh 打 AssetBundle 标签（例如 `stormnav`），Build 出 bundle；
4. 控制台启动游戏时把 bundle 路径传给插件；插件 `AssetBundle.LoadFromFile` 读进来，
   拿到 Mesh 后建 NavMeshGraph。

**优点**：游戏目录完全不动，bundle 放工作区，随控制台分发。
**风险**：bundle 版本要和游戏引擎（2020.3.30f1c1）一致。

### B. 注入游戏 resources.assets + 改场景（原生，但会改游戏文件）

1. 用 UABEA / UnityPy 把 Mesh 加进 `resources.assets`，命名 `Nano30_Storm_NavMesh`；
2. 改 `level9` 场景里 `AstarPath` 的 `dataString`（base64 zip），把 PointGraph 换成
   NavMeshGraph，`sourceMesh` 指向新 Mesh；
3. 改前算哈希、留备份；改后进图验证。

**优点**：和原厂完全一致，最稳。
**代价**：改游戏文件，分发时要带补丁工具。

## 4. 验收清单

1. 进图后日志出现 `nm: loaded ...`（或 A* 自己报 NavMeshGraph）；
2. 人机 `near` 不为 0，且能在面上自由走位；
3. 你的 12 条跳链仍然成立（跳蹲参数原样）；
4. 不刷 `NullReferenceException at Bot.Update`；
5. 帧率不掉（原厂面图 700~1,300 三角形，我们的 1,258，同量级）。

## 5. 回滚

先把要改的文件复制到 `backup/`，记下原文件 MD5；出问题直接覆盖回去。
bundle 方案不存在回滚问题（删掉 bundle 即恢复）。

## 6. 已落地：用 Unity 自己的 Recast 烘焙（2026-11-28）

不再用 Python 的格子近似，改成 Unity 官方烘焙器，参数有依据：

| 项 | 值 |
| --- | --- |
| 源几何 | `unity-navmesh/Assets/map_geometry.obj`（整张 storm：80,947 顶点 / 64,556 三角） |
| Agent 半径 | 0.4 m |
| Agent 高度 | 1.8 m |
| 可跨台阶 | 0.45 m |
| 最大坡度 | 45° |
| 烘焙结果 | **10,562 顶点 / 4,838 三角形** |
| 产物 | `unity-navmesh/Bundle/stormnav`（63 KB）→ 复制到 `data/maps/<图>/navmesh_bundle` |

对照：原厂 8 张图的面图是 700~1,300 三角形；storm 更大更复杂，4,838 属正常量级，
要继续压可以调 `minRegionArea` / 提高 cellSize。

命令（不需要 -batchmode）：

```powershell
Unity.exe -projectPath <unity-navmesh> -executeMethod BuildNav.BatchBuild -quit -logFile D:\navbake.log
```

**游戏目录不改**；bundle 与工程都在工作区。
