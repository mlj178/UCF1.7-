## 2. 阵营与出生点容器

中文名出自 `01-游戏系统分析/03-dump-枚举类汇总_清洗版.md`（`Team` 枚举）与场景里 `pointDic` 的 key。

| 代码 | 中文 | 说明 |
| --- | --- | --- |
| `Team.BlackList = 0` / `SP_BL` | **潜伏者** | 团队模式 = 潜伏者；生化模式 = **幽灵 / 终结者**方（游戏就是拿 `team == BlackList` 判幽灵） |
| `Team.GlobalRisk = 1` / `SP_GR` | **保卫者** | 团队模式 = 保卫者；生化模式 = **人类 / 佣兵**方 |
| `Team.Neutral = 2` / `SP_Netural` | **中立** | 个人竞技 / 混战全员共用；字段名是笔误，场景里 key 写的是 `Neutral` |
| `pointDic` | **出生点字典** | 场景里真正存点的容器：`key` → `SpawnPoint[]`（坐标 + 朝向角） |

**`pointDic` 和 `SP_*` 什么关系**：那几个 `SP_*` 数组没有 `[SerializeField]`，场景里只存字典；运行时 `Awake`（推断）按 key 拆成数组。
所以运行期改 `SP_*` 只是改缓存，**换图重载就按字典重建**——要持久改，得改场景里的字典。

**每张图的字典里到底有哪些 key**（2026-11-19 直接读 `levelN` 场景字节）：

- 运输船 / 小型工厂 / 椰岛之巅 / 竞技场 / 刀锋寨 / 死亡擂台 = `BL` + `GR`；
- 沙漠要塞 / 生化酒店 / 飓风危城 = `BL` + `GR` + `SupplyBox`；
- 新寂静村 = `BL` + `GR` + `SupplyBox` + `RedBox` + `BlueBox`；
- **只有胜利广场（个人竞技）是单个 `Neutral`**。

11 张图都没有叫 `Netural` 的 key——所以团队图里的"中立出生点"本来就是空的，个人竞技要套团队图只能借用 BL/GR（功能 27 的兜底就是干这个）。
