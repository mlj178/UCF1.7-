# 网页版导航编辑器（navview.html · 2026-11-16 重做）

> 目标：在浏览器里**看得懂、改得动、存得下、游戏里立刻生效**。
> 一份 HTML + 一个本地服务（只用标准库），俯视和 3D 分屏，中文地图名。

---

## 0. 怎么打开（最容易错的一步）

双击：

    ucf_mod\tools\启动导航编辑器.bat

它会起一个**只监听 127.0.0.1** 的本地服务，并自动打开浏览器。
端口从 8765 开始找第一个空的，窗口里会打印真实地址（例如 http://127.0.0.1:8765/navview.html）。

**不要直接双击 navview.html。** 用 file:// 打开时浏览器不允许读写你磁盘上的文件，
编辑器会降级成"只能拖 JSON 进来看、保存只能下载"。页面顶部会出现黄色横幅提示。

关掉那个黑窗口 = 停止服务；编辑器里已经保存的文件不受影响。

## 1. 数据是怎么流的

| 文件 | 谁写 | 作用 |
| --- | --- | --- |
| `vis/<地图>_<时间>.json` | 游戏内插件 `Ctrl+E` | **原始扫描**（只增不改，用来对比） |
| `nav/<指纹>.txt` | 编辑器保存 / 游戏内 Ctrl+Shift+* 编辑 | **游戏真正读的编辑清单** |
| `nav/<地图>.json` | 编辑器保存 | 编辑后的权威数据（ucf-navgraph v1 + `edits` 段），给人看、给下次打开用 |
| `nav/names.json` | 编辑器"存名" | 每张图的中文名 / 关卡（按指纹、地图名、关卡名三个键都记） |
| `geo/web/<关卡>.bin` | `tools/geo2web.py` | 3D 视图用的灰模网格（navedit 的 `geo/*.npz` 瘦身版） |

进图后的流程（插件 `editor.c`）：

1. 游戏 Scan 出点图 → 节点数稳定两跳；
2. 插件算**基础图指纹** `n<节点数>-<16位哈希>`（哈希是每个节点坐标量化后 FNV-1a 再异或）；
3. 找 `ucf_mod\nav\<指纹>.txt` → 读 → 按坐标（容差 0.35 m）依次套用；
4. 套完 `RebuildNodeLookup()`，A* 立刻能用；之后每 ~1 秒抽查一次，图被游戏重扫就再套一遍。

所以要"保存后应用到游戏"，**只需要把编辑写成 `nav/<基础图指纹>.txt`** —— 编辑器保存时做的就是这个。

## 2. 保存 → 生效

1. 编辑完点 **保存并应用**（Ctrl+S）。
   写入两份文件，改动前的文件自动备份成 `*.bak_时间`：
   - `nav/<目标指纹>.txt` ← 游戏读的
   - `nav/<JSON 名>.json` ← 编辑器下次读的
2. 回到游戏：
   - **已经在图里**：按 `Ctrl+Shift+R` 强制重套用（日志有 `naved: re-applied N/M edits`）；
   - **还没进图**：直接进这张图，插件会自动套用（日志 `naved: applied N/M edits on <指纹>`）。
3. 想撤：删掉 `nav/<指纹>.txt` 下次进图就是原图；或者用编辑器右下的 **备份** 按钮还原。

### 目标指纹怎么选（唯一容易踩的坑）

- 指纹是**节点数 + 所有节点坐标**算出来的。游戏每次进图重扫，得到的是**没套编辑之前的**基础图指纹。
- 在游戏里用 Ctrl+Shift+N 加点以后导出的 JSON（`map_n792-…`）已经是**加过点**的图，它的指纹 `n792-…`
  游戏根本不会去找（游戏会找 `n786-…`）。
- 编辑器的"目标指纹"下拉会自动挑：① 已经有 `.txt` 的那个 → ② 节点最少的那份快照（就是基础图）。
  选错的表现是：保存成功了，但游戏里毫无变化（日志里 `naved: no edit file for n7xx-…`）。

## 3. 能改什么、不能改什么

插件只认四种指令，所以编辑器的编辑能力也严格限定在这四种上：

| 指令 | 含义 |
| --- | --- |
| `node add x y z` | 在坐标处加一个可走点（已有可走点 <0.35 m 则什么也不做） |
| `node del x y z` | 把该坐标的点设为**不可走**并断开它的所有边（不是从数组删，避免下标位移） |
| `edge add ax ay az bx by bz` | 两点连边（双向） |
| `edge del ...` | 断边（双向） |

对应的界面操作：

| 你想做的 | 编辑器里怎么表达 |
| --- | --- |
| 加点 | `node add` |
| 删点 / 禁用 | `node del` |
| 移动点 | `node del 旧位置` + `node add 新位置` |
| 设为不可走 / 恢复可走 | `node del` / `node add` |
| 连边 / 断边 | `edge add` / `edge del` |
| 改 tag、penalty | **不支持**（插件没有对应指令；JSON 里能存，游戏不会用） |
| 改出生点/蹲守点/守区 | **不支持**（同上；这些是小地图数据，不在点图里） |

> 特征点（出生点、蹲守点、幽灵守区…）在编辑器里**只显示不修改**，用来判断"加的这条路通不通向出生点"。
> 想改它们，得回到游戏里用 Ctrl+数字 那套标记编辑（`markers/`）。

## 4. 界面

- **左侧**
  - 地图数据：文件、指纹、节点/边、特征、包围盒、扫描时间；
  - 打开：按中文名分组的快照（同名的 n786/n787/n792… 都在一组里），点一下载入；
  - 编辑：选择 / 加点 / 连线 / 删点 / 可走 / 孤立点 + 选中点的坐标、Y 微调、"落地"；
  - 显示：地形、边、不可走、带 tag、特征、孤立点、**楼层带**（按选中点切层）；
  - 应用到游戏：写入的 txt 路径、目标指纹、JSON 名、导出、备份、改动统计；
  - 校验：V1 边端点不可走 / V2 孤立点 / V3 连通块 / V5 超过 8 m 的长边 / V6 悬空特征点。
- **俯视**（左半）：地形平面图（带楼层带时只画这一段高度）+ 路点 + 边 + 特征点；
  空白处拖动=平移，滚轮=缩放，左键=选中/拖动，Shift+拖动=框选。
- **3D**（右半）：真几何的灰模 + 路点 + 连线；**右键拖动=转视角**，**鼠标停在 3D 上就用 WASD 飞**
  （Q/E 升降，Shift 加速 3 倍；不必按住任何键，按住右键也照样能飞），中键或 Shift+右键=平移，
  滚轮=推拉，左键点选、拖动=框选，双击对准路点，Esc 收掉飞行状态；
  **切层**（按楼层带剖切，看室内）、**近处**（只画选中点 26 m 内）、**穿透**（路点隔墙也半透明可见）。
- 中间分隔条可以拖、双击切换左右/上下分屏。

### 快捷键

| 键 | 作用 |
| --- | --- |
| 滚轮 / 右键拖动 | 缩放 / 平移（3D 里：滚轮=推拉，右键拖动=转视角） |
| W A S D / Q E（鼠标在 3D 上） | 3D 飞行（W 前 S 后 A 左 D 右，Q 降 E 升，Shift 加速 3 倍） |
| W A S D / Q E（鼠标在左边或侧栏） | 仍是编辑快捷键：W=可走、A=加点、E=连线，Q/D/S 无绑定 |
| A / E / V | 加点 / 连线 / 选择模式 |
| Delete | 禁用选中的点 |
| W | 可走 ↔ 不可走 |
| F / 空格 | 俯视 + 3D 都回到全图 |
| G | 跳到下一个孤立点 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+S | 保存并应用 |
| Ctrl+R | 丢掉未保存改动，重新读文件 |
| 双击路点 | 3D 相机跑过去 |
| ? | 说明面板 |

## 5. 3D 的地形是哪来的

`tools/geo2web.py` 读 navedit 提取的 `ucf_mod/geo/<关卡>.npz`（顶点/法线/UV/索引 + 分块表），
转成 `geo/web/<关卡>.bin`：位置 f32、法线 int8、索引 u32，外加一个 JSON 头（包围盒、环境光、分块颜色）。

- **不带贴图**：navedit 那套 UV/贴图是乱的（用户已确认不修），3D 只用"法线光照 + 材质色"的灰模，
  看得清结构、也不会被错乱贴图干扰。
- 转换时丢掉三类分块：`shadow`（阴影体）、`blocker`（碰撞壳）、`card`（巨幅装饰面/海面）——
  它们本来就不该被看见，留着只会挡住室内。运输船 39433 → 19783 三角形。
- 关卡选错，3D 就对不上路点（右上角下拉可改；同名关卡会自动记住）。
- **3D 默认开"切层 + 穿透"**：按路点高度带（最低点-2 m ~ 最高点+2 m）剖切，船这类封闭场景不切就只看得见外壳；
  路点半透明叠一层，墙后也能看见。不想切就取消勾选，或在左侧"楼层带"里点"看全部"。
- 没有 `geo/web` 时编辑器照样能用，只是 3D 只有路点。

重新生成（改了 `geo/*.npz` 之后）：

    python tools/geo2web.py            # 全部
    python tools/geo2web.py level1     # 只一个
    python tools/geo2web.py --force    # 源文件没变也重转

## 6. 中文名

- 内置：`level1 / level1_TransportShip` → **运输船**；`level9 / Nano30_Storm` → **生化幽灵·风暴**。
- 其它图在顶部名字框里改一下，点 **存名** 即可（写进 `nav/names.json`）。
  存名会同时写三个键：当前指纹、地图名（`map.name`）、关卡名（`levelN`），
  所以"关卡名"一改，这张图以后所有快照都会显示同一个中文名，不怕指纹变。
- 关卡下拉决定 3D 用哪份地形，和中文名一起记住。

## 7. 排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 顶部黄色横幅"现在是用 file:// 直接打开的" | 用 `启动导航编辑器.bat` 打开 |
| 右侧"打开"列表是空的 | 服务没连上，或 `vis/` 里还没有数据（先游戏里 Ctrl+E） |
| 3D 只有点没有地形 | 关卡没选 / `geo/web` 里没有这个关卡：跑 `geo2web.py`（要 numpy） |
| 3D 地形和路点对不上 | 关卡选错了（例如运输船的点用了 level6 的地形） |
| 载入后节点 0 / 报错 | 文件不是 `ucf-navgraph`（老 `graph_*.json` 也支持，但那种没有指纹） |
| 保存报"第 N 行不是合法的编辑指令" | `nav/<fp>.txt` 被人手改坏了，编辑器会拒绝写出坏文件；先备份再修 |
| 保存成功但游戏里没变化 | ① 目标指纹选错（见 §2）；② 是否 `collect-only` 模式；③ 按 `Ctrl+Shift+R`；④ 看 `ucf_mod.log` 的 `naved:` 行 |
| 中文名不显示 | 点"存名"；或检查 `nav/names.json` 是否可写 |
| 楼层带一开什么都没有 | 这一段高度真的没有地板；把两个滑块拉宽，或点"看全部" |

## 8. 回滚

- **只回滚编辑**：删 `nav/<指纹>.txt`。
- **回滚某次保存**：编辑器的 **备份** 按钮（列 `nav/*.bak_时间`，点还原即可）。
- **回滚编辑器本身**：`tools/navview.html.bak_20261116` 是旧版（只能看不能存的那种）。
- 所有编辑都只写 `ucf_mod\nav\`、`ucf_mod\gear...` 之外的文本文件，**不碰 DLL、不碰游戏资源**。
