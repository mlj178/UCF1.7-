## 4. 对「录制」的参数建议（由这批数据推出来）

- **采样档位**：最短滞空 0.18 s。要在一跳里留够 8 帧，需要 ≥ 44 Hz；建议 **30 Hz 起步，60 Hz 用于连跳/短跳**。
- **跳链长度**：跨缺口跳距中位 6.35 m、最大 6.63 m。游戏原生跳链 ≤ 2.91 m，所以自动建链只上 1.5~2.9 m；更远的要补中间落脚点或标「待实测」。
- **跳上高台**：28 次（高差中位 1.86 m）。这类不是跳链，是「从一个面跳到另一个面」，落点要落在台面上，不要写成 jump add。
- **判定口径**：起跳看竖直速度（> 6 m/s）且 isGrounded 由真到假；落地看 isGrounded。不要再用「离地 0.3 m」，那是旧格式靠相机射线估出来的办法。
