SyPB 的操作，在 UCF 里对应什么

左边是 CS 1.6 SyPB 的习惯；右边是 UCF 1.7 的真实数据落点

SyPB 的路点 = 中心坐标 + 半径，路径分向外 / 向内 / 双向。UCF 的 PointNode 只有坐标， 能不能连边由全局 maxDistance（多数图 2.1 m）+ 射线决定，所以没有“单点半径”这一项； 但“双向 / 单向 / 删路径”可以一一对应。
两个不能照搬的地方：跳跃点 = Bot_JumpLink（挂在起点、指向终点，两点成对，不是单独一个点）； 标签区 = PointNodeTagModifier（给范围内的点打 tag，不是新增点）。控制台仍用 SyPB 的叫法，但落数据时按组件处理。

落地范围：复用、新增、暂不做

这份样稿只解决“长什么样、怎么操作”；下面是代码边界

复用（已经有的）

  • 点 / 边读写：node add/del、edge add/del、blank 头、撤销、自动存
  • 蹲守 / 守区 / 守点：现有 type 1/2/3 标记 + markers.txt
  • 可视化：五层、可走面线框、文字标签、HUD
  • 测试包：UCF_PACK / UCF_FP 只对一张图生效
  • 开关不动：editor / collect_only 仍读 ucf_mod.json，新页只做联动，不新增第二套配置
  • 重套用：Ctrl+Shift+R、控制台 ucf_navcmd.txt
风险：低，底层已经实机验证过

新增（这次要做的）

  • 控制台页签：选图 / ④ 包 / 开关 / 计数 / 最近操作
  • 游戏内菜单：长按 E / F2，1-9 直选，小键盘 8/2 上下、5 确认、0 返回
  • 类型笔刷：普通 / 跳跃 / 蹲守 / 守点 / 聚集区 / 标签
  • 单向 / 双向路径，删除路径 / 点，移动 / 落地
  • markers 加指纹：现有 markers.txt 不分图，必须升级成按指纹分文件
风险：中；菜单是纯数据层之上的 UI，不改行为层

暂不做（明确边界）

  • 出生点 / 补给箱写入：MapManager 静态数组，第一版只读
  • 胜利广场 / 死亡擂台加点：没有 PointGraph，要新建图
  • 改 NavMesh 烘焙面：只加点/连边，不动三角网
  • 自动铺全图 / 联机同步：单人编辑工具，不碰对局逻辑
  • 旧 Bot_GuardPos / Bot_GuardArea：当前版本死数据
这些会写进页签的灰色说明，不让操作看起来“能用”

需要你拍板的 4 件事

你确认后，我按这个顺序落地：控制台页签 → 菜单骨架 → 运输船空白包实测

1
菜单入口用哪个键？

SyPB 是长按 E，但 UCF 的 E 可能是交互/安装键，容易冲突。建议 F2 主入口 + 长按 E 备用，菜单里都显示。

2
第一版类型做到哪一步？

建议：普通 / 跳跃 / 蹲守 / 守点 / 聚集区 / 标签区；出生点、补给箱只读。若想更稳，可先砍掉跳跃和标签，只做点 + 边 + 蹲守 + 守区。

3
页签名用哪个？

建议 「人机路点」，和底部「路点工作台（查看）」区分开：一个是编辑，一个是只读查看。

4
默认写哪一版数据？

建议默认 ④ 测试包（只对一张图生效，安全）；③ 正式版 置灰或二次确认，避免现场编辑直接改坏游戏正在读的 nav/。
