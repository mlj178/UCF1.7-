01 · 五条交互原则为什么这么排
  • 1
    手不离 WASD录制中只有 1-6 是标记，其它全自动。菜单打开时 W/A/S/D、空格、鼠标照旧交给游戏。
  • 2
    默认值就能直接跑标准 = 4 m 间距 / 2.5 m 吸附 / 自动识别全开；不想调参的人可以一路默认。
  • 3
    先录、后编录制只产“轨迹 + 事件”，不做最终判断；岔路、双选、删除、连通都留到复盘。走位时不用纠结。
  • 4
    结果先看得见HUD 有距离/点数/事件；复盘有问题清单；保存前先给 +N 点 / +M 边 的增量。
  • 5
    不制造脏数据去重、吸附、传送断段、静止不采点、④ 隔离、原轨迹保留——每一条都对应一种以前踩过的坑。

03 · 哪些不用按，哪些要按一下按错也不怕
事情谁做规则 / 按键
走位自动每 4 m 落一个点；站着不动 2 s 停止采点，不堆点。
跳箱子自动空格起跳、落地配成一对 → 自动补两端路点 + A→B 边 + jump 链。
高台跳下自动没按空格、连续下降 ≥ 1.5 m → 单向落链（只下不上）。
岔路自动候选2.5 m 内第二次经过 / 出口 ≥ 2 → 标黄；按 1 确认成“双选”。
蹲点建议蹲 > 0.8 s 且位移 < 1 m → 只提示；按 4 才落点。
守点 / 补给手动需要意图，插件猜不到：5 守点、6 补给。
单向 / 双向复盘默认双向；落链默认单向，要反向往回走就在复盘里改。
04 · HUD 放哪中间永远不挡
左上 · REC时钟 / 距离 / 点数 / 事件
左下 · 轨迹缩略俯视，知道录到哪
下中 · 罗盘原有的，不动
右下 · 键位1-6 直选，15 s 后可淡
准星 / 中心区 · 空白

只占四角；F2 菜单是右侧 300 px 的小面板，不盖中心，打开也能继续走。录制结束只在底部弹一条“完成 + 去复盘”，不弹全屏结算。

为什么不放顶部横条：顶部要留给游戏自己的比分/击杀提示；横条会跟准星视线同一水平线，比四角更挡。
05 · 自动识别的阈值都能改，但先给一套能用的
判定条件产物 / 备注
跳跃按空格 & 离地 > 0.3 m；落地时水平位移 ≥ 1.5 m起跳点 + 落点各一个路点，补 A→B 边，写 jump add；< 1.5 m 直接丢掉。
高台落下没按空格，垂直下降 ≥ 1.5 m，落差 ≥ 2 m单向 落链，只允许高 → 低；落差 > 6 m 标“可能摔伤，待验证”。
岔路距已有路径 < 2.5 m 的第二次经过；或该点出口 ≥ 2标黄“候选”，按 1 确认成双选；不确认就不进图。
蹲点蹲 > 0.8 s 且 1 m 内位移只提示“这里像个蹲点”，按 4 才落 Bot_CrouchPos。
静止2 s 没位移暂停采样，HUD 写“站着不动 · 不采点”。
传送单帧位移 > 15 m断段，不连边；避免把传送画成穿墙长边。
悬空 / 坡度离地 > 0.6 m；坡度 > 25°标“待确认”告警；楼梯、箱子边最容易出这种点。
超长边相邻点距离 > 4.6 m复盘标橙；人机可能卡墙或绕路。
06 · 录制产物（示意）raw 是真相，graph 是视图
// recordings/level1_进攻主路_20261120_2130.json
{
  "version": 1,
  "map": { "level": "level1", "fp": "n786-57a4…", "label": "运输船" },
  "route": { "name": "进攻主路", "side": "BL", "preset": "std" },

  // 只追加、不改：崩溃也能从这儿续
  "raw": { "hz": 20, "points": [[-4.0, 1.5, -8.0, 0.00], …] },

  // 人按的 + 自动认的，都在这
  "marks": [
    { "t": 2.76, "kind": "jump",   "auto": true,  "from": […], "to": […] },
    { "t": 9.10, "kind": "drop",   "auto": true,  "h": 3.0 },
    { "t": 12.4, "kind": "branch", "auto": false, "p": […] }
  ],

  // 按间距重算出来的成品图（可反复重算）
  "graph": {
    "nodes": [{ "id": "r1", "p": […], "kind": "normal", "src": "walk" }],
    "edges": [{ "a": "r1", "b": "r2", "kind": "walk", "len": 3.8 }],
    "links": [{ "kind": "jump", "a": "r6", "b": "r7", "h": 1.2 }]
  },

  // 保存到 ④ 时真正追加的行
  "emit": ["node add -4.00 1.50 -6.00", "edge add …", "jump add …"]
}

raw 只追加、永不重写；graph/emit 每次重采样重算。这样“调间距”不是破坏性操作，录错一段也只删 raw 的一段。

09 · 硬约束（来自现有插件）不是设计偏好，是事实
槽位：③ 正式版 / 普通包加点只能复用“不可走”槽位；原生点全可走的图（运输船 786、沙漠要塞 12）会打 no free slot。当前 ④ 运输船是 grow 包（原生点全禁用、AddNode 新建，203 点），不受原生点数限制。
暴风（Nano30_Storm）原生 0 点：没有可借槽位，建不了空白包；只能从已有 ④ 包导入或换图。
跳链触发三条件：① 两端都解析到图上的路点；② 两点之间有 A→B 的边；③ 长度 ≥ 1.5 m。缺一条，Bot 都不会跳。

另外：源码的自动铺设是 4 m 采样 / 4.6 m 连边 / 9 m 蹲点 / 每 11 点造守区；markers 目前不分图（蹲守/守区/标签要按图清空）；数据流固定 ④ → ② → ③。

10 · 明确不做先把边界说清
  • ×
    录制时不弹大菜单F2 只开右侧小面板，不暂停、不锁键。
  • ×
    不自动判断“双选”出口是不是真能走，要人按 1 确认；误判会直接把 bot 引到死路。
  • ×
    不手画路线路线 = 点图 + 自动连边 + 跳/落链，和现在这套数据模型一致。
  • ×
    不直接写 ③录制只进 ④；② 要确认，③ 只走控制台部署。
  • ×
    不把跳/落当普通边方向性会丢：落链只下不上，跳链要两端都挂上。
11 · 需要你拍板的 6 个问题每个都给了我的建议
  1. 默认间距 4 m？建议 4 m，和源码自动铺设的 4 m 一致；窄道/楼梯预设切 2.5 m。
  2. 岔路全自动还是候选？建议“候选 + 按 1 确认”，宁可少标，不要标错。
  3. 录制写 ④ 的哪类包？建议 grow 空白包；普通包会撞槽位，录一半才报错最难受。
  4. 双选怎么补第二条？建议复盘里“从岔路点补一条出口”再回游戏走；录制时不做决策。
  5. 跳 / 落默认单向？建议单向；要反向跳回来，复盘里显式加反向边。
  6. 复盘页放哪？建议工作台加一个「录制」页，复用现有 2D 画布和版本切换；也能单独开。
