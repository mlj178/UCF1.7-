# 调试脚本使用说明

## 脚本信息

- **脚本名称**：AAAAA-debug_isMyPlayer_isMyWeapon.js
- **脚本位置**：d:\trae_project\ucf1.7-modifier\06-测试\
- **脚本功能**：调试 get_isMyPlayer 和 get_isMyWeapon 方法，分析为什么都返回0

## 使用方法

### 方法1：使用frida命令行（推荐）

```bash
# 通过进程名启动（推荐）
frida -n UnityCrossFire.exe -l AAAAA-debug_isMyPlayer_isMyWeapon.js

# 通过PID启动（备选）
# 1. 查找游戏进程ID
tasklist | findstr UnityCrossFire.exe

# 2. 注入脚本
frida -p <pid> -l AAAAA-debug_isMyPlayer_isMyWeapon.js
```

### 方法2：使用Python启动器

```python
import frida
import sys

def on_message(message, data):
    if message['type'] == 'send':
        print(f"[{message['payload']['level']}] [{message['payload']['module']}] {message['payload']['message']}")
    elif message['type'] == 'log':
        print(message['payload'])

# 连接到游戏进程
session = frida.attach("UnityCrossFire.exe")

# 加载脚本
with open("AAAAA-debug_isMyPlayer_isMyWeapon.js", "r", encoding="utf-8") as f:
    script_code = f.read()

script = session.create_script(script_code)
script.on('message', on_message)
script.load()

# 保持运行
sys.stdin.read()
```

## 可能的问题及原因

### 问题1：所有get_isMyPlayer()都返回0

**可能原因**：
- GameManager.myPlayer为null（游戏未完全初始化）
- 调用时机不对（在游戏加载完成前调用）

**解决方案**：
- 等待游戏完全加载后再注入脚本
- 确保已进入游戏房间

### 问题2：所有get_isMyWeapon()都返回0

**可能原因**：
- GameManager.myPlayer为null
- Weapon.owner字段为null
- 武器对象未正确初始化

**解决方案**：
- 检查Weapon.owner字段是否正确
- 确保玩家已装备武器

### 问题3：找不到Player

**可能原因**：
- GameManager未初始化
- 游戏模式不支持

**解决方案**：
- 确保已进入游戏房间
- 尝试不同的游戏模式

## 调试步骤

1. **启动游戏**
   - 打开UnityCrossFire.exe
   - 进入任意游戏房间

2. **注入脚本**
   - 使用frida注入脚本
   - 观察输出结果

3. **分析结果**
   - 检查GameManager.myPlayer是否有值
   - 检查Player数量是否正确
   - 检查get_isMyPlayer()返回值
   - 检查get_isMyWeapon()返回值
   - 检查Weapon.owner字段

4. **定位问题**
   - 如果GameManager.myPlayer为null → 游戏未初始化
   - 如果get_isMyPlayer()都返回0 → 比较逻辑问题
   - 如果Weapon.owner为null → 武器未初始化

## 注意事项

1. **注入时机**：必须在游戏完全加载后注入脚本
2. **游戏模式**：某些模式可能没有Player（如主菜单）
3. **日志限制**：每个模块最多输出100条日志，防止日志洪泛
4. **安全检查**：所有指针读取都有安全检查，避免崩溃

## 后续分析

根据调试结果，可以进一步分析：

1. **如果GameManager.myPlayer为null**
   - 需要Hook GameManager的初始化过程
   - 等待myPlayer赋值后再调用

2. **如果get_isMyPlayer()逻辑正确但返回0**
   - 检查Player实例是否正确
   - 检查比较逻辑是否正确

3. **如果Weapon.owner字段不正确**
   - 需要Hook武器创建过程
   - 确保owner字段正确赋值
