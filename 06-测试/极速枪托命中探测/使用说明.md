# 极速枪托命中减速只读探测

## 目的

确认本地枪托在命中人物后，是否进入 `CFAnimator.PlayKnifeHitStunAnim` 的动画暂停分支，以及该暂停与枪托开始、伤害判定和动画退出之间的实际时间关系。

初始探测脚本只记录事件；后续两个验证脚本仅作用于运行中的游戏，均不修改整合包 2.5 文件。

## 运行前准备

1. 启动 `UnityCrossFire.exe` 并进入可进行枪托测试的房间。
2. 保持整合包 2.5 的“极速枪托”处于你平时复现问题的状态。
3. 打开 PowerShell，运行：

```powershell
python "D:\trae_project\ucf1.7-modifier\06-测试\极速枪托命中探测\run_fast_stock_hit_probe.py"
```

程序只会附加到已经运行的游戏；找不到游戏进程时会直接退出，不会启动游戏。

## 建议测试顺序

1. 对空气连续做 5 次枪托，间隔约 1 秒。
2. 对同一种目标、相近距离连续做 5 次命中枪托，间隔约 1 秒。
3. 按 `Ctrl+C` 结束，程序会先调用 `cleanup()` 再保存日志。

日志文件会保存在本目录，名称类似：

```text
fast_stock_hit_probe_20260902_153000.log
```

## 关键日志事件

| 事件 | 含义 |
| --- | --- |
| `special_button_down` | 本地玩家开始枪托。 |
| `knife_attack_event` | 枪托动画事件到达伤害时刻。 |
| `call_knife_attack` | 进入近战判定和伤害收集。 |
| `entity_hurt` | 实体接收伤害；日志保留 DamageEventData 中的攻击者和受害者指针。 |
| `knife_hit_stun_start` | 游戏开始近战命中硬直流程。 |
| `knife_hit_stun_coroutine_step` | 命中硬直协程推进；IDA 已确认该协程会短暂把 Animator 速度置为 0 后恢复。 |
| `weapon_animation_exit` | 本地枪托动画退出并解除枪托状态。 |

每条本地枪托相关日志都会带 `session_id` 和 `since_special_ms`。比较未命中与命中两组中，从 `special_button_down` 到 `weapon_animation_exit` 的时长，并观察是否夹有 `knife_hit_stun_start`，即可确定命中减速是否来自该硬直链路。

## 结果判定

- 命中组出现 `knife_hit_stun_start`，且枪托退出耗时明显更长：优先研究仅对本地攻击者缩短或跳过该命中硬直。
- 命中组更慢但没有该事件：转查 `knifeAttackAnim` 解除时机与角色动画路径，不要修改受击硬直。
- 未命中和命中组的时序一致：现象可能来自网络、目标状态或视觉表现，需要增加角色动画层的对象关联日志后再下结论。

## 命中硬直旁路验证

日志已经确认命中硬直作用于本地枪托对象后，可以在不修改整合包 2.5 的前提下运行临时验证版本：

```powershell
python "D:\trae_project\ucf1.7-modifier\06-测试\极速枪托命中探测\run_fast_stock_hit_probe.py" --mode bypass
```

它只会在本地枪托对象进入 `CFAnimator.PlayKnifeHitStunAnim` 时跳过原函数；其他角色和目标仍走游戏原逻辑。按 `Ctrl+C` 会调用 `cleanup()` 并通过 `Interceptor.revert` 恢复原函数。

验证时请在同一房间交替测试空枪托和命中枪托，重点确认命中后是否不再出现原来的明显停顿。这个最小验证版本会同时跳过本地命中镜头震动，仅用于证明动画硬直就是减速来源；若效果正确，正式实现应进一步保留镜头震动，只取消 Animator 暂停。

## 精确验证：保留命中镜头反馈

```powershell
python "D:\trae_project\ucf1.7-modifier\06-测试\极速枪托命中探测\run_fast_stock_hit_probe.py" --mode precise
```

此版本不替换 `PlayKnifeHitStunAnim`。它让原协程完成命中镜头震动的调用；仅在协程的 `state=1` 分支将本地人物与手部 Animator 置零后，立即将它们恢复为 `1.0`。日志中的 `local_hit_stun_speed_restored` 表示一次精确恢复成功。请连续命中至少 15 次，并观察镜头震动是否仍存在、枪托是否持续流畅，以及切枪或死亡后是否正常。按 `Ctrl+C` 结束并保存清理记录。

## 第三版验证：缩短命中等待

```powershell
python "D:\trae_project\ucf1.7-modifier\06-测试\极速枪托命中探测\run_fast_stock_hit_probe.py" --mode wait
```

此版本保留原命中协程、Animator 置零/复原过程和镜头震动；仅在“本地对象、命中暂停阶段、同一调用线程”同时成立时，将该阶段创建的 `WaitForSeconds` 参数改为 `0`。`local_hit_stun_wait_shortened` 表示一次命中等待已被缩短。请交替测试空枪托与连续命中，并检查命中反馈、枪托连贯性、切枪和死亡恢复。按 `Ctrl+C` 清理。
