HUD_Crosshair

准星 HUD：根据玩家武器和状态显示准星

它直接保存的主要类型

GameObject 字段依据：allCrosshair

Unity 场景对象或预制体。这里多用于 UI 容器、玩家条目模板或模式对象生成。

Image 字段依据：sniperCrossBackGround

Unity UI 图片：显示图标、准星、血条等界面元素

Player 字段依据：player

玩家战斗主体。保存生命、阵营、武器、输入、模型和 HUD 状态，是本机玩家、队友、敌人和 Bot 在战斗层的核心对象。

RaycastHit 字段依据：zoomRaycastTemp

Unity 射线命中信息：记录开火、瞄准或检测命中的物体和位置

readonly Color 字段依据：color_ZoomTeammate / color_ZoomEnemy

颜色配置类型：用于 UI、特效、渲染或阵营表现的颜色数据

RectTransform 字段依据：sniperCross / hitRect / crosshair1_horizontal / crosshair1_vertical

Unity UI 矩形变换：控制 HUD/UI 元素位置、尺寸和锚点

Text 字段依据：zoomTargetTexts

Unity UI 文本组件。用于显示比分、回合、倒计时、模式提示等。

字段系统分类统计

武器与伤害结算 3 个字段

负责武器、弹药、命中、伤害、死亡和击杀反馈。

Bot/AI/寻路 7 个字段

负责电脑玩家目标、路径、动作和决策状态。

HUD/UI/计分板 1 个字段

负责比分、时间、玩家条目和模式提示显示。

玩法规则/比分回合 1 个字段

负责比分、目标分数、目标回合和回合推进。

玩家与阵营统计 2 个字段

负责双方人数、存活人数和本机玩家引用。
