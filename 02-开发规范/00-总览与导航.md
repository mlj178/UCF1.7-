## 1. 按角色阅读顺序

### 新 AI 会话上手


## 3. 开发顺序总览

```text
说清需求 -> 查 dump/IDA -> 可选写简要说明 -> 讲清原理 -> 停下等确认
-> 写唯一核心 JS -> 写唯一 CustomTkinter UI -> 自动验证语法
-> 进游戏实测 -> 稳定后按 21 接入整合包 -> 同步更新 22 持久化总表
```

不要跳过单功能验证直接改整合包。

## 4. 一句话提醒下一位 AI

先读资料，先查成功案例，先用 IDA MCP 确认逻辑，再写测试代码。不要猜地址，不要乱改旧功能，不要把整合包当试验田。
