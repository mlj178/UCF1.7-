# 编码与文件规范

这份规范是项目所有文本文件编码的**唯一权威**。

它适用于：

```text
单功能阶段（05-正式功能/）
整合包阶段（04-正式发行版/全功能整合包x.x/game_modifier/）
所有文档、源码、配置、脚本
```

其他文档不再单独维护编码规范，统一引用本文档。

## 1. 基本要求

所有新建和修改的文本文件必须使用 UTF-8 编码。

默认使用 UTF-8 无 BOM。

禁止使用 GBK、ANSI、Windows 默认编码保存源码或文档。

## 2. 适用范围

以下类型的文件必须统一 UTF-8：

```text
.md     文档文件
.py     Python 源码
.js     JavaScript 源码
.json   配置文件
.txt    文本文件
.bat    批处理脚本
.ps1    PowerShell 脚本
.yaml   YAML 配置
.yml    YAML 配置
.ini    配置文件
.cfg    配置文件
.toml   配置文件
```

所有包含中文、emoji、特殊符号的文件，必须确认保存为 UTF-8。

## 3. Python 读写规范

Python 读取文本文件时必须显式写：

```python
with open(path, "r", encoding="utf-8") as f:
    content = f.read()
```

Python 写入文本文件时必须显式写：

```python
with open(path, "w", encoding="utf-8") as f:
    f.write(content)
```

## 4. JSON 读写规范

Python 写入 JSON 时必须使用：

```python
import json

with open(path, "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

Python 读取 JSON 时必须使用：

```python
import json

with open(path, "r", encoding="utf-8") as f:
    data = json.load(f)
```

## 5. 日志规范

`logging.FileHandler` 必须指定 `encoding="utf-8"`：

```python
import logging

handler = logging.FileHandler(log_path, encoding="utf-8")
```

不允许因为 Windows 中文环境而使用默认编码读取文件。

## 6. manifest.json 编码要求

插件 `manifest.json` 中的以下字段必须 UTF-8：

- `display_name` 功能显示名
- `icon` 图标
- `desc` 功能描述
- `controls.label` 控件标签
- `display_values` 显示值

UI 文本、功能名称、按钮文字、提示文字、日志文字、manifest 中文字段、README 文档全部必须 UTF-8。

程序标题、tab 名称、卡片名称、卡片说明、状态栏文字、设置窗口文字不能出现乱码。

## 7. 新增功能编码要求

新增功能时，如果出现中文或 emoji，必须先确认文件编码是 UTF-8。

文档文件 `.md` 也必须使用 UTF-8，不允许用 ANSI / GBK 保存。

## 8. 打包迁移要求

打包、复制、迁移版本时，不能破坏 UTF-8 编码。

不允许把正常中文替换成 Unicode 乱码、问号或不可读字符。

不允许把中文转成错误编码后提交。

## 9. 乱码禁止

不允许出现以下情况：

```text
????    问号代替中文
       Unicode 替换字符
乱码中文
emoji 丢失
```
