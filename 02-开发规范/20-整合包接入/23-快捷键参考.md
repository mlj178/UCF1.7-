# 快捷键说明-整合包通用参考

这份不是某个单独版本的说明，而是后续整合包继续迭代时的快捷键参考。只有当新功能可能需要快捷键时，再看这里判断。

原则很简单：战斗中经常临时开关的，适合；创建房间前才该设置、容易误触、或者本身是复杂配置页的，不适合。

> 基准版本：整合包 2.7（40 个功能）。快捷键位置、专用键定义以 `core/config.py` 为准。

## 文档职责

这份文档只管"要不要进快捷键选项"，不管功能怎么接入，也不管开关和参数怎么保存。

新增功能时先看主接入规范。只有当这个功能可能需要快捷键时，再读这份文档。

## 可用位置池

`core/config.py` 的 `HOTKEY_POSITIONS` 只有这 9 个位置：

```text
Ctrl+1  Ctrl+2  Ctrl+3  Ctrl+4  Ctrl+5  F1  F2  Alt+1  Alt+2
```

其中 `F1`、`F2`、`Alt+1`、`Alt+2` 已被定点瞬移固定占用（`DEDICATED_HOTKEY_ACTIONS`），不会出现在设置页的普通功能下拉框里。

**所以普通功能实际只能绑 `Ctrl+1` ~ `Ctrl+5` 五个位置。** 位置池是全局资源，用完就没有了；新增可绑功能前先确认还有空位。

## 普通快捷键选项

这些功能出现在设置页的“功能快捷键绑定”下拉框里（manifest 里 `hotkey.enabled = true`）：

| 功能 | 建议 | 理由 |
|---|---|---|
| 08-聚怪 | 适合 | 常用，一键触发 |
| 10-回合跳过 | 适合 | 按钮型功能，适快捷触发 |
| 20-时间加速 | 适合 | 适合开关，倍率不靠快捷键调 |
| 21-第三人称视角 | 适合 | 视角类开关，战斗中切换 |
| 24-人机暂停 | 适合 | 测试、刷图、观察时常用 |
| 29-子弹穿墙/弹体穿墙 | 适合 | 需要临时开关 |
| 36-增加血量 | 适合 | 一次性动作，战斗中顺手加一次 |
| 37-增加防化服 | 适合（限多人生化） | 一次性动作，回合内反复补 |

`15-多人生化Buff选择`、`16-赋予武器`、`18-方框透视`、`19-强制决战回合`、`26-手雷模式` 是特殊页/特殊机制，不参与普通快捷键绑定。

## 固定专用快捷键

这些也是快捷键，但不是设置页下拉框里随便绑定的功能。它们是功能自己固定占用的快捷键，页面上只做展示：

| 功能 | 键 | 动作 |
|---|---|---|
| 31-定点瞬移 | `Alt+1` | 保存点位1 |
| 31-定点瞬移 | `Alt+2` | 瞬移到点位1 |
| 31-定点瞬移 | `F1` | 保存点位2 |
| 31-定点瞬移 | `F2` | 瞬移到点位2 |
| 34-角色变身 | `Alt+Q` | 本地玩家：选择英雄 |
| 34-角色变身 | `Alt+W` | 本地玩家：选择超级终结者 |
| 34-角色变身 | `Alt+E` | 人类 Bot：随机英雄 |
| 34-角色变身 | `Alt+R` | 幽灵 Bot：随机超级终结者 |
| 38-直接变身救世主 | `Alt+A` | 玩家变身救世主 |
| 38-直接变身救世主 | `Alt+S` | 人类人机变救世主 |
| 39-直接变身剑客 | `Alt+D` | 玩家变身剑客 |
| 39-直接变身剑客 | `Alt+F` | 人类人机变剑客 |

固定专用快捷键不要和普通快捷键混在一起统计，也不要在普通下拉绑定里重复占用。

## 后续可考虑

位置池已经排满（5 个通用位 + 4 个瞬移专用位 + 8 个变身专用位）。真要再加专用键，需要同时改三处：

1. `core/config.py` 里加位置与 `*_HOTKEY_ACTIONS` 映射；
2. `hotkey_manager.py` 注册/注销逻辑；
3. `settings_window.py` 的展示行。

不建议为了单个功能临时加键——先确认现有位置真的不够用。

## 新功能接入时怎么判断

新增功能进整合包时，按这个顺序想：

1. 这个功能是不是战斗中会反复开关？
2. 它是不是简单开关或按钮，不需要先选一堆配置？
3. 误触一下会不会把房间规则、ESP、模式状态弄乱？
4. 如果它只是开局前配置一次，就不要放快捷键。
5. 如果它更适合先在 UI 里调参数，再手动开关，也可以不放快捷键。

满足前两条，并且误触风险低，才建议在 manifest 里加：

```json
"hotkey": {
  "enabled": true
}
```

只加进快捷键选项，不代表必须默认绑定。默认绑定要看是否真的常用、有没有空位、会不会和专用快捷键冲突。
