# 设置页 · 红色主题 Tab 设计

这份文档记录设置窗口里新增的「红色主题」Tab 的需求和设计方案。以后改这个 Tab 时，对照这份文档检查，别把原本的设计改偏。

## 0. 概念绑定表

统一命名。中文给人看，英文 ID 给代码和 AI 对照用。

- `settings_window`（设置窗口）：点击设置后弹出的窗口。
- `red_theme_tab`（红色主题页）：设置窗口里新增的 Tab，本文档的设计对象。
- `image_carousel`（图片轮播区）：展示多张图片、可左右切换的区块。
- `text_viewer`（文字展示区）：展示文字、可左右切换上一段/下一段的区块。
- `nav_button`（切换按钮）：位于 `position_label` 左右两侧的「‹」「›」按钮，与 `position_label` 同一行。
- `position_label`（位置标签）：显示「X / N」格式的位置文字，数字和斜杠之间各有一个空格。

## 1. Tab 命名与入口

| 项目 | 值 |
|---|---|
| Tab 英文 ID | `red_theme_tab` |
| Tab 显示名称 | 红色主题 |
| 所属窗口 | `settings_window`（设置窗口） |
| Tab 位置 | 排在设置窗口关于 Tab 之后 |

**设计说明**：Tab 名叫「红色主题」，简洁直白，用户一眼能看出这一页是关于红色主题的内容展示。

## 2. 整体布局

`red_theme_tab` 打开后，从上到下竖向排列两个独立区块，每个区块功能单一、互不干扰：

1. `image_carousel`（图片轮播区）—— 最上方
2. `text_viewer`（文字展示区）—— 最下方

两个区块都用同样的「中间内容 + 下方控制条（左按钮 + 位置标签 + 右按钮，同一行）」交互模式，用户学会一个就会用另外一个。

## 3. 需求与设计对应

### 需求 1：新增一个红色主题的 Tab

**设计**：在 `settings_window` 里新增 `red_theme_tab`，显示名称「红色主题」。Tab 整体采用红色主题配色（具体色值在 §5 占位，后续补充）。

### 需求 2：放图片展示

**设计**：用 `image_carousel` 区块展示图片。

- 中间显示当前图片。
- 图片下方展示该图的 `title` 和 `description`（来自 `images.json`，两者都为空则不显示该区域）。`title` 加粗，`description` 普通字号，均在图片下方、控制条上方。
- 图片下方是一行控制条，结构为「`nav_button`（‹） + `position_label` + `nav_button`（›）」三个元素紧贴成一组、整体居中显示（按钮贴近位置标签，仅保留小间距，不分散在内容区两侧），点击切换到上一张/下一张。
- `position_label` 显示数字位置，格式为「`X / N`」（数字和斜杠之间各有一个空格），例如 `1 / 4`。
- 切到第一张时左按钮置灰，切到最后一张时右按钮置灰。

**用户视角**：打开这一页就能看到一张图，图下方可能有标题和说明文字，再下面一行有左按钮、位置数字、右按钮，点右边按钮看下一张，点左边按钮回上一张，数字告诉自己看到哪了。

### 需求 3：放文字展示

**设计**：用 `text_viewer` 区块展示毛泽东语录（来自 `mao_zedong_quotes.json`）。

- 中间显示当前一条语录的 `content`，文字色 `#CC0000`。
- 语录正文下方显示出处行，格式「—— `source`　`date`」（`source` 或 `date` 为空则省略对应部分；两者都为空则整行不显示），用浅红色小字，右对齐。
- 语录下方是一行控制条，结构为「`nav_button`（‹） + `position_label` + `nav_button`（›）」三个元素紧贴成一组、整体居中显示（按钮贴近位置标签，仅保留小间距，不分散在内容区两侧），点击切换到上一条/下一条。
- `position_label` 显示数字位置，格式为「`X / N`」（数字和斜杠之间各有一个空格）。

**用户视角**：能看到毛泽东经典语录，正文是红色，下面小字注明出处和年份，再下面一行的左右按钮翻看上一条/下一条，中间数字显示当前第几条。

## 4. 统一交互规则

两个区块共用一套交互，降低学习成本：

| 交互 | 行为 |
|---|---|
| 点右按钮 `›` | 切到下一个（图片/文字） |
| 点左按钮 `‹` | 切到上一个 |
| 到第一个 | 左按钮置灰，不能再点 |
| 到最后一个 | 右按钮置灰，不能再点 |
| 位置标签 | 始终显示「X / N」格式，数字和斜杠之间各有一个空格，例如 `1 / 4` |
| 控制条布局 | `nav_button`（‹）、`position_label`、`nav_button`（›）三个元素紧贴成一组、整体居中显示；按钮贴近位置标签，仅保留小间距，不分散在内容区两侧 |
| 循环切换 | 默认不循环（到头就停） |

## 5. 内容区高度规范

**核心原则**：容器固定高度，内容适配容器，而不是容器适应内容。切换图片或语录时，区块整体高度保持不变，避免页面抖动。

### 5.1 图片轮播区

| 项目 | 值 |
|---|---|
| 内容区固定高度 | `280px` |
| 内容区固定宽度 | `430px`（随设置窗口 500 宽留 padding） |
| 图片适配方式 | `Image.thumbnail` 等比缩放，居中显示，不裁剪不变形 |
| 切换行为 | 切图时容器不动，图片在容器内变化 |

**设计说明**：宽图横向铺满、长图竖向铺满，都装进 430×280 的固定容器里居中。容器高度锁死，切到小图时下方控制条位置不变。

### 5.2 文字展示区

| 项目 | 值 |
|---|---|
| 内容区固定高度 | `180px` |
| 正文字号 | 12 号，`#CC0000`，`wraplength=420` 自动换行 |
| 出处行字号 | 10 号，浅红，右对齐 |
| 超长语录处理 | 内容区内部自动滚动（用 `CTkTextbox` 实现），保证完整显示 |
| 切换行为 | 切语录时容器不动，文字在容器内变化 |

**设计说明**：180px 能装下最长语录的 3-4 行换行 + 出处行。短语录（如「人民万岁！」）在容器内居中，留白可接受。极少数超长语录启用内部滚动，不截断、不撑高容器。

**为什么不用「容器适应内容」**：语录长度从 4 字到 60 字不等，若容器跟随内容变高，切换时区块高度反复跳动，下方控制条和相邻区块位置都会抖动，体验差。固定高度是桌面设置页小区域的标准做法。

### 6.1 资源路径与命名

| 类型 | 子路径 | 命名规则 | 当前文件 |
|---|---|---|---|
| 图片 | `资源\红色图片\` | `<序号>.jpg` | `1.jpg` ~ `8.jpg`（共 8 张） |

### 6.2 图片元数据文件 `images.json`

`红色图片\images.json` 是图片轮播区的元数据来源，集中登记每张图片的标题、描述和加载顺序，免去改代码。

**结构**：

```json
{
  "version": 1,
  "images": [
    {
      "filename": "1.jpg",
      "order": 1,
      "title": "",
      "description": "",
      "width": 1920,
      "height": 1280
    }
  ]
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 作用 |
|---|---|---|---|
| `version` | number | 是 | 结构版本号，当前 `1` |
| `images` | array | 是 | 图片条目数组 |
| `images[].filename` | string | 是 | 图片文件名（不含路径），必须真实存在于 `红色图片\` 目录 |
| `images[].order` | number | 否 | 加载顺序，数字小的在前；缺失时按 `filename` 数字兜底 |
| `images[].title` | string | 否 | 图片标题，展示在图片下方，加粗；为空不显示 |
| `images[].description` | string | 否 | 图片描述，展示在标题下方，普通字号；为空不显示 |
| `images[].width` | number | 否 | 图片宽度（像素），仅作记录，程序运行时按实际文件适配 |
| `images[].height` | number | 否 | 图片高度（像素），仅作记录 |

**加载规则**：

- 程序优先读取 `images.json`，按 `order` 升序排序展示。
- `filename` 在目录中找不到的条目会被跳过，不影响其他图片。
- `images.json` 不存在或 JSON 解析失败时，回退到扫描 `红色图片\` 目录，按文件名数字升序展示（此时无标题/描述）。
- `title` 和 `description` 都为空时，图片下方不显示描述区域，保持紧凑。

### 6.3 资源排序规则

- **图片**：优先按 `images.json` 的 `order` 字段升序；无 JSON 时按文件名数字升序（`1.jpg` → `2.jpg` → `3.jpg` → `4.jpg`）。
- **语录**：按 `mao_zedong_quotes.json` 中 `categories` 数组顺序，每个分类内按 `quotes` 数组顺序展平。

### 6.4 语录元数据文件 `mao_zedong_quotes.json`

`红色文案\mao_zedong_quotes.json` 是文字展示区的数据来源，收录毛泽东经典语录。

**结构**：

```json
{
  "title": "毛泽东经典语录精选",
  "description": "从《毛泽东选集》及相关文献中精选的经典语录...",
  "total_count": 60,
  "categories": [
    {
      "category_id": 1,
      "category_name": "阶级斗争与革命斗争",
      "category_en": "Class Struggle and Revolutionary Struggle",
      "quotes": [
        {
          "id": 1,
          "content": "谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。",
          "source": "《中国社会各阶级的分析》",
          "date": "1926年3月",
          "collection": "《毛泽东选集》第一卷"
        }
      ]
    }
  ],
  "metadata": {
    "created_date": "2026-08-08",
    "version": "1.0",
    "language": "zh-CN",
    "sources": ["《毛泽东选集》", "《毛泽东文集》", "..."]
  }
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 作用 |
|---|---|---|---|
| `title` | string | 否 | 语录集标题，仅作记录 |
| `description` | string | 否 | 语录集说明，仅作记录 |
| `total_count` | number | 否 | 语录总数，仅作记录 |
| `categories` | array | 是 | 分类数组 |
| `categories[].category_id` | number | 否 | 分类编号，仅作记录 |
| `categories[].category_name` | string | 否 | 分类中文名，仅作记录 |
| `categories[].category_en` | string | 否 | 分类英文名，仅作记录 |
| `categories[].quotes` | array | 是 | 该分类下的语录数组 |
| `categories[].quotes[].content` | string | 是 | 语录正文，展示为主文字（`#CC0000`） |
| `categories[].quotes[].source` | string | 否 | 出处，展示在正文下方（浅红小字）；为空则不显示 |
| `categories[].quotes[].date` | string | 否 | 时间，与 `source` 拼接展示；为空则不显示 |
| `categories[].quotes[].collection` | string | 否 | 所属集册，仅作记录，不展示 |

**加载规则**：

- 程序按 `categories` 数组顺序遍历，每个分类内按 `quotes` 数组顺序，展平为一个语录列表。
- `content` 为空的条目会被跳过。
- `source` 和 `date` 都为空时，正文下方不显示出处行。
- `mao_zedong_quotes.json` 不存在或解析失败时，文字区块降级为「红色文案资源待补充」占位提示。
- `category_id`、`category_name`、`collection` 等字段仅作记录，程序当前不展示，后续可扩展。
