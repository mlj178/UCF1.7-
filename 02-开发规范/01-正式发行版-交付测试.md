# 正式发行版-交付测试

> 这份清单按"测试节点"排列，覆盖过往功能最常翻车的场景。实机测试照着节点逐个过，每个节点都写清了老问题、原因和必测点。

## 一、过往最常翻车的三个老问题

1. **退出房间重开一局，功能就失效了**——明明 UI 是开启的，只有第一次进游戏房间生效。
   - 原因一句话：功能只在第一次进房时"应用"过一次；退房后游戏对象重建了，旧的应用状态没跟过来，也没人重新应用。
   - 必测：开功能 → 进房生效 → 退出房间重开一局 → 确认还生效。

2. **UI 显示开着，进游戏必须手动开关一次才生效**。
   - 原因一句话：程序启动时恢复了开关，但当时还没进房、游戏对象没就绪，enable 没真正写进游戏；进房后没人再补一次。
   - 必测：先开功能再进房，全程不动开关，确认进房后自己就生效。

3. **滑块数值显示和实际不一致，进游戏必须手动调一次才生效**。
   - 原因一句话：参数只在拖动时写了一次，进房后没有按参数重新应用。
   - 必测：调好数值 → 进房 → 确认实际表现就是那个数值，不用再动。

## 二、按节点逐个测

### 1. 启动 + 连接游戏
- 上次的开关和参数能恢复（feature_state / user_config）。
- 恢复的开关进房后能自动生效（对应老问题 2）。
- 游戏进程重启 / 被杀后，UI 能自动重连，并按当前开关状态恢复。

### 2. 未进房就开功能 → 再进房
- 不动开关、不调参数，直接进房就能生效（对应老问题 2、3）。
- 按钮型功能（回合跳过、瞬移、赋予武器）：进房前点了不留残留，进房后点才正常。

### 3. 进房后开功能
- 大厅开了没反应是正常；进房后开要立即生效。
- 模式类功能（回合、模式切换、生化 Buff）：确认只在当前模式/多人生化下生效。

### 4. 退出房间 / 重开一局
- 退房后不再写旧对象：不报错、不卡死、不残留。
- 重开一局能重新生效（对应老问题 1）。

### 5. 死亡 / 重生
- 死亡不崩、不报错；重生后功能自动恢复。
- 依赖玩家的功能（无敌、移速、穿墙、视角）：重生后必须重新拿到新玩家对象，不能还拿着旧地址。

### 6. 切武器 / 捡补给箱武器
- 换武器后功能不丢（无限子弹、射速、无后座、极速枪托）。
- 特殊武器重点测：RPG/AT4/榴弹、狙击/半自动。补给箱捡到的特殊枪有时要"部署两次"或打两枪才生效（射速变快、连狙）。

### 7. 反复开关
- 连续开/关 5 次以上：不重复装 Hook、不叠加定时器、不卡。
- 关掉就真的不生效，不能再改游戏。

### 8. 关闭功能 / 退出 UI
- 关闭功能后定时器停、能恢复的数值恢复。
- 直接关 UI：清理干净，游戏里不残留，下次启动不报错。

### 10. 人机局 vs 多人生化
- 只该影响本地玩家的功能：确认不误伤 Bot / 队友（无敌、移速、射速、穿墙）。
- 只该在生化模式生效的：普通模式不该有影响。
