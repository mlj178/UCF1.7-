# 30｜调整伤害倍率（Damage Multiplier）

**来源**：`features/30_damage_multiplier/`（script.js）+ 开发素材 `05-正式功能/30-增加伤害倍率/增加伤害倍率-简要说明.md`、`伤害来源分类与倍率可行性.md`

## 核心原理

- **一句话**：Hook `Entity.OnEntityHurt` 与 `Player.OnEntityHurt`，在 x86 cdecl 栈上定位按值传入的 `DamageEventData`，仅在 `attacker`（或其 owner）为本地玩家、`victim` 非本地玩家时把 `damage` 字段乘以倍率；通过记录 `WPN_Missile.SetOwner / SentryGun.SetData` 实现导弹/炮台这类“伤害源非玩家本体”的归属映射，本质是“就地改写伤害事件参数”类方案。
- **手段归类**：Interceptor.attach + 栈参数定位（DamageEventData 按值传入）+ owner 映射表 + 生命周期 Hook 清理。

## 关键 Hook 表（GameAssembly.dll）

| RVA | 符号 | 手段 | 作用 |
|---|---|---|---|
| 0xB3F470 | Entity.OnEntityHurt | Interceptor.attach | 通用伤害入口：定位 DamageEventData 并放大 |
| 0xB516B0 | Player.OnEntityHurt | attach | 玩家伤害入口：归属判断 + 防二次放大 |
| 0xB55FD0 | Player.get_isMyPlayer | NativeFunction | 本地玩家判断 |
| 0xB66390 | WPN_Missile.SetOwner | attach | 记录 missile→owner（RPG/AT4/榴弹） |
| 0xB1E030 | SentryGun.SetData | attach | 记录炮台→owner（机枪守卫） |
| 0xAFAA40 / 0xAEBCB0 / 0xAEBD40 | GameManager.GameRoundEnd / NewGameRoundStart / OnDestroy | attach | 回合/房间生命周期清空 owner 映射 |

## 修改的关键字段

| 偏移 | 字段 | 值/说明 |
|---|---|---|
| DamageEventData +0x00 | attacker | 读取攻击者（或其 owner）判断归属 |
| DamageEventData +0x04 | victim | 读取受害者（非本地玩家才放大） |
| DamageEventData +0x08 | damage | 乘以倍率（钳制上限 maxDamage=999999） |
| DamageEventData +0x34 | type | 伤害类型过滤（默认 Gun/Knife/Grenade/Other，Infect 默认不放大） |
| DamageEventData +0x38 | damageTag | 特殊武器/技能判断（观察用） |
| DamageEventData +0x3C / +0x40 | wpnIndex / wpnSprIndex | 武器索引判断 |
| DamageEventData +0x44 | ignoreDmgRate | 是否忽略倍率 |

**特殊处理**：
- **防二次放大（playerHurtDepth）**：`Player.OnEntityHurt` 会调用基类 `Entity.OnEntityHurt`，用深度计数让同一调用链内的 `Entity.OnEntityHurt` 跳过，避免伤害被放大两次。
- **owner 映射 + TTL**：missile/炮台 owner 记录带 15s 过期（ownerTtlMs），防旧映射误用；命中时优先用 attacker 本体，本体非本地玩家再查 owner。
- **伤害类型过滤**：默认放大 Gun/Knife/Grenade 并允许 Other（特殊技能），Infect（生化感染）默认不放大，可配置 `include_infect`。
- **作用域钳制**：multiplier 1.0–20.0、damage ≤ 999999；默认跳过本地受害（不把自己打自己的伤害放大）。
- **统计与限频**：记录各跳过原因（notLocalAttacker/localVictim/invalid 等）便于诊断；错误计数超限自动关闭防失控。
- **可逆卸载**：回合结束/新回合/房间销毁时清空 missile/sentry owner 映射，disable 时 detach 全部 hooks。

## 作用范围

仅“本地玩家造成”的有效伤害（含本地导弹/榴弹/炮台/守卫映射回本地玩家的来源）。不放大其他玩家、Bot、人机造成的伤害；不放大敌方打自己的伤害；非本地归属或无效/0/负伤害不放大。不属于阵营倍率，也不属全局倍率。

## 产品设计巧思

- 只放大“自己打出去的伤害”，Bot/他人/敌人打你完全不受影响，PVE 体验翻倍但不会互相秒杀。
- 覆盖范围广：枪、刀、手雷、RPG/AT4/榴弹、炮台/守卫都自动映射回本地玩家。
- 倍率 1.0–20.0 可调 + 伤害上限钳制，防止数值溢出；默认避开感染伤害，生化玩法不被破坏。

## 开发历程（重点）

### 踩过的坑

1. **玩家伤害被放大两次**
   - 一开始没考虑到：`Player.OnEntityHurt` 会调用基类 `Entity.OnEntityHurt`，两个 Hook 各自放大一次。
   - 出问题：本地玩家造成的伤害明显高于设置倍率（平方级）。
   - 怎么修：引入 `playerHurtDepth`，Player 入口期间同一调用链的 Entity.OnEntityHurt 跳过不二次修改。

2. **RPG/AT4/榴弹/炮台等特殊来源放大不到**
   - 一开始没考虑到：这些伤害的 `attacker` 不是玩家本体（是 missile/炮台），直接按 attacker==isMyPlayer 判断会漏。
   - 出问题：本地 RPG/炮台打出的伤害不放大。
   - 怎么修：Hook `WPN_Missile.SetOwner` / `SentryGun.SetData` 记录 owner 映射，命中时按 owner 回查本地玩家；映射带 TTL 防陈旧。

3. **DamageEventData 栈定位与字段偏移**
   - 一开始没考虑到：`DamageEventData` 按值传入 x86 cdecl 栈，字段偏移与实例布局不同；type 偏移与部分资料（如 12-金刚不坏）不一致。
   - 出问题：字段读错导致归属/类型判断失效。
   - 怎么修：按 dump.cs + IDA 汇编核对栈布局（attacker=0x00/victim=0x04/damage=0x08/type=0x34…），并在脚本头注释来源。

4. **感染伤害（Infect）被误放大破坏生化玩法**
   - 一开始没考虑到：`type=4` 的感染伤害若被放大，生化玩法可能失衡。
   - 出问题：生化感染伤害异常放大。
   - 怎么修：默认 `include_infect=false`，Infect 类型跳过，可配置放开。

### 方案迭代

- **早期（只 Hook Entity.OnEntityHurt）**：放大所有经过的伤害。缺点：玩家伤害二次放大、特殊来源漏放大。
- **中期（加 Player 入口防重 + owner 映射）**：playerHurtDepth + missile/炮台映射。缺点：Infect 误放大、字段偏移踩坑。
- **最终（全过滤 + 钳制 + 生命周期清理）**：类型过滤（Infect 默认排除）+ 作用域钳制 + owner TTL + 回合/房间清理，统计各跳过原因便于诊断。

### 一开始没考虑到的点

- 继承链上的基类 Hook 与子类 Hook 会同时触发，需要深度计数防重。
- “攻击者”不一定是玩家本体，导弹/炮台/守卫的归属要走 owner 映射。
- DamageEventData 是按值传栈的，字段偏移需单独核对，不能套实例布局。
- 伤害类型（type=4 Infect 等）会影响玩法平衡，需要默认过滤 + 可配置。

### 经验教训

- 伤害类功能先做**来源分类与归属映射**，再谈放大，否则特殊武器/载具必然漏。
- 继承链多 Hook 要防重复放大，用深度计数而非简单 enabled 开关。
- 栈传参结构体的字段偏移要**按调用约定单独核对**，不能与实例字段混用。

## 一句话总结

Hook `Entity/Player.OnEntityHurt` 定位栈上按值传入的 `DamageEventData`，仅当 attacker（或其 missile/炮台 owner）为本地玩家且 victim 非本地时放大 damage，用 playerHurtDepth 防二次放大、WPN_Missile.SetOwner/SentryGun.SetData 做归属映射、Infect 默认排除；踩坑集中在“继承链重复放大”“特殊来源漏放大”“栈字段偏移核对”，最终以全过滤 + 钳制 + 生命周期清理收尾。
