## 核心原理

GUN / 榴弹模式 / RPG 是同一条语义的三条实现，必须分别处理：

| 形态 | 换弹入口 | 时长由谁决定 | 本功能手段 |
|---|---|---|---|
| 普通枪械 | WPN_Gun.Reload(0xB62CB0) | GetAnimSpeed(reloadAnimRatio) × PlayerWeapons.ReloadSpeed → CFAnimator.SetFloat("ReloadSpeed", v) | Interceptor.replace SetFloat，把 v 乘倍率 |
| 榴弹模式（WPN_GrenadeGun.changeMode） | 同 WPN_Gun.Reload | 动画名被改成 "reload_A"，**不吃 "ReloadSpeed"** | 换弹前把武器/手部 Animator.speed 设为倍率，结束后复位 |
| WPN_RPG（火箭筒/AT4） | WPN_RPG.OnReloadBtnDown(0xB67AF0) | 只播放动画，从不写 "ReloadSpeed" | 同上 |

三条路径的换弹结束都是「reload 动画播完」事件 → 缩短动画即缩短换弹。

## 作用范围

- 模式：无限制。
- 武器：WPN_Gun 系（步枪/冲锋枪/狙击/手枪/霰弹/榴弹枪）+ 步枪的榴弹模式 + WPN_RPG（火箭筒/AT4/Nano AT4）。
  投掷 / 一次性 / 哨戒炮 / 近战不涉及。
- 仅本地玩家：bot 与其他玩家不变速。
- 叠加：多人生化人类「快速换弹」BUFF（attribute_Human.id == 15）×2.5 只作用于普通枪械；
  榴弹模式与 RPG 的最终倍率就是滑块值。
- Animator.speed 一定会在换弹结束 / 切模式 / 重新部署 / 关闭功能 / 5s 看门狗五个时机之一复位，
  不会残留导致后续动作一直加速。

## 参数

| 名称 | 范围 | 默认 | 说明 |
|---|---|---|---|
| multiplier | 1.0 ~ 5.0（步进 0.1） | 4.0 | 1.0 = 不加速；滑块拖动即时生效 |

manifest.controls 声明 slider（key=multiplier）；panel.py 自绘滑块行并返回
ui_handles.slider_var / slider_label 供 app 回填配置。

## 开发历程（重点）

### 踩过的坑

1. Hook get_isInfinityAmmo() 无效：只被 HUD_Weapon.Update 调用，纯 UI 显示。
2. IL2CPP bool 返回值要用 "int" 传 1/0。
3. v1 用 get_ReloadSpeed 只覆盖 GUN，覆盖式返回值还会冲掉原生 BUFF → 改为在最终值上乘。
4. v2：RPG 无效。原因：WPN_RPG.Reload(0xB67C40) 是死代码；RPG 换弹不吃 "ReloadSpeed"；
   日志辅助函数每模块 10 条上限把 AT4 阶段日志全吞了。→ RPG 改 Animator.speed。
5. v3：步枪切榴弹模式无效。原因：WPN_GrenadeGun.AnimName_Modifier 把 "reload" 改写成 "reload_A"，
   榴弹模式那条 clip 不吃 "ReloadSpeed"。→ 榴弹模式也走 Animator.speed，
   并在 SetFloat 参数路径里按 changeMode 跳过，避免倍率平方。
6. 2.7/2.8 早期：originalGetReloadSpeed 漏写 var → Frida 17 严格模式 ReferenceError，
   enable() 在装 Hook 前中断，功能 100% 不生效，而 UI 乐观更新不回滚。

### 经验教训

- 同一语义可能有多条实现路径（普通模式 / 榴弹模式 / RPG），要按"谁最终消费这个值"分流；
  同一个类里的两条动画状态也可能是两种机制。
- "函数存在"不等于"函数被调用"：改之前先扫全 DLL 的 call 指令确认调用点。
- 日志要有独立通道，且不能被 UI 层限流吞掉，否则排查时是瞎的。
- 能乘就不要覆盖；改动画器速度必须在结束/打断/切模式/重部署时复位。

## 一句话总结

普通枪械用 Interceptor.replace 包住 CFAnimator.SetFloat(+0xB34E40) 乘 "ReloadSpeed"；
榴弹模式（changeMode+0x54）在 WPN_Gun.Reload(+0xB62CB0)、RPG 在 WPN_RPG.OnReloadBtnDown(+0xB67AF0)
把武器与手部 Animator.speed 设为倍率；换弹结束/切模式/重新部署/关闭/5s 看门狗复位。
